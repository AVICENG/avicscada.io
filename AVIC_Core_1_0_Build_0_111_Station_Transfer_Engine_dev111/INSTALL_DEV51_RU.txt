AVIC Core 1.0 — DEV51 IQVISION Workbench Reconstruction

1. Распакуйте архив в отдельную папку (не поверх DEV50).
2. Откройте CMD в папке проекта.
3. Создайте окружение:
   py -3 -m venv .venv
4. Активируйте:
   .venv\Scripts\activate
5. Установите проект и зависимости разработки:
   python -m pip install --upgrade pip
   python -m pip install -e ".[dev]"
6. Запустите полный набор тестов:
   python -m pytest -q
7. Запустите Workbench:
   python -m avic_core.ui
8. Откройте в браузере:
   http://127.0.0.1:8000

Что проверить в интерфейсе DEV51:
- В левой панели переключите «Навигатор» / «Палитра».
- В Палитре найдите «Насос», затем «AND»; поиск должен фильтровать элементы.
- Введите в Locator Bar «AVIC / Аварии» и нажмите Enter или ↵.
- Вернитесь назад кнопкой ‹ или Alt+Left, вперёд — кнопкой › или Alt+Right.
- Выберите представление через View Changer.
- Нажмите правой кнопкой мыши на раздел дерева и выберите «Открыть».
- Для Project/Station/Network/Device/Point проверьте объектное контекстное меню, если объекты созданы.
- Откройте меню «Расписания» и перейдите в Scheduler.

Безопасность:
DEV51 не включает физические команды управления оборудованием в ходе этих UI-проверок. Discovery запускайте только осознанно, с выбранным сетевым интерфейсом и разрешением владельца OT-сети. Демонстрационный переключатель профиля не является серверным RBAC. Не использовать сборку для управления действующим объектом без отдельной приёмки безопасности, драйверов и полевых команд.
