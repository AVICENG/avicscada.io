AVIC Core 1.0 DEV92 — установка

1. Распакуйте архив в отдельную папку. Не устанавливайте поверх DEV85/DEV91.
2. Откройте CMD в папке сборки.
3. Выполните:
   python -m pip install -e ".[dev]"
4. Затем:
   python -m pytest -q
5. Проверка CLI:
   python -m avic_core --help

В Workbench выберите станцию → Создать физическую сеть.
- «Автоматически» — выберите интерфейс текущего компьютера.
- «Вручную» — задайте IP будущего компьютера AVIC, подсеть CIDR, шлюз и DNS.

После установки на объекте откройте контекстное меню сети:
- «Проверить привязку на этом ПК».
- «Ping IP станции».

AVIC не меняет IP Windows. Назначение адреса выполняется администратором ОС/сети отдельно. Не запускайте BACnet Discovery до выбора правильного интерфейса. Для manual-сети полевой опрос разрешается после точного совпадения IP и подсети с планом.
