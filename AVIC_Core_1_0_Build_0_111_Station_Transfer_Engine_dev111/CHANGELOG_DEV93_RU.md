# Изменения DEV93

- Русифицированы и упрощены основные подсказки в сетевом разделе.
- Добавлен пошаговый сценарий: сеть → протокол → устройство → проверка IP → проверка протокола.
- Добавлен словарь сетевых терминов простым языком.
- Уточнено различие между IP-маршрутизатором и промышленным шлюзом протоколов.
- В Time Manager добавлен выбор станции из дерева проектов и станций.
- Добавлен выбор часового пояса с понятными названиями городов/регионов.
- Объяснено различие UTC, местного времени объекта и времени выполнения циклов.
- Разрешение передачи времени контроллеру вынесено в дополнительные параметры с предупреждением.
- Сохранены ограничения безопасности: нет автоматического изменения сетевых настроек и нет фактической синхронизации часов контроллеров.
- Новые расписания наследуют часовой пояс выбранной станции из Time Manager; ручное дублирование настройки часового пояса убрано.
