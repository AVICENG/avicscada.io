# AVIC Core — журнал сборки DEV187

Дата: 26.11.2026

## Изменения
- Добавлен Core FBD блок COMBINATION с четырьмя BOOL-входами E/F/G/H и выходом OUT.
- Реализована формула таблицы условий: AND внутри строки, OR между включёнными строками; uppercase требует TRUE, lowercase требует FALSE.
- Добавлена строгая проверка четырёх строк, четырёх ячеек и допустимых значений.
- Добавлен COMBINATION в серверный FBD Studio compiler mapping и compile-preview validation.
- Полевые записи не выполняются; компиляция не означает публикацию.

## Регрессия
- Добавлен сквозной тест Studio → compile-preview → Core compile → Core simulation.
- Добавлен отрицательный тест неизвестного символа условия.
- Результаты CI: ожидают фактического выполнения. Статус DEV187 — НЕ ПОДТВЕРЖДЁН до завершения Windows CI.

## Покрытие
22 из 29 типов редактора имеют Core-контракт и путь компиляции. Остаются ANALOG_INPUT, EXTERNAL_SENSOR, PID_LOOP, DELAY, LATCH, SWITCH, TIME.

## Известные ограничения
- PID, временные и sensor blocks не объявляются готовыми до отдельной Core-реализации и тестов.
- Публикация в runtime и физические записи остаются отдельным защищённым процессом.
