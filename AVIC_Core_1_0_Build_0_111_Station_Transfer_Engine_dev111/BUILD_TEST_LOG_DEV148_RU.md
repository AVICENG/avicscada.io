# Журнал DEV148 — Station Transfer Workbench

## Изменения
- Добавлен экран Workbench для экспорта, проверки, переноса и клонирования.
- Реализованы API catalog/export/inspect/stage/commit.
- Экспорт блокируется при работающем Runtime или активных драйверах.
- Загрузка потоковая, лимит 512 МБ; токены случайные, TTL 15 минут, максимум 16 незавершённых операций.
- Пакет без подписи явно помечается UNsigned/unverified; staging требует acknowledgement.
- Перед изменением базы есть отдельное финальное подтверждение IMPORT или CLONE.
- Клон получает новые IDs для вложенных FBD nodes и Graphic elements; имена клонов проверяются на уровне Core service.
- После импорта Runtime регистрирует станцию в STOPPED, активация остаётся ручной.
- Origin guard проверяет точный hostname.
- Версия пакета и проекта: 1.0.0.dev148.

## Проверки
- Добавлены end-to-end тесты экспорта, upload/inspect/stage/commit, acknowledgement неподписанного пакета, подтверждения операции и запрета экспорта работающей станции.
- Добавлены проверки независимости вложенных IDs в FBD и графике.
- Итог CI фиксируется после завершения всех jobs для DEV148.

## Ограничения
- Подпись издателя отсутствует; происхождение пакета пользователь должен проверить самостоятельно.
- Миграция между разными версиями Core заблокирована.
- Нет автоматической активации, адресации оборудования и удалённого provisioning.
