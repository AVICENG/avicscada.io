# AVIC Core DEV79 — интеграция FBD-проектов в инженерное дерево

DEV79 продолжает DEV78. Основная задача — связать FBD Studio с основным деревом проекта и сделать редакторную навигацию и контекстные команды единообразными.

## Что изменено

- Инженерное дерево API теперь возвращает для каждой станции `fbd_projects`: список сохранённых FBD Studio документов, их страниц и опубликованных FBD Points (метаданные, без исполнения алгоритма).
- В основном дереве AVIC добавлен раскрываемый узел **FBD-проекты** под станцией. В нём видны документы, страницы и FBD Points.
- Из основного дерева можно создать FBD-проект, открыть конкретный проект или страницу, вызвать печать всего проекта либо выбранной страницы, а также создать страницу.
- FBD Studio открывает документ по `?document=<id>` и выбирает страницу по `?page=<id>`. Команда `?print=1` запускает печать выбранной страницы или всего документа.
- Правая панель редактора упрощена до единой библиотеки реально зарегистрированных FBD-блоков с поиском и категориями. Дублирующее дерево страниц и панели поиска/свойств убраны из видимой правой панели.
- Контекстные команды добавлены для страниц и проекта в левом дереве редактора; на доске контекстное меню различает блок, порт, соединение и пустое поле.
- Core Points и FBD Points в левом дереве редактора поддерживают перетаскивание на доску. Для FBD Point создаётся входной модуль со ссылкой на исходную FBD-точку; при перетаскивании на совместимый вход создаётся соединение.

## Важное ограничение

Перенос точки в FBD создаёт ссылку/привязку в авторском документе. Это не означает, что весь граф уже скомпилирован в исполняемую логику контроллера. FBD Studio документы по-прежнему имеют статус authoring-only; контроллерные записи не выполняются.
