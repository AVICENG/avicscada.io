# AVIC Core 1.0 — DEV92

Сборка развивает DEV91 в направлении Network Planning & Deployment.

## Ключевая возможность

Инженер может создать сеть вручную, указав будущий IP компьютера диспетчеризации, подсеть, шлюз и DNS, даже если он разрабатывает проект на другом компьютере и вне сети объекта. После установки AVIC проверяет, совпадает ли фактический интерфейс с проектной адресацией.

## Установка

```cmd
python -m pip install -e ".[dev]"
python -m pytest -q
python -m avic_core --help
```

## Важные ограничения

DEV92 не назначает IP компьютеру или контроллерам, не меняет маршрутизаторы и не выполняет массовое сканирование. ICMP Ping не гарантирует доступность прикладного протокола. Полная Windows acceptance и испытания на реальном оборудовании должны быть выполнены отдельно.
