# DEV141 — журнал сборки и тестирования

Дата: 25.11.2026

## Изменения
- Исправлен планировщик PollingSession: при превышении длительностью запроса периода опроса следующий запрос переносится на полный интервал после завершения предыдущего.
- Устранён немедленный catch-up запрос после медленного ответа контроллера. Это снижает риск дополнительной нагрузки на перегруженное оборудование.
- Сохранено поведение одного worker и отсутствие параллельных poll_once вызовов.

## Регрессионная проверка
- Добавлен тест длительного poll_once, подтверждающий полный интервал ожидания после overrun.
- Существующие проверки запуска, остановки, повторного запуска и валидации интервала сохранены.

## Статус
Код и регрессионный тест добавлены. Полный CI и Windows acceptance ещё не подтверждены. DEV141 не считается принятым до прохождения матрицы CI.
