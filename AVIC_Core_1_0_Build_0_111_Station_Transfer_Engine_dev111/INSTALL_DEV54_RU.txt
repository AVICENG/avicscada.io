AVIC Core 1.0 — DEV54

1. Распакуйте архив в новую папку.
2. Откройте CMD в этой папке.
3. Выполните:
   python -m pip install -e ".[dev]"
4. Затем отдельно выполните:
   python -m pytest --collect-only -q
5. После получения числа собранных тестов выполните:
   python -m pytest -q
6. Дополнительные проверки:
   python -m compileall -q avic_core tests
   python -m avic_core --help
7. Запуск Workbench:
   python -m avic_core.ui

DEV54: редактор мнемосхем доступен через раздел «Мнемосхемы». Создайте станцию, нажмите «Тестовая ВУ», добавьте привязки точек и сохраните.
Командные привязки и запись в оборудование отключены.
