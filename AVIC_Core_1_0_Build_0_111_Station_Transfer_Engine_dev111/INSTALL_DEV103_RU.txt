AVIC Core DEV103 — Windows

1) Распакуйте ZIP в отдельную папку, не поверх DEV102.
2) Откройте CMD в папке проекта.
3) Создайте окружение:
   python -m venv .venv
4) Активируйте его:
   .venv\Scripts\activate
5) Установите DEV-зависимости:
   python -m pip install -e ".[dev]"
6) Запустите локальную приёмку:
   python -m pytest -q tests\test_dev103_fbd_exposed_runtime_points.py tests\test_dev85_point_runtime.py tests\test_dev90_fbd_cyclic_runtime.py tests\test_dev95_fbd_studio_compiler.py tests\test_engineering_tree_values_dev39.py tests\test_graphics_binding_engine_dev98.py tests\test_ahu_fbd_to_fan_animation_dev102.py
7) Проверка модулей:
   python -m compileall -q avic_core
8) Запуск Workbench:
   python -m avic_core --help

Внимание: DEV103 проверяет циклическое вычисление FBD и публикацию виртуальных FBD-точек. Команды BACnet/Modbus Write и включение реального оборудования в этой сборке не реализованы. `background: false` используется только в детерминированном тесте; штатный запуск Runtime — фоновый.
