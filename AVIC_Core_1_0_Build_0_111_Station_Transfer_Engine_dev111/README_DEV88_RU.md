# AVIC Core 1.0 — DEV88

DEV88 продолжает DEV87. Основная задача — сделать происхождение FBD-точек однозначным при переносе из дерева проекта на другие страницы.

## Реализовано
- Инженерное дерево API дополняет FBD-точки структурой `provenance`.
- Происхождение содержит страницу, ID владельца, номер/тег и тип блока, индекс и человекочитаемый номер выхода, имя контакта.
- Номер выхода отображается с единицы (`OUT1`, `OUT2`), внутренний индекс остаётся нулевым.
- В FBD-дереве происхождение теперь видно под именем точки и полностью доступно во всплывающей подсказке.
- Если источник не разрешён по данным документа, он явно помечается как неразрешённый; отсутствующие сведения не угадываются.

## Не заявляется готовым
- FBD Runtime ещё не вычисляет выходы блоков как живые точки.
- Перенос FBD-точки в мнемосхему пока не означает работающую live-подписку.
- BACnet/Modbus polling и запись не добавлены этим этапом.
- Контекстные операции для сетей/устройств и объединение внутренних деревьев Graphics/Web Pages остаются следующими задачами.
