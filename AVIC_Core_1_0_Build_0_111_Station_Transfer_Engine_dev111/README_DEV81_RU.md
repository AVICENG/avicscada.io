# AVIC Core 1.0 — DEV81 FBD Editing Fixes

DEV81 продолжает DEV80. Сборка исправляет базовые операции FBD-доски и управление проектами.

## Изменения
- Соединения рисуются тонкой SVG-линией без кривых сегментов: только горизонтальные и вертикальные отрезки с поворотами 90°.
- Линии являются самостоятельными выбираемыми объектами; выбранная линия подсвечивается. Удаление выполняется через контекстное меню и Delete/Backspace.
- Перетаскивание блока начинается с любой его области, кроме портов; заголовок больше не является единственной зоной захвата.
- Инструмент T создаёт текстовую заметку на доске. Заметку можно перемещать, редактировать двойным щелчком/контекстным меню и удалять.
- После создания FBD-точки показывается её источник (страница → блок → порт) и предлагается перейти к модулю-источнику.
- Добавление/переименование страниц защищено от пустых и повторяющихся имён внутри проекта.
- FBD-проекты на сервере станции защищены от повторяющихся имён (без учёта регистра); добавлен API удаления проекта с проверкой ревизии и записью аудита.
- В контекстное меню FBD-проекта добавлено удаление с подтверждением.

## Важные границы
- Это не означает, что FBD-граф исполняется в AVIC Runtime: документы остаются authoring-only, runtime compiler не входит в DEV81.
- Перетаскивание FBD-точки между разными FBD-проектами не стало runtime-связью.
- Визуальная приёмка в реальном браузере Windows и проверка реального диалога печати ещё не выполнены.
