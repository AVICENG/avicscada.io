# Журнал сборки AVIC Core DEV79

Дата: 22.11.2026  
База: DEV78 FBD Visual Repair.

## Реализовано

1. `EngineeringTreeService` включает сохранённые `FBDStudioDocument` в дерево станции: проекты, страницы, FBD Points.
2. Основное дерево AVIC показывает FBD-проекты под каждой станцией. Добавлены создание FBD-проекта, открытие проекта/страницы, печать проекта/страницы и создание страницы через контекстные команды.
3. FBD Studio выбирает документ и страницу по query-параметрам; режим печати запускается после загрузки документа.
4. Правая панель FBD Studio оставлена под библиотеку зарегистрированных блоков с категориями и поиском.
5. Внутреннее дерево FBD Studio поддерживает контекстные команды проекта и страниц.
6. Контекстное меню рабочей доски обрабатывает блоки, порты, линии и пустое поле.
7. Core Points и FBD Points поддерживают drag-and-drop на доску; FBD Point формирует входной модуль с сохранённой ссылкой на исходную точку и может соединяться с совместимым входом.

## Ограничения / статус

- FBD Studio остаётся редактором авторского графа; полноценная компиляция всех блоков в исполняемую логику контроллера не заявляется.
- Перетаскивание FBD Point создаёт входной модуль со ссылкой на FBD Point. Runtime-разрешение такой ссылки между графами/проектами ещё не реализовано.
- Печать через системный диалог реализована через браузерный `window.print()`; визуальная проверка разбиения всех страниц на бумажные листы нужна в Windows.
- DEV79 — интеграционная сборка для приёмки, не финальный релиз.
