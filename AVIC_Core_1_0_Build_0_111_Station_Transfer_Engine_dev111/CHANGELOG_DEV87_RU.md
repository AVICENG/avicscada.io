# Изменения DEV87

- На главной странице скрыта вторая колонка старого навигатора; используется общая панель инженерного дерева.
- В FBD Studio скрыта локальная копия инженерного дерева: дерево открывается из общей левой навигации, справа остаётся библиотека FBD-блоков.
- Добавлен корневой узел `AVIC`; контекстное меню по правому щелчку на нём предлагает создать проект.
- Контекстное меню проекта предлагает создать станцию и переименовать проект.
- Контекстное меню станции предлагает переименовать станцию.
- Операции используют существующие API Core, сохраняются через ProjectStationService и проходят локальную проверку оператора.
- Сохранены перенос физических точек и FBD-точек из общего дерева.
- Добавлены регрессионные тесты общей навигации, контекстных операций и сохранности Point Runtime/FBD wiring.
