# AVIC Core 1.0 — DEV100

DEV100 продолжает интеграцию Repository Manager DEV23 в Core на базе предоставленного архива DEV98.

Основное изменение: Repository стал видимой веткой существующего инженерного дерева под каждой станцией. Переход сохраняет station context и открывает существующий Core Web Pages workspace.

Сборка не создаёт второй сервер, хранилище, реестр точек или систему авторизации.

См. `docs/REPOSITORY_DEV23_CORE_MERGE_DEV100_RU.md` и `BUILD_TEST_LOG_DEV100_RU.md`.
