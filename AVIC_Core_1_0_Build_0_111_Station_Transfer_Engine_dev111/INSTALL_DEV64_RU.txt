AVIC Core 1.0 — DEV64 Workbench Editors & SVG Library

1. Распакуйте архив, например, в:
   C:\AVIC_Core_1_0_Build_0_64_IQVISION_Workbench_Editors_dev64

2. Откройте CMD и перейдите в каталог:
   cd /d C:\AVIC_Core_1_0_Build_0_64_IQVISION_Workbench_Editors_dev64

3. (Рекомендуется) создайте виртуальное окружение:
   python -m venv .venv
   .venv\Scripts\activate

4. Установите DEV-зависимости:
   python -m pip install -e ".[dev]"

5. Проверьте исходники:
   python -m compileall -q avic_core tests

6. Запустите полный набор тестов:
   python -m pytest -q

7. Запустите AVIC Engineering Workbench:
   python -m avic_core.ui --host 127.0.0.1 --port 8765 --data-dir .\data_dev64

8. Откройте браузер:
   http://127.0.0.1:8765

ПРОВЕРКА SVG / GRAPHICS:
- Откройте меню «Инженерия» → «SVG-библиотека символов».
- Создайте проект и станцию либо выберите существующую станцию.
- В Graphics Editor создайте новую мнемосхему.
- В левой панели найдите «Вентилятор», «Насос» или «Датчик температуры».
- Нажмите символ или перетащите его на холст.
- Измените имя/позицию/размер/поворот и нажмите «Сохранить».
- Закройте/откройте документ и проверьте сохранённый символ.

ПРОВЕРКА FBD:
- Откройте «Инженерия» → «Wiresheet / FBD».
- Выберите рабочую станцию.
- Создайте новую схему либо откройте существующую.
- Добавьте блоки из левой библиотеки.
- Выберите выходной порт первого блока и совместимый входной порт второго.
- Сохраните схему и выполните «Сохранить и симулировать».
- Убедитесь, что результат помечен как OFFLINE и полевые записи не выполнялись.

Безопасность и ограничения DEV64:
- Runtime не включается автоматически.
- Offline Simulation не управляет полевыми контроллерами.
- Полевые записи отключены.
- Серверный RBAC в DEV64 не реализован; loopback guard не является промышленной системой доступа.
- Пользовательский импорт SVG отсутствует; доступны только 28 встроенных SVG.
- Сборка не заявляется как полная IQVISION/Niagara parity.
