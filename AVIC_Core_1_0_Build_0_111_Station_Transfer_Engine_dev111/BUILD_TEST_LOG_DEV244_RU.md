# DEV244 — Строгая валидация временных меток Driver IPC

Дата: 27.11.2026

## Изменения

- Заменена поверхностная проверка формата `sent_at` на разбор RFC3339 через Chrono.
- Сохраняется требование канонического UTC с суффиксом `Z`.
- Отклоняются невозможные календарные даты и значения времени.
- Смещения `+03:00` и `+00:00` не принимаются вместо канонического UTC-представления.
- Корректные дробные секунды остаются допустимыми.
- Добавлены тесты на невозможную дату, месяц, часы, минуты, секунды и корректную дробную часть.

## Затронутые компоненты

- Rust Communication Engine: `rust/avic-communication-engine/src/ipc.rs`.
- Контракт Driver SDK v1: `docs/architecture/DRIVER_SDK_V1_IPC_CONTRACT_RU.md`.

## Безопасность и совместимость

Изменение ужесточает валидацию входящих сообщений, не меняя формат корректных сообщений, которые уже отправляет AVIC Worker (`...Z`). Некорректные сообщения отклоняются до обработки payload.

## Проверки

- Локальное выполнение тестов в этой операции не заявляется.
- GitHub Actions для DEV244 должен подтвердить Rust unit tests и общую матрицу Windows/Linux/Python.
- До завершения нового CI статус DEV244: **ожидает проверки**.
- Аппаратные испытания и производственная приёмка не выполнялись.
