AVIC Core DEV79 — установка в Windows

1. Распакуйте архив в новую папку. Не устанавливайте поверх DEV77/DEV78.
2. Откройте CMD в папке проекта.
3. Выполните по одной команде:

python -m venv .venv
.venv\Scripts\activate
python -m pip install -e ".[dev]"
python -m pip check
python -m avic_core.ui --host 127.0.0.1 --port 8001 --data-dir .\data

4. Откройте http://127.0.0.1:8001/ .
5. Раскройте проект и станцию. Под станцией должен быть узел «FBD-проекты».
6. Через плюс создайте FBD-проект. Раскройте его, откройте страницу двойным щелчком.
7. Для печати проекта или страницы используйте правую кнопку мыши на соответствующем узле дерева.
8. В FBD Studio правая панель содержит библиотеку блоков. Core Points и FBD Points находятся в левом дереве и перетаскиваются на доску.

Если `pip check` сообщает конфликт пакетов, пришлите полный вывод. Не смешивайте команды в одну строку.
