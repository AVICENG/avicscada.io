# Изменения DEV97

- Добавлен Core FBD HYSTERESIS с состоянием между циклами.
- Добавлено транзакционное обновление runtime_state: состояние фиксируется только после успешного прохода графа.
- FBDExecutionService хранит состояние блоков на протяжении поколения стратегии и сбрасывает его при новом запуске.
- SCALE Studio компилируется в Core SCALE; параметры диапазонов материализуются в четыре константы Core.
- Сохранена настройка clampOutput, по умолчанию ограничение включено.
- HYSTERESIS Studio компилируется; не подключённые LOW/HIGH берутся из параметров блока, явные связи имеют приоритет.
- Локальная логика DIV больше не возвращает фиктивный ноль при делении на ноль.
- Добавлены тесты на гистерезис, память между тиками, сброс при перезапуске, ошибочные пороги, компиляцию SCALE/HYSTERESIS и валидацию нулевого диапазона.
