# AVIC Core 1.0 — DEV158

## Цель
Закрыть найденную тестовую регрессию DEV157 и не допускать откат в неполные исторические снимки.

## Изменения
- Rollback отклоняет исторические версии, где графический блок не содержит frozen graphic_snapshot.
- Сквозной тест после перезапуска проверяет, что рабочая графика содержит намеренное изменение, а опубликованная версия по-прежнему содержит две исходные привязки.
- Добавлены проверки наличия в Page Builder выбора версии и команды rollback.
- Уточнён статусный текст редактора: публикация доступна с историей версий.
- Версия пакета повышена до 1.0.0.dev158.

## Проверки
- DEV157: Python 3.13 / Ubuntu — 31 261 passed, 1 failed; единственная ошибка была в финальной проверке исходной графики после того, как тест намеренно удалил её bindings. Проверки неизменности опубликованного снимка и rollback прошли.
- DEV158 CI запускается после commit; до полной матрицы Linux/Windows сборка не считается принятой.

## Безопасность
- Workbench всё ещё работает в local-only режиме. Существующие роли и Security Gateway пока не подключены к UI/API маршрутам; удалённое customer deployment запрещено до завершения интеграции аутентификации, MFA, RBAC и station scopes.
- Откат к историческим версиям без замороженных графических snapshots теперь явно запрещён.
