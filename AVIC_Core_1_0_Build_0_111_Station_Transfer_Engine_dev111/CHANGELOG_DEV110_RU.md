# DEV110 — AVIC Deployment Manager (первый этап)

- Добавлен формат переносимого инженерного пакета `.avicpkg`.
- Добавлены manifest, SHA-256, контроль состава, ограничение размера и безопасная проверка путей.
- Добавлены проверка версии Core/модулей и staged import без перезаписи непустой целевой папки.
- Site Profile и секреты отделены от переносимого пакета.
- Backup/Restore остаётся отдельной функцией.
- Реализация пока частичная: нет интерфейса, подписи издателя, миграций версий, автоматического импорта из БД и активации/rollback работающей станции.
