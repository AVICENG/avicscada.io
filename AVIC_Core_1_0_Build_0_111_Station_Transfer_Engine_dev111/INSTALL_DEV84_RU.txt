AVIC Core 1.0 DEV84 — установка в Windows

1. Распакуйте архив в отдельную папку. Не устанавливайте поверх DEV83.
2. Откройте CMD или PowerShell в папке сборки.
3. Выполните:
   python -m pip install -e ".[dev]"
   python -m pip check
   python -m avic_core --data-dir .\avic_data init
   python -m avic_core.ui --host 127.0.0.1 --port 8001 --data-dir .\avic_data
4. Откройте http://127.0.0.1:8001/

Общая левая навигация: Главная, Проекты, Сети, Устройства, Точки, Мнемосхемы, FBD, Web Pages, Аварии, Архивы, Безопасность, Диагностика.

В FBD точки оборудования находятся в инженерном дереве под Сети и устройства → Сеть → Протокол → Устройство → Точки. Перетаскивание создаёт ссылку на исходную точку. В DEV84 связь хранит протокольные метаданные, но автоматический циклический опрос и запись команд ещё не включены.

Безопасность: DEV84 не отправляет команды записи в полевые контроллеры. Не используйте локальную FBD-симуляцию как подтверждение реального управления оборудованием.
