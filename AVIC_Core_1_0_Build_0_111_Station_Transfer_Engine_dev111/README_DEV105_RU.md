# AVIC Core 1.0 DEV105 — Embedded Graphics Runtime

DEV105 продолжает DEV104. Основное изменение — полноценное встраивание опубликованной мнемосхемы в Web Application страницу.

## Новый сценарий

1. Создать страницу в Repository → Web Application.
2. Назначить странице мнемосхему из Core Graphics.
3. Добавить компонент «Мнемосхема» на страницу и сохранить.
4. Опубликовать страницу.
5. Открыть операторский URL: мнемосхема отображается внутри страницы, а не отдельной ссылкой.
6. Значения, quality и разрешённая обратной связью анимация обновляются из Point Runtime.

## Важная граница безопасности

DEV105 реализует только read-only отображение мнемосхемы. Кнопки запуска/остановки в Web Page Builder не управляют оборудованием. Физические команды остаются выключенными до полноценной реализации Command Manager, server-side RBAC, Access Lease, драйверных write adapters и подтверждения read-back.

См. `docs/WEB_APPLICATION_PAGE_BUILDER_DEV104_RU.md` и `BUILD_TEST_LOG_DEV105_RU.md`.
