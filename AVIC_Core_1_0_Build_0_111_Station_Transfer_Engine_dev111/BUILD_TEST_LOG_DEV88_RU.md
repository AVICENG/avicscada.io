# Журнал DEV88

## База
- DEV87, версия `1.0.0.dev87`.
- Новая версия пакета: `1.0.0.dev88`.

## Изменения
- `EngineeringTreeService` теперь разрешает ссылку FBD-точки до страницы и блока-владельца.
- Добавлены provenance-поля `page_id`, `page_code`, `module_id`, `module_no`, `module_tag`, `module_type`, `output_index`, `output_number`, `output_name`, `label`, `resolved`.
- FBD Tree показывает страницу, тег/тип блока и `OUTn` с именем выхода.
- Сохранено правило: неизвестные данные не подменяются выдуманными значениями.

## Проверки
- Добавлены unit-тесты для корректного разрешения блока и перевода нулевого индекса выхода в номер с единицы, а также для отсутствующих/неразрешённых источников.
- Результаты тестов и сборки будут внесены после фактического запуска в текущей среде.

## Ограничения
- Это provenance/UI-улучшение, а не FBD Runtime.
- Не подключает физические драйверы и не создаёт live binding мнемосхем.
