# AVIC Core 1.0 DEV62

Интегрированная инженерная сборка на базе DEV57 с накопленными сервисами Workbench, Network/Discovery, Driver Manager, Graphics, FBD, Scheduler, Alarm, History, Audit, Security primitives и Backup primitives.

Начните с `INSTALL_DEV62_RU.txt`. Новые функции и ограничения описаны в `docs/BUILD_062_RU.md`, сквозной цикл — в `docs/INTEGRATED_ENGINEERING_WORKFLOWS_DEV62_RU.md`.

DEV62 — development build. Это не production-ready SCADA: field writes, циклическое production исполнение FBD, полноценный runtime scheduler и полная серверная RBAC-интеграция не включены.
