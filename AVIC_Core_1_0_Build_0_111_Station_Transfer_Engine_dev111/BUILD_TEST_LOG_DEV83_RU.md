## Ограничения

- Полный набор репозитория не запускался.
- Windows-браузерная визуальная приёмка и проверка реального указателя по линиям не выполнялись.
- Важное уточнение по заливкам: просмотр DEV81 показал, что постоянные линии уже выводились через `polyline` с `fill=none`; временный preview — через `path` с CSS `fill:none`. Поэтому моя предыдущая версия про автоматическое замыкание постоянного `path` была неверна. DEV83 добавляет `fill:none!important` и `fill-opacity:0!important` для всех SVG polyline/path внутри слоя проводов. Фактическую первопричину увиденного в браузере эффекта можно подтвердить только по скриншоту и DOM/CSS фактически открытой сборки; вероятные направления проверки — переопределяющий стиль или старая закэшированная версия.
- FBD Studio остаётся редактором подготовки, runtime-компиляция не заявляется.
