# AVIC Core 1.0 — DEV80 FBD Workbench Usability

DEV80 продолжает DEV79. Сборка исправляет навигацию по большому числу FBD-страниц, контекстные команды и работу с несколькими FBD-проектами одной станции.

## Основные изменения

- Вкладки FBD-страниц больше не обрезаются горизонтальной полосой с `overflow:hidden`: используется адаптивная сетка вкладок с переносом на несколько строк, ограниченной высотой и прокруткой при очень большом количестве страниц. Названия вкладок показываются с подсказкой полного имени.
- Контекстные команды переведены на единый обработчик правой кнопки мыши на уровне документа. Он учитывает порты, блоки, соединения, вкладки, точки контроллеров, FBD Points, FBD-проекты, группы страниц/точек, инженерное дерево и свободное поле доски.
- Верхние меню Файл, Проект, Правка, Каталоги, Стратегия, Вид, Инструменты, Окно и Справка теперь открывают компактные выпадающие меню с командами вместо модального окна со случайным набором кнопок.
- Основное инженерное дерево показывает все FBD-проекты станции из `/api/engineering/tree`, включая их страницы и FBD Points. Проекты можно открывать отдельно; поддержано создание нескольких проектов на одной станции.
- Контекстные команды страницы в основном дереве включают открытие и печать страницы, а также печать всего соответствующего FBD-проекта.
- Перед переключением на другой FBD-документ выполняется принудительное сохранение текущего документа в Core, чтобы не потерять изменения, ожидающие debounce-таймера автосохранения.
- Печать полного проекта остаётся отдельной командой и формирует комплект листов по всем страницам текущего FBD-документа.

## Запуск

```cmd
python -m venv .venv
.venv\Scripts\activate
python -m pip install -e ".[dev]"
python -m pip check
python -m avic_core.ui --host 127.0.0.1 --port 8001 --data-dir .\data
```

Открыть `http://127.0.0.1:8001/logic`.
