# CHANGELOG DEV114

- Расширен каталог Network & Drivers: 15 протокольных/интеграционных позиций.
- Добавлены категории дерева: Trend, Building Automation, Industrial, Integration, Semantic & Metadata.
- Каждому драйверу назначен стабильный license feature key `driver.<id>`.
- Fox, CCN, Andover и N2 исключены.
- Сохранены честные статусы: только BACnet/IP и Modbus TCP имеют текущие ограниченные read-only transport возможности.
- Добавлены тесты состава каталога, исключений, группировки, license keys и запрета записи.
- Добавлена русская документация дерева и коммерческой модели.
- Реальная интеграция с License Manager и UI tree не входит в DEV114.
