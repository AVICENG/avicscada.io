# Журнал DEV153 — корректировка KNX DPT 9.001 regression vectors

## Изменения
- Обновлён исторический codec regression test: отрицательное значение DPT 9.001 теперь использует корректную 11-битную signed two's-complement мантиссу (0x860C для -5.00).
- Добавлена проверка invalid data pattern 0x7FFF.
- Это синхронизирует ранний тест DEV142 с исправленным декодером DEV152.

## Проверки
- Проверки выполняются полным CI на актуальной ветке; отдельный результат до завершения workflow не заявляется.
