# AVIC Core 1.0 — DEV175
## Безопасная остановка Core и владение FBD Runtime

**Статус:** реализация добавлена в рабочую ветку; CI и интеграционные проверки ожидают подтверждения. Не считать сборку принятой до зелёной матрицы.

### Изменения
- CoreApplication владеет FBDExecutionService.
- Добавлен read-only preview состояния станций, драйверов и FBD worker перед остановкой.
- Добавлен endpoint POST /api/core/shutdown с обязательным подтверждением STOP AVIC CORE и локальной проверкой Origin.
- Последовательность остановки: FBD → драйверы → station Runtime.
- При неуспешной остановке worker Core не помечается закрытым; API возвращает HTTP 409.
- CLI Workbench использует Uvicorn Server и запрашивает graceful shutdown после ответа API.
- В навигацию добавлена отдельная команда «Остановить AVIC Core»; выход из Workbench остаётся отдельной операцией.
- Версия пакета обновлена до 1.0.0.dev175.

### Проверки, добавленные в тесты
- Preview не останавливает сервисы.
- Core.close закрывает принадлежащий Core FBDExecutionService.
- API требует точную строку подтверждения.
- Callback завершения процесса вызывается только после успешной остановки.
- При ошибке остановки FBD API возвращает 409 и не объявляет Core закрытым.
- UI содержит отдельную команду остановки Core.

### Что ещё не подтверждено
- Полный pytest на Python 3.11/3.12/3.13 и Windows.
- Реальное завершение Uvicorn-процесса в Windows и Linux.
- Browser E2E с активным драйвером, активной FBD-стратегией и имитацией зависшего worker.
- Интеграция RBAC/Admin scope для остановки Core.

### Безопасность
Остановка локального процесса не выключает полевые контроллеры и не обесточивает оборудование. Контроллеры продолжают автономную работу. Команда не отправляет физические STOP-команды через драйверы.
