# Журнал сборки AVIC Core 1.0 DEV100

Дата: 23.11.2026  
База: предоставленный пользователем архив AVIC Core DEV98 + изменения Repository DEV99.  
Версия пакета: `1.0.0.dev100`.

## Реализовано

1. В общем инженерном дереве добавлена видимая строка `Репозиторий` под каждой станцией.
2. Нажатие на строку открывает `/repository?station=<station_id>`.
3. Страница Repository читает station ID из query string и выбирает указанную станцию. Если параметр отсутствует или не соответствует станции проекта, используется первая доступная станция.
4. Для Repository используется общий Core Workbench shell и уже существующий `WebPagesService`; отдельный сервер и отдельное хранилище не создавались.
5. Добавлен регрессионный тест на дерево, навигацию, передачу контекста станции и активное состояние навигации.
6. Обновлены документация интеграции, README и журнал сборки.

## Известные ограничения

- DEV100 не завершает полноценную миграцию DEV23. Перенесена навигационная интеграция и выбор контекста станции.
- API изменения Web Pages по-прежнему защищены loopback/Origin guard. Это временный локальный барьер, не полноценная сессия, MFA или RBAC.
- Полное применение `SecurityGateway` ко всем изменяющим API ещё не выполнено.
- Редактор ресурсов, шаблонов, отдельных стилей и скриптов из DEV23 требует дальнейшей миграции в Core-owned сервисы.
- Публикация веб-страниц в клиентскую сеть выключена.
- Команды оборудования из графики не добавлены и не должны обходить Core Command Manager.

## Готовность

**DEV100 — проверенная итерация навигационной интеграции, не релиз-кандидат.** Три выбранных набора тестов прошли, синтаксис JavaScript и импорт wheel проверены. Полный тестовый набор, Windows acceptance и полноценная серверная RBAC-защита остаются обязательными следующими этапами.
