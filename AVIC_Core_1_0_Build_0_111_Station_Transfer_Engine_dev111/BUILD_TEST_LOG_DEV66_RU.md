## Известные ограничения

- Символы — оригинальная объёмная изометрическая SVG-графика, не true-3D CAD и не фотореалистичные рендеры.
- `anim-rotor` — именованная группа для Runtime renderer; сама по себе не запускает вращение.
- Положение заслонок, скорость вентиляторов, live-перекраска контуров и управление физическим оборудованием не подключены к данным Runtime.
- Niagara assets не копировались; сделана собственная библиотека по аналогичной инженерной таксономии.
