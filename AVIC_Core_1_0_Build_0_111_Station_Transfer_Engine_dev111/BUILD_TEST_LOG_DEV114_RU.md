# DEV114 — журнал сборки и испытаний

Дата: 2026-11-25  
Ветка: `dev113-network-drivers`  
Версия: `1.0.0.dev114`

## Изменено
- Расширен каталог драйверов и добавлены категории.
- Добавлен license feature key для каждой позиции.
- Обновлены тесты каталога.
- Добавлена документация `docs/DRIVER_CATALOG_TREE_DEV114_RU.md`.

## Объём каталога
15 позиций: Trend IP, BACnet/IP, BACnet MS/TP, Modbus TCP, Modbus RTU, LonWorks, KNXnet/IP, MQTT, OPC UA Client, OPC UA Server, OPC DA Gateway, oBIX, SNMP, Haystack, AVIC REST Integration.

Исключены Fox, CCN, Andover и N2.

## Проверки
- Автоматические тесты DEV114: ожидают выполнения в CI после публикации коммита.
- До завершения CI результат не заявляется.
- Полевые испытания протоколов не проводились.

## Ограничения
- Реализованы только прежние ограниченные read-only основы BACnet/IP и Modbus TCP.
- Остальные позиции имеют статус Planned.
- Trend IP/vCNC, лицензирование, UI-дерево и платное включение драйверов не реализованы этим изменением.

## Готовность
Каталог/архитектурное дерево: добавлено в код и документацию; требуется CI.
Сетевые драйверы как готовые продукты: не готовы.
Коммерческая блокировка лицензией: спроектирована на уровне feature keys, не реализована.
