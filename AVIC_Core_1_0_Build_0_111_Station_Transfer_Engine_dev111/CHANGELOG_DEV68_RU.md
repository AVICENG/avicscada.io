# CHANGELOG DEV68

## FBD Strategy Pages & Cross-page Connectives
- С DEV67 сохранена база AHU Modular Animation и SVG HVAC.
- Добавлена сущность StrategyPage и автоматическая первая страница для новых FBD-документов.
- Добавлены CRUD-операции страниц с защитой последней страницы и занятых страниц.
- Добавлено назначение LogicNode на страницу.
- Добавлена сущность StrategyConnective для связи типизированных портов между страницами.
- Межстраничные Connective участвуют в offline-симуляции.
- Добавлены проверки типов, занятости входов, циклов, принадлежности стратегии и optimistic revision.
- В FBD UI добавлен переключатель страниц, базовое управление страницами и создание/удаление межстраничных связей.
- Добавлены тесты DEV68.
- Полевые команды по-прежнему отключены.
