# AVIC Core 1.0 — DEV83

- Введён единый контракт UID / Tag / Name для FBD-блоков.
- Автоматическая типовая нумерация блоков: PID_001, AI_001, AND_001 и др.; tag уникален на уровне FBD-проекта.
- Копирование блока и страницы назначает новые UID/tag, не меняя исходные объекты.
- FBD Points получают отдельную нумерацию AO_001 / DO_001; legacy FBDP tag сохраняется в legacy_tag при миграции.
- Символьный адрес формируется по устойчивому tag блока: P1.PID_001.OUT.
- Сервер отклоняет повторяющиеся module tags.
- У SVG-соединений усилен запрет заливки на уровне CSS; видимая линия и прозрачная зона выбора остаются раздельными.
