# AVIC Core 1.0 — DEV82 Unified Engineering Tree & Point Identity

DEV82 продолжает DEV81. Сборка объединяет исправления инженерного дерева, FBD Points, адресации и PID.

## Установка и запуск (Windows)
```bat
python -m pip install -e ".[dev]"
python -m pip check
python -m avic_core --data-dir .\avic_data init
python -m avic_core.ui --host 127.0.0.1 --port 8001 --data-dir .\avic_data
```
Откройте `http://127.0.0.1:8001/`. Навигация между Dashboard, Pages, FBD и Graphics доступна из общей верхней панели.

## Что проверять вручную
1. Создать FBD-проект, страницу P1, блок PID_LOOP.
2. Создать FBD point из выхода PV/OUT (в зависимости от нужного порта). Точка должна появиться внутри дерева своего FBD-проекта после автосохранения.
3. Убедиться, что нижнего отдельного каталога FBD Points больше нет.
4. Раскрыть четыре группы типов/направлений точек; пустые группы не должны создавать фиктивные точки.
5. Навести курсор на точку: проверить полный source/provenance в tooltip; двойной щелчок и контекстное меню должны вести к источнику/свойствам.
6. Попробовать повторно опубликовать тот же source port — операция должна быть отклонена.
7. Проверить FBD-провод: тонкая линия, 90° повороты, отдельная зона выбора, удаление без затрагивания блоков.
8. Перетащить блок за тело и проверить, что порты остаются рабочими.
9. Открыть PID на дисплее 1366×768 и 1920×1080; проверить заголовок, прокрутку, нижние кнопки.
10. В локальной симуляции проверить Direct/Reverse, насыщение, MANUAL/AUTO и reset. Не подключать к реальному управлению без отдельной commissioning/validation процедуры.

## Ограничения
- FBD Studio остаётся редактором подготовки; компиляция FBD-графа в Runtime в DEV82 не реализована.
- Регистрация `pending_core_registration` показана как ожидающее состояние; интеграция с серверным License Manager ещё не завершена.
- Проверка браузерного hit-testing, печати и реального поведения мыши в Windows должна быть выполнена пользователем.
- Общая навигация в этой сборке связывает четыре реализованных workspace; она не означает, что каждый тип оборудования уже имеет отдельный полноценный редактор.
- BACnet/Modbus сохраняют родные адреса. Нормативный контракт и модель хранения описаны в `docs/AVIC_POINT_IDENTITY_CONTRACT_DEV82_RU.md`; конкретные драйверы требуют отдельной аппаратной приёмки.
