# AVIC Core 1.0 · DEV102

## Цель сборки

Проверить сквозной сценарий: **точка станции → FBD POINT_INPUT → логический BOOL-выход → секция приточного вентилятора ПВУ → вращение SVG-ротора**.

## Что исправлено

- Разрешена привязка BOOL-выхода FBD к `ahu_section_supply_fan`, а не только к старому универсальному символу `fan`.
- Сохранение мнемосхемы больше не удаляет FBD-привязку секционного вентилятора ПВУ.
- Добавлен read-only endpoint `/api/graphics/{document_id}/logic-bindings/evaluate`: он вычисляет FBD-схему через `POINT_INPUT`, читающий Core Point Runtime, и возвращает значение/качество привязки.
- Graphics Workbench использует FBD-результат для `state-fan-running`. При ошибке расчёта или качестве не GOOD вентилятор не анимируется.
- Исправлен SVG-рендер: прозрачная область перехвата мыши больше не перекрывает сами SVG-модули белым прямоугольником.
- Подписи элементов вынесены из масштабируемой группы, поэтому текст не растягивается вместе с символом.
- Сохранение времени CSS-анимаций при периодическом обновлении значений предотвращает перезапуск вращения каждые 1,5 секунды.

## Как проверить сценарий

1. Открыть инженерное дерево → станция → Репозиторий → Graphics.
2. Нажать «Тестовая ПВУ · 7 секций».
3. В FBD создать стратегию для той же станции; добавить реальную точку типа BOOL через `POINT_INPUT`.
4. Соединить `POINT_INPUT` и разрешающий BOOL-сигнал с блоком `AND` (или другим BOOL-блоком).
5. Выбрать секцию «Приточный вентилятор», выбрать BOOL-выход FBD и нажать «Связать с логикой».
6. При GOOD/TRUE ротор вращается; при GOOD/FALSE останавливается; при BAD/UNCERTAIN/STALE расчёт закрывается безопасно и анимация выключается.

## Проверки DEV102

- Совместная выборочная регрессия: 12 543 passed.
- Headless Chromium: SVG ПВУ видны, FBD GOOD/TRUE включает `avicFanSpin`, GOOD/FALSE и BAD выключают анимацию.
- Полный pytest не завершился за 120 секунд (остановлен примерно на 40%); полного результата нет.

## Ограничения

- Это проверка read-only FBD evaluation/preview поверх Core Point Runtime. Она не является публикацией стратегии в контроллер и не включает автономный циклический FBD runtime.
- Запись в BACnet/Modbus и команды оборудованию не выполняются.
- Проверка выполнена на синтетической точке в Core Point Runtime и в headless Chromium с подменёнными HTTP-ответами UI. Физический BACnet-контроллер и Windows acceptance в этой сборке не проверялись.
- Полный набор pytest и полная регрессия всех рабочих пространств не заявляются как пройденные; журнал содержит фактические выборочные результаты.
