# AVIC Core 1.0 — DEV43: нижний инспектор и действия дерева

## Основа
DEV43 собран из исходной папки DEV42 `AVIC_Core_1_0_Build_0_42_Persistent_Navigation_dev42`.

## Реализовано
- Правая постоянно открытая колонка инспектора удалена из основного layout.
- Инспектор перенесён в нижний dock под рабочей областью; центральная область получает освободившуюся ширину.
- Нижний dock можно изменять по высоте перетаскиванием верхней границы; высота сохраняется в localStorage.
- Инспектор можно скрыть и вернуть через кнопку панели инструментов/меню «Окно»; видимость сохраняется.
- Двойной щелчок по заголовку инспектора разворачивает/восстанавливает его.
- Вкладки: «Свойства», «Значения», «Диагностика», «Зависимости», «История».
- «Свойства» используют существующий API `/api/engineering/entities/{id}`. Значения и диагностика показывают только возвращённые Core данные. Для зависимостей и полной истории отображается честное состояние «пока не подключено» — данные не выдумываются.
- У объектов динамического инженерного дерева добавлена кнопка `···`; она открывает типизированное меню действий.
- Правая кнопка мыши на объекте открывает то же меню.
- Двойной щелчок по узлу с дочерними объектами раскрывает/сворачивает его; двойной щелчок по конечному объекту выбирает его и загружает инспектор.
- Исправлена передача интерфейса сети в BACnet Discovery из контекстного меню: используется сохранённый контекст выбранного объекта, а не ссылка на переменную DOM вне её области видимости.
- Обновлены версия UI/API и сведения сборки на DEV43.

## Проверки в среде сборки
- `node --check` встроенного JavaScript `index.html` — успешно.
- `python -m compileall -q avic_core` — успешно.
- `python -m pytest -q` — **215 passed**.
- `python -m pytest -q -rs` — **215 passed**, пропусков нет.
- `python -m pip check` — обнаружено внешнее несоответствие окружения: `moviepy 2.2.1` требует `pillow<12.0`, установлена `pillow 12.3.0`. Это не зависимость AVIC Core, но проверка окружения в целом не проходит.

## Не входит в готовность DEV43
- RBAC/authentication не становится реализованным от переноса инспектора.
- Граф зависимостей и полноценный журнал истории объекта пока не подключены; вкладки честно показывают это.
- Не добавлены новые backend-операции удаления/редактирования сверх уже существующих DEV42.
- Это проверка исходного кода и тестов в текущей среде сборки. Требуется отдельная Windows-приёмка пользователем: визуальная проверка размера dock, drag-resize, скрытия/восстановления, меню `···`, правого клика и двойного щелчка.
- Не является заявлением о production readiness.

## Рекомендуемая Windows-приёмка
1. Установить wheel DEV43.
2. Запустить `python -m uvicorn avic_core.ui.__main__:app --host 127.0.0.1 --port 8080`.
3. Проверить, что справа больше нет инспектора, а снизу есть dock.
4. Выбрать проект/станцию/сеть/контроллер/точку и проверить обновление свойств.
5. Перетащить верхнюю границу dock, скрыть и вернуть инспектор, обновить страницу и проверить сохранение состояния.
6. Проверить `···` и правый клик на типах объектов, двойной щелчок по родителю и конечному объекту.
