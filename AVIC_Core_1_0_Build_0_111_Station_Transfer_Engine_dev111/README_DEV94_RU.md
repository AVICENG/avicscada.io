# AVIC Core 1.0 — DEV94

## Основное изменение

DEV94 связывает сохранённые расписания Core с исполняемым FBD `LogicDocument`: добавлен блок `SCHEDULE` («Расписание станции»). Он читает расписание из единого `ScheduleService` на каждом проходе симуляции/циклического FBD runtime. Календарь не дублируется внутри FBD-блока.

## Защитные правила

- Только расписание той же станции; чужая станция отклоняется при сохранении и повторно проверяется во время вычисления.
- Поддерживаются BOOLEAN, NUMERIC, STRING и ENUM.
- Диагностика показывает источник, часовой пояс и время следующего изменения.
- Никаких записей в физические точки и никакой публикации runtime: DEV94 остаётся в режиме intent/simulation-only.

## Ограничение

FBD Studio документы (`FBDStudioService`) всё ещё хранятся как authoring-only и не компилируются в исполняемый `LogicDocument`. Эта интеграция относится к исполняемому FBD Core API; подключение Studio через compiler adapter — следующий отдельный этап.

Подробности: `docs/FBD_SCHEDULE_CORE_INTEGRATION_DEV94_RU.md`. Результаты проверок: `BUILD_TEST_LOG_DEV94_RU.md`.
