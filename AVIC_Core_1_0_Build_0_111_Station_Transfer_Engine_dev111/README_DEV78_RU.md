# AVIC Core DEV78 — FBD Visual Repair

Адресная визуальная и runtime-очистка FBD Studio на базе DEV77.

- Блок перемещается только за заголовок.
- Портовые подписи стоят непосредственно возле портов.
- Соединения и preview используют единый ортогональный маршрут с мягкими углами.
- Толщина линии стабильна при выделении.
- Значения симуляции отображаются только во время RUN; Stop очищает временные значения и состояние симулятора.

См. `BUILD_TEST_LOG_DEV78_RU.md` и `INSTALL_DEV78_RU.txt`.
