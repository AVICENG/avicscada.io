# AVIC Core 1.0 — DEV91

## FBD: переносимый проект и Schedule-блок

### Переносимый FBD-пакет
- Экспорт проекта в `.avicfbd.json` с manifest/schema version.
- SHA-256 контроль целостности содержимого проекта.
- Импорт нового пакета и прежнего JSON-формата редактора.
- Проверка страниц, уникальности ID страниц/блоков и ссылок между блоками до изменения текущего проекта.
- Подтверждение замены открытого проекта.
- Пакет включает страницы, блоки, связи, точки FBD и ссылки проекта, как в модели редактора.

### Schedule-блок
- Новый блок `SCHEDULE` с одним выходом.
- Выход может быть BOOL или числовым.
- Недельные интервалы по дням недели.
- Несколько интервалов на день, копирование понедельника на вторник–пятницу.
- Исключения по диапазону дат с приоритетом.
- Значение по умолчанию и часовой пояс IANA.
- Временное ручное переопределение через данные конфигурации блока.
- Поддержка интервалов через полночь.
- В локальной симуляции показывает рассчитанное значение и диагностические сведения.

## Ограничения DEV91
- Это экспортируемый JSON-пакет с манифестом и SHA-256, а не ZIP-контейнер.
- Импорт Trend `.TSET` напрямую не реализован: предоставленный файл начинается с сигнатуры `Standard Jet DB` и содержит бинарный формат базы данных; его структура/шифрование не декодированы.
- `ToolSET.zip` содержит в основном бинарные OCX/DLL/EXE, а не исходники редактора.
- Schedule-блок пока вычисляется в локальной симуляции редактора. Он ещё не связан с Core `ScheduleService`, циклическим FBD Runtime и PointRuntime; не пишет в физические устройства.
- Для реального исполнения и публикации значения потребуется следующий этап интеграции Core scheduler/runtime, качества, журналирования и безопасной команды.
- Не заявляется совместимость форматов `.TSET`/`.TSITE` на уровне импорта.
