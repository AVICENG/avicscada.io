# AVIC Core 1.0 — DEV112. Журнал сборки и проверок

## Назначение сборки

DEV112 устраняет ложное сообщение об ошибке Station Import при отказе EventService/AuditService после фиксации инженерных данных. Добавлены durable outbox, идемпотентная доставка и startup recovery.

## Изменения

- `StationTransferManager`: запись операции в `station_transfer_outbox` в той же транзакции `objects.sqlite3`, что и импортируемые сущности.
- После подтверждения auxiliary stores операция переходит в `JOURNAL_PENDING`.
- Событие и аудит используют детерминированные ID; повторная доставка безопасна.
- При сбое доставки `commit_import` возвращает импорт как зафиксированный с `journal_status=PENDING_RETRY`, а не сообщает об откате.
- `CoreApplication` при старте повторяет `JOURNAL_PENDING` и переводит оставшиеся `PREPARED` в `NEEDS_RECONCILIATION` без ложного подтверждения успеха.
- Добавлены fault-injection тесты отказа EventService и AuditService, включая восстановление после перезапуска Core.
- Добавлен API `list_recovery_operations(core)` для просмотра незавершённых операций администратором.
- Версия пакета: `1.0.0.dev112`.

## Известные ограничения

- Отдельные SQLite-файлы не образуют одну физическую транзакцию. Если процесс аварийно завершился до подтверждения auxiliary stores, операция будет отмечена `NEEDS_RECONCILIATION`; автоматическое объявление импорта успешным запрещено.
- DEV112 не реализует автоматическую компенсацию/ремонт частично завершённой операции после внезапного отключения питания.
- До успешной Windows acceptance сборка не считается проверенной или готовой к эксплуатации.
