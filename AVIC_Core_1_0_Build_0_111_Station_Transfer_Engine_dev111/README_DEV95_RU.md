# AVIC Core 1.0 — DEV95

DEV95 добавляет первый проверяемый компилятор FBD Studio → исполняемый FBD Core.

- Предварительная проверка до создания Core-стратегии.
- Перенос поддерживаемых блоков и связей.
- Сохранение нескольких страниц, их названий и порядка.
- Идемпотентность: повторная компиляция той же ревизии не создаёт дубликат.
- При ошибке компиляции выполняется очистка частично созданной стратегии.
- Исходный FBD Studio остаётся неизменным.
- Запуск стратегии, публикация и запись в оборудование отключены.

Поддерживаемые блоки и ограничения описаны в `docs/FBD_STUDIO_COMPILER_DEV95_RU.md`.
Результаты испытаний — `BUILD_TEST_LOG_DEV95_RU.md`.
