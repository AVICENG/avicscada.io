# AVIC Core — журнал сборки DEV186

Дата: 26.11.2026

## Изменения
- Добавлены Core FBD блоки KNOB и CONSTANT с числовым FLOAT-выходом.
- Добавлена проверка конечного числового значения при сохранении Core-графа.
- Добавлены KNOB и CONSTANT в FBD Studio compiler mapping и compile-preview validation.
- Реализована Core simulation семантика источников; KNOB можно переопределить в тестовой симуляции.
- Физические записи не включаются; compile не публикует стратегию в runtime.
- Linux compatibility matrix переведена на ручной запуск через workflow_dispatch, чтобы PR не запускал hosted Linux jobs автоматически.

## Регрессия
- Добавлен тест сквозного сценария KNOB + CONSTANT → ADD → FLOAT_OUTPUT.
- Добавлен отрицательный тест на нечисловое значение CONSTANT.
- Результаты тестов: ожидают выполнения CI после коммита DEV186. До получения фактического результата статус — НЕ ПОДТВЕРЖДЁН.

## Известные ограничения
- ANALOG_INPUT, EXTERNAL_SENSOR, COMBINATION, PID_LOOP, DELAY, LATCH, SWITCH и TIME пока не имеют полного подтверждённого Core execution path.
- DEV186 не является завершением FBD parity.
- Публикация и запись в физические контроллеры остаются отключёнными.

## Готовность
DEV186 — промежуточное инженерное изменение. Приёмка зависит от полного Windows CI и регрессионных тестов.
