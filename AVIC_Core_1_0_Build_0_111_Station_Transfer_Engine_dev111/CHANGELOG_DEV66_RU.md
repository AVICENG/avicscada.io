# CHANGELOG — DEV66

## Iso3D HVAC / ITP SVG Library

- Перерисованы 28 сохранённых SVG ID в объёмной изометрической стилистике.
- Добавлен 31 новый SVG asset; всего 59 самостоятельных SVG в 19 инженерных категориях.
- Добавлены разные типы вентиляторов, воздушные заслонки, фасонные секции воздуховодов, теплообменные секции, трубопроводные элементы, приборы и узлы ИТП.
- Для нагревателей/охладителей/теплообменников показаны отдельные красный и синий контуры.
- Добавлены rotor-группы вентиляторов как точки интеграции будущей Runtime-анимации.
- API каталога возвращает стиль `isometric-3d`, версию библиотеки 2.0.0 и 59 ресурсов.
- Увеличены размеры карточек предпросмотра и вставляемых символов в Graphics Editor.
- Обновлены version/theme release guard tests под DEV66.
