# AVIC Core 1.0 — DEV157

## Цель
Обеспечить полноценную историю неизменяемых публикаций Web Pages и дать инженеру визуальный rollback.

## Изменения
- История публикаций теперь сохраняет deep copy опубликованного layout вместе с frozen graphic snapshots и bindings.
- Rollback восстанавливает полный snapshot выбранной публикации и записывает отдельную версию с указанием rollback_of.
- В Page Builder добавлены список версий публикации и кнопка «Откатить» с подтверждением.
- Сквозной тест проверяет, что изменение исходной мнемосхемы после публикации не меняет опубликованную геометрию и bindings; затем проверяется откат к предыдущей версии.
- Версия пакета повышена до 1.0.0.dev157.

## Проверки
- Добавлены регрессионные assertions в test_dev109_fbd_graphics_page_flow.py.
- CI DEV157 ещё не запускался на момент создания этого журнала; сборка не считается принятой до полной матрицы Linux/Windows.

## Ограничения и безопасность
- Старые записи истории, созданные до DEV157, могли сохранить только обычный layout без frozen graphic snapshots; их откат может не восстановить графику и требует отдельной миграционной политики.
- В DEV156 Workbench остаётся local-only: require_local_operator не является пользовательской аутентификацией и RBAC. Полноценные учётные записи, роли, scopes и серверная авторизация маршрутов — обязательный следующий этап до customer deployment.
- PR остаётся draft и не объединяется без отдельного разрешения.
