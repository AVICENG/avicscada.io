AVIC Core 1.0 DEV87 — установка на Windows

1. Распаковать архив DEV87 в отдельную папку; DEV85/DEV86 не перезаписывать.
2. Открыть CMD в папке DEV87.
3. Выполнить: python --version
4. Выполнить: python -m pip install -e ".[dev]"
5. Выполнить: python -m pip check
6. Выполнить: python -m pytest -q
7. Запустить: python -m avic_core.ui --host 127.0.0.1 --port 8001 --data-dir .\avic_data
8. Открыть: http://127.0.0.1:8001

Проверка общей навигации:
- На главной странице нажать значок инженерного дерева на общей левой панели: должна открыться одна общая панель дерева, без второй центральной колонки старого навигатора.
- Правой кнопкой нажать `AVIC` в дереве: выбрать «Создать проект».
- Правой кнопкой нажать проект: создать станцию или переименовать проект.
- Правой кнопкой нажать станцию: переименовать станцию.
- Перейти в FBD: старой локальной копии дерева слева быть не должно; открыть общее дерево через левую панель. Справа должна остаться библиотека FBD-блоков.
- Проверить перетаскивание физической и FBD-точки из общего дерева на FBD-доску.

Это инженерная сборка для проверки интерфейса и контекстных операций. Она не предназначена для управления реальным объектом.
