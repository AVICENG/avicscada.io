# Журнал сборки AVIC Core DEV78

Дата: 22.11.2026

## Исправления
- Перетаскивание блока запускается только с верхней полосы заголовка; остальные части блока не являются drag-handle.
- Подписи входов и выходов выровнены рядом со своими портами: входы — слева направо от порта, выходы — справа налево к порту.
- Постоянные и временные соединения используют единый ортогональный маршрут с закруглёнными углами; толщина линии не меняется при выделении.
- Диагональный сегмент временного соединения удалён.
- При остановке симуляции очищаются входные/выходные временные значения, runtime state и PID diagnostics; исходные значения блоков восстанавливаются, Tracker и wire labels скрывают 0/1 и результаты вне активной симуляции.
