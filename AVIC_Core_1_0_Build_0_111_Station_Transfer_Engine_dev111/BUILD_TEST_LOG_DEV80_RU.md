# Журнал сборки AVIC Core DEV80

Дата: 22.11.2026  
База: DEV79 FBD Project Integration.  
Версия пакета: `1.0.0.dev80`.

## Реализовано

- Адаптивные вкладки страниц с переносом на несколько строк и прокруткой при большом числе страниц.
- Унифицированная обработка правой кнопки мыши для доски, блоков, портов, линий, вкладок, точек, FBD-проектов и инженерного дерева.
- Выпадающие верхние меню с командами для файла, проекта, редактирования, каталогов, стратегии, вида, инструментов, окна и справки.
- Вывод всех FBD-документов одной станции в основном дереве, включая страницы и FBD Points.
- Открытие конкретного FBD-документа/страницы и создание дополнительных проектов на станции.
- Принудительная фиксация ожидающего автосохранения перед переключением между документами.
- Печать текущей страницы и всех страниц открытого проекта из контекстных и верхних меню.

## Известные ограничения

- Печать полного проекта реализована через браузерный `window.print()` и требует проверки разбиения листов на принтере/PDF в Windows.
- При очень большом числе страниц вкладочная полоса становится прокручиваемой по вертикали; вкладки не обрезаются за правой границей.
- FBD-редактор сохраняет авторский граф; полноценная компиляция графа в исполняемую программу контроллера не входит в эту сборку.
- Перенос FBD Point из другого документа переключает редактор на документ-владелец точки; кросс-документальная ссылка как отдельный runtime-контракт пока не заявляется.

## Статус

DEV80 — интеграционная сборка для проверки удобства FBD Workbench. Она прошла целевые автоматические тесты и статическую проверку JavaScript, но не прошла визуальную браузерную приёмку Windows.
