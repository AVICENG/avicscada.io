AVIC Core 1.0 DEV86 — установка на Windows

1. Распаковать архив DEV86 в отдельную папку.
2. Открыть CMD в этой папке.
3. Проверить Python: python --version
4. Установить пакет: python -m pip install -e ".[dev]"
5. Проверить зависимости: python -m pip check
6. Запустить тесты: python -m pytest -q
7. Запустить Workbench:
   python -m avic_core.ui --host 127.0.0.1 --port 8001 --data-dir .\avic_data
8. Открыть http://127.0.0.1:8001

Для проверки FBD:
- открыть FBD / Logic;
- расположить один блок между выходным и входным блоками;
- создать соединение через выходной и входной контакты;
- проверить, что провод обходит препятствие ортогонально;
- щёлкнуть по проводу и проверить подсветку всей линии;
- навести указатель на контакты и проверить полные подсказки.

DEV86 требует визуальной приёмки на Windows. Не использовать как подтверждение готовности BACnet/Modbus Runtime или графических привязок.
