# AVIC Core 1.0 — DEV85

Сборка DEV85 продолжает DEV84 и добавляет общий инженерный tree drawer и единый Point Runtime.

## Основные файлы
- `CHANGELOG_DEV85_RU.md` — изменения.
- `BUILD_TEST_LOG_DEV85_RU.md` — фактические результаты тестов.
- `INSTALL_DEV85_RU.txt` — установка Windows.
- `docs/BUILD_085_RU.md` — описание сборки.
- `docs/POINT_RUNTIME_CONTRACT_DEV85_RU.md` — контракт Live Point Engine.

## Важно
DEV85 обеспечивает единый внутренний механизм значений и качества точек и показывает опубликованные значения в FBD. Это ещё не готовый сетевой polling BACnet/Modbus, не FBD execution runtime и не command/write path. См. ограничения в документации.
