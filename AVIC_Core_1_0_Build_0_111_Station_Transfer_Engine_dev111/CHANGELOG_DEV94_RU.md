# Изменения DEV94

- Добавлен исполняемый FBD-блок `SCHEDULE` в `FBDService.BLOCKS`.
- Блок ссылается на сохранённое расписание Core по ID.
- Проверяется принадлежность расписания станции FBD-стратегии.
- `FBDService.simulate()` получает актуальное значение через `ScheduleService.evaluate()`.
- В диагностику добавлены часовой пояс, локальное время, UTC-время, ревизия расписания, источник и ближайшее изменение.
- Сохранён запрет на запись в физические точки и публикацию runtime.
- Обновлена версия пакета и `api_version` до `1.0.0.dev94`.
