# Журнал сборки DEV45

Статус: подготовлена исправляющая сборка из DEV44.

## Реализовано
- API предварительного просмотра состава объектов при удалении проекта/станции.
- Каскадное удаление проекта/станции только после явного подтверждения.
- Удаление выполняется транзакционно; при ошибке изменения откатываются.
- Команды удаления проекта и станции добавлены в контекстное меню инженерного дерева.
- Аудит операции; полевое оборудование не затрагивается.

## Тесты
- Полный набор: 225 passed, 1 warning (среда тестирования не смогла записать pytest cache).
- Регрессионные тесты удаления проекта/станции включены.
- Ручной браузерный тест на Windows ещё не выполнен.

## Ограничения
- Единый canvas для Web Pages и Graphics пока не реализован.
- Не все типы узлов получили полный набор контекстных операций.
- Drag-and-drop, multi-select, undo/redo и единая модель документа между визуальным редактором, кодом и графикой не заявляются как готовые.
