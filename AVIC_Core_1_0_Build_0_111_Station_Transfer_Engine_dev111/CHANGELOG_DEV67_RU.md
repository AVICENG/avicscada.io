# AVIC Core 1.0 — DEV67

## Модульная ПВУ в Graphics Workbench

- Добавлены 7 самостоятельных SVG-секций одного типоразмера и общей геометрии стыков:
  1. заслонка наружного воздуха;
  2. секция фильтров;
  3. пластинчатый рекуператор;
  4. водяной нагреватель;
  5. водяной охладитель;
  6. секция приточного вентилятора;
  7. открытый выходной короб после вентилятора.
- SVG используют общий viewBox `35 62 317 185`, общую оболочку, одинаковые стыковочные фланцы и одинаковую перспективу.
- Выходной короб намеренно выполнен без глухой боковой облицовки; внутренний воздушный канал остаётся видимым.
- В SVG добавлены CSS-состояния заслонки, вентилятора и потока воздуха.
- В Graphics Workbench включено встраивание доверенных модульных SVG в лист, привязка анимации к Boolean/value/feedback-точкам и обновление снимка точек раз в 1,5 секунды.
- Поток воздуха визуализируется, когда одновременно открыта входная заслонка и работает вентилятор.
- Добавлен локальный режим просмотра ВКЛ/ВЫКЛ без отправки команд в контроллер.
- Добавлен API создания демонстрационной ПВУ из семи секций.
- Манифест Workbench сообщает о семи модульных секциях и поддержке бинарной SVG-анимации.
- Сохранены все существовавшие 59 SVG ID; общий каталог содержит 66 символов.

## Ограничения

- DEV67 не включает запись команд в физическое оборудование.
- Автоматическая анимация читает point snapshot, отдаваемый Core. Для фактического движения на объекте драйвер/Runtime должен обновлять значение и качество точки.
- Для анимации требуется качество точки `GOOD`; `BAD`, `UNCERTAIN`, `COMM_LOST` не трактуются как включённое состояние.
- Локальная кнопка предпросмотра не является симуляцией контроллера и не выполняет полевые операции.
- Независимые группы нескольких ПВУ на одном листе пока не выделяются отдельным group ID; демонстрационная схема рассчитана на одну установку на документ.
- Браузерная визуальная приёмка в среде сборки не проведена: запуск Chromium блокируется системной политикой. Нужна проверка на Windows у пользователя.
