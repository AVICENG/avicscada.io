# AVIC Core 1.0 — DEV109

## Назначение

DEV109 продолжает DEV108 и усиливает сквозной инженерный сценарий создания мнемосхемы и страницы оператора на основе FBD-точек.

## Изменения

- Добавлен сквозной интеграционный тест `test_dev109_fbd_graphics_page_flow.py`.
- Тест создаёт проект и станцию, сохраняет FBD-граф, компилирует его, регистрирует виртуальную FBD-точку и запускает Core FBD Runtime.
- Проверяется появление той же точки в инженерном дереве и каталоге точек Graphics Workbench с тем же стабильным Core ID.
- Проверяется сохранение двух независимых привязок одной точки к вентилятору: `feedback → animation` и `quality → status`.
- Проверяются повторное открытие мнемосхемы, назначение её странице, редактирование макета, публикация и операторский просмотр.
- Проверяется сохранность страницы, мнемосхемы и привязок после закрытия и повторного создания приложения с тем же `data_dir`.
- Версия приложения и пакета повышена до `1.0.0.dev109`.

## Важное уточнение

Тест проверяет API и UI-контракты, но не является полноценным браузерным E2E с реальным drag мышью. Фактическое выполнение перетаскивания в браузере и визуальная проверка остаются отдельным этапом приемки. Команды физическим BACnet/Modbus-устройствам не отправляются; управление остаётся отключённым/симуляционным.
