# AVIC Core 1.0 — DEV96

DEV96 расширяет исполняемый FBD Core и компилятор FBD Studio → Core четырьмя стандартными блоками:

- `SUB` — вычитание A − B;
- `MUL` — умножение A × B;
- `DIV` — деление A / B с явным запретом деления на ноль;
- `SELECT` — выбор числового входа A или B по булевому входу SEL (TRUE выбирает A, FALSE — B).

Новые блоки доступны в контракте Core, участвуют в типизированной проверке связей, рассчитываются в симуляции и проходят компиляцию из FBD Studio.

DEV96 не включает PID, гистерезис, задержки, защёлки, переключатели, SCALE Studio, межстраничные Connective или публикацию FBD Points. Исполняемая стратегия по-прежнему не запускается и не пишет в физические контроллеры автоматически.
