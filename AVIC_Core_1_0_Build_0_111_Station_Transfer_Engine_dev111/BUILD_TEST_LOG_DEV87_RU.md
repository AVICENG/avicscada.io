# Журнал сборки и тестирования DEV87

## База
- Источник: `AVIC_Core_1_0_Build_0_86_FBD_Wiring_Block_Layout_dev86.zip`.
- DEV87 создан в отдельном каталоге; DEV86 не изменён.
- Версия пакета: `1.0.0.dev87`.

## Реализовано
- Убрана вторая навигационная колонка Home; центральная рабочая область занимает освободившееся место.
- Убрана локальная панель дерева FBD Studio; FBD использует общий выдвижной Engineering Tree.
- Общая панель сохраняет дерево проектов, станций, сетей, каналов, устройств, физических точек, FBD-проектов, страниц и FBD-точек.
- Контекстное меню по правому щелчку на корневом узле AVIC создаёт проект.
- Контекстное меню проекта создаёт станцию и переименовывает проект.
- Контекстное меню станции переименовывает станцию.
- Создание и переименование выполняются через существующие API и ProjectStationService; для PATCH используется актуальная версия объекта.
- Сохранены drag payload `point` и `fbd-point`.

## Проверки
- `tests/test_dev87_shared_tree_context.py`: проверка отсутствия дубля Home/FBD и операций API.
- `tests/test_dev85_shared_navigation.py`: пройдены.
- `tests/test_dev85_point_runtime.py`: пройдены.
- `tests/test_fbd_wire_routing_dev86.py`: пройдены.
- Итого целевой набор: **15 passed**.
- `node --check` для встроенного скрипта общей панели: успешно.
- `python -m compileall -q avic_core tests`: успешно.
- GET `/`, `/logic`, `/graphics`, `/pages`: HTTP 200.
- Wheel и ZIP собираются отдельно после этих проверок.

## Ограничения
- Полный набор ~31 тыс. тестов DEV87 не запускался в этой среде; DEV85 полный набор на Windows пользователя прошёл: 31 041 passed, 1 skipped.
- Нет визуальной браузерной приёмки DEV87 на Windows.
- Контекстные команды пока реализованы для корня AVIC, проекта и станции. Для сетей/каналов/устройств/точек нужна отдельная матрица безопасных команд.
- Собственные рабочие панели Graphics и Web Pages пока не сведены полностью к одному универсальному дереву.
- Нет реального BACnet/Modbus polling/write path, полного FBD Runtime и FBD-to-Graphics live binding.

## Статус
DEV87 — целевая доработка общей навигации и контекстного управления Project/Station. Требует Windows UI acceptance; не использовать для управления реальным оборудованием.
