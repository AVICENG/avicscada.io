AVIC Core 1.0 — DEV48 Scheduler Editor Operations

1. Распакуйте архив в отдельную папку, не поверх предыдущей сборки.
2. Откройте CMD в папке проекта.
3. Создайте окружение:
   py -3 -m venv .venv
4. Активируйте:
   .venv\Scripts\activate
5. Установите сборку:
   python -m pip install --upgrade pip
   python -m pip install -e ".[dev]"
6. Запустите тесты:
   python -m pytest -q
7. Запустите Workbench:
   python -m avic_core.ui
8. Откройте адрес, который покажет сервер (обычно http://127.0.0.1:8000).

Проверка Scheduler:
- Создайте проект и станцию в инженерном дереве.
- Откройте «Расписания».
- Создайте BOOLEAN расписание.
- Добавьте недельное событие в понедельник.
- Проверьте 24-часовую сетку.
- Выберите понедельник как источник и выполните «Применить Пн–Пт».
- Перезагрузите страницу и проверьте, что интервалы сохранены.

ВАЖНО: Scheduler DEV48 не управляет физическими выходами. Он сохраняет конфигурацию и вычисляет schedule intent. Не используйте сборку для управления реальным оборудованием.
