# AVIC Core 1.0 — DEV42: постоянная панель навигации

## Реализовано в этой сборке
- Добавлена постоянная вертикальная панель основных разделов слева (иконки с подсказками).
- Основные разделы открываются непосредственно с панели; активный раздел подсвечивается.
- Инженерное дерево остаётся отдельной панелью и сворачивается независимо от основной навигации.
- Состояние видимости инженерного дерева и инспектора сохраняется в localStorage браузера.
- Ширина инженерного дерева уменьшена с 330 до 270 px; при скрытии дерева остаётся только узкая панель навигации.
- Панель навигации сохраняется при переключении рабочих разделов.
- Такая же постоянная панель добавлена непосредственно в отдельный Graphics Workbench; навигация не исчезает при переходе в редактор мнемосхем.
- Переходы из Graphics Workbench возвращают в нужный раздел главной оболочки через параметр `?page=`.

## Проверки
- `python -m compileall -q avic_core` — успешно.
- `python -m pytest -q` — 215 passed.
- `node --check` для встроенного JavaScript в `index.html` и `graphics.html` — успешно.

## Ограничения и честный статус
- Эта сборка меняет оболочку и навигацию. Она не завершает графический редактор мнемосхем или FBD.
- Контекстные меню дерева и полный набор операций над объектами требуют отдельной проверки и доработки; не считать их принятыми только по результатам общих pytest.
- Перед приёмкой требуется визуальная проверка на Windows: переходы по разделам, скрытие/показ дерева, сохранение состояния после обновления страницы, работа в Graphics.
- Не является заявлением о готовности к промышленной эксплуатации.
