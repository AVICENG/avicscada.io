# Журнал DEV149 — исправление проверки Windows ACL

## Изменения
- Исправлена проверка защищённого ACL каталога installation identity на Windows.
- Проверка разрешает SDDL aliases в числовые SID через Windows SecurityIdentifier.
- Устранено ошибочное отождествление SDDL alias LA (локальная встроенная учётная запись Administrator, RID 500) с широким principal Local Account (S-1-5-113).
- Проверяются защищённость DACL от наследования, явные ACE FullControl для текущего пользователя, SYSTEM и Administrators, наследование на дочерние объекты и отсутствие широкого S-1-5-113.
- Код формирования ACL в HostIdentity не ослаблялся.

## Проверки
- Исправление адресует фактическое падение Windows CI DEV148: runner возвращал LA вместо числового SID пользователя с RID 500.
- Новый Windows CI должен подтвердить корректность преобразования alias в SID.
- Полный CI DEV149 до завершения всех jobs не считается зелёным.

## Ограничения
- Реальное поведение ACL должно быть подтверждено новым Windows CI job.
- Изменение теста не заменяет отдельную проверку ACL на пользовательской Windows-машине.
