# Журнал испытаний — AVIC Core DEV97

Дата: 23.11.2026
Версия пакета: `1.0.0.dev97`

## Реализовано

- Core FBD SCALE: линейное масштабирование; проверка ненулевого входного диапазона; опциональное ограничение результата с поддержкой обратного выходного диапазона.
- Core FBD HYSTERESIS: два порога LOW/HIGH, удержание состояния в промежутке, начальное состояние.
- FBDExecutionService: хранение состояния HYSTERESIS между тиками; сброс состояния на новом поколении запуска.
- FBD Studio → Core: компиляция SCALE и HYSTERESIS; диапазоны SCALE разворачиваются в четыре FLOAT_INPUT Core; неподключённые LOW/HIGH HYSTERESIS заполняются из параметров Studio; явные пользовательские связи имеют приоритет.
- Ошибка деления на ноль теперь согласована с Core и в локальном предпросмотре FBD.

## Неполные / внешние проверки

- Полный `python -m pytest -q` был запущен, но не завершился за 300 секунд: прогресс остановился примерно на 41%. Это не считается полным проходом и не является подтверждением оставшейся части тестов.
- `pip check` сообщает об уже известном конфликте глобального окружения: установленный `moviepy 2.2.1` требует `Pillow <12`, а в окружении находится `Pillow 12.3.0`. Это не зависимость AVIC Core и не связано с изменениями DEV97.
- Windows-приёмка на Python пользователя и визуальная проверка в браузере не выполнялись.
- Совпадение граничных правил SCALE/HYSTERESIS с конкретной моделью/версией Trend SET требует отдельной сверки с документацией и испытаниями. Нельзя считать это подтверждением полного паритета с Trend.

## Безопасность / эксплуатационные ограничения

- DEV97 по-прежнему работает в режиме FBD simulation/runtime без публикации стратегии в Point Runtime и без записи в физические контроллеры.
- Состояние HYSTERESIS хранится в памяти процесса, не переживает перезапуск процесса и инициализируется заново из `initial_state` при новом запуске стратегии.
- Ошибка расчёта не фиксирует частично обновлённое состояние блока.
