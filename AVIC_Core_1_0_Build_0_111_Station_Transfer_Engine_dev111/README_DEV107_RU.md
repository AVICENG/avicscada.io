# AVIC Core 1.0 — DEV107

DEV107 продолжает DEV106. Исправлен переход из общего инженерного дерева в Web Application Page Builder: выбор корневого узла «Репозиторий» станции теперь открывает раздел Web Application, а не Graphics Workbench. Раздел Graphics остаётся отдельным рабочим местом и открывается по своему узлу.

## Сценарий работы со страницей

1. Создайте проект и станцию в инженерном дереве.
2. Раскройте узел станции и нажмите «Репозиторий» — откроется Web Application Page Builder.
3. Создайте сайт, затем страницу (при необходимости создайте папку и выберите её перед созданием страницы).
4. Добавьте элементы из библиотеки: заголовок, надпись, изображение, значение Core Point, мнемосхему, разделитель или карточку.
5. Перетащите элементы на холст, настройте координаты и размеры справа. Для значения выберите точку по стабильному Core ID.
6. Для изображения загрузите файл в ресурсы станции. Для мнемосхемы сначала назначьте документ странице.
7. Сохраните страницу, проверьте её в предпросмотре и нажмите «Опубликовать».
8. Откройте опубликованную страницу из панели публикации.

## Важно

- `/pages` не возвращает старый редактор `pages.html`; legacy editor остаётся отключённым.
- `/repository?section=WebApplication` — визуальный редактор Web Application.
- `/repository?section=GraphicsRepository` и `/graphics` — отдельный Graphics Workbench.
- Компонент «Кнопка» пока декоративный. DEV106 Command Manager остаётся отдельным SIMULATION_ONLY API; операторская кнопка не подключена к физическому управлению.
- Публикация доступна локальному оператору Workbench. Полноценные пользовательские сессии, серверный RBAC и MFA ещё не реализованы.
- Значения Point Runtime на опубликованной странице обновляются read-only; команда с экрана страницы не отправляется.
