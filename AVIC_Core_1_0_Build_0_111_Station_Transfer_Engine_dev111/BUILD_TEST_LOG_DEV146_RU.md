# Журнал сборки DEV146 — масштабирование FBD Runtime

## Изменения
- `avic_core/runtime/fbd_execution.py`: общий scheduler и ограниченный пул рабочих потоков вместо потока на каждую стратегию.
- `avic_core/logic_fbd.py`: топологическая сортировка Кана; убрано повторное сканирование множества ожидающих блоков.
- Добавлены тесты `tests/test_fbd_bounded_scheduler_dev146.py` для 12 параллельных стратегий, bounded workers, пропуска просроченных циклов, изоляции отказа и цепочки 1000 блоков.

## Проверки
- CI запускается после фиксации DEV146. До завершения матрицы тесты не объявляются пройденными.
- Локальная проверка Windows в этой итерации не выполнялась.

## Ограничения
- FBD не пишет в физическое оборудование.
- Планировщик резервных копий, Station Clone, Deployment Manager и Provisioning Manager остаются отдельными следующими задачами.
- Не заявляется подтверждённая производительность на промышленных масштабах без нагрузочного теста.
