# Изменения DEV65

## SVG Import
- Добавлен безопасный импорт пользовательских SVG-файлов до 1 МБ.
- Добавлена станционная SQLite-библиотека пользовательских символов.
- Добавлен каталог, поиск, фильтрация, preview, вставка на Graphics Canvas и защита удаления используемых символов.
- Добавлена проверка XML namespace, локальных ссылок, CSS-свойств, DTD/ENTITY и активных элементов.
- Добавлен аудит импорта и удаления SVG с SHA-256.

## Web Pages Authoring
- Расширен визуальный редактор страниц восьмью типами компонентов.
- Добавлен инспектор свойств, drag-move, дублирование, перестановка и удаление компонентов.
- Добавлены диалоги создания, переименования и перемещения узлов вместо браузерных prompt для операций с деревом.
- Добавлены API и service для изменения порядка соседних узлов.
- Устранена коллизия URL slug между папкой и страницей у одного родителя.
- Удаление привязки мнемосхемы теперь удаляет связанные visual blocks.
- Уточнены проверки layout и запрет небезопасных/protocol-relative URL.
- Разрешён горизонтальный разделитель высотой от 1 px.
- Исправлен pointer capture при перетаскивании компонентов.

## Версия и пакет
- Версия проекта изменена на `1.0.0.dev65`.
- Обновлены версии API/манифеста и тема интерфейсных entrypoints.
- DEV64 сохранён как отдельная база.
