## Обнаруженные и исправленные дефекты

1. `init()` обращался к `welcomeWizard`, которого нет в DOM; ошибка останавливала дальнейшую инициализацию. Добавлена проверка наличия элемента.
2. Элемент Palette с `hidden` сохранял `display:flex` из класса и не скрывался при фильтрации. Добавлено правило `[hidden] { display:none !important }` для элементов Palette.
3. История навигации не включала начальную страницу. Начальная страница добавлена первым элементом истории, поэтому кнопка «Назад» активируется после первого перехода.
4. Locator Bar заменил старую видимую строку breadcrumb, но существующий render() обновлял `#crumb`. Добавлен скрытый совместимый узел, чтобы сохранить старый контракт UI без ошибки.

## Ограничения

- Chromium smoke запускался на локальном HTML DOM harness с имитацией fetch, а не на пользовательском Windows браузере.
- Полный pytest пройден в Linux-среде сборки. Нужен повторный запуск на Windows пользователя.
- Не выполнены реальные проверки BACnet/Modbus, драйверов, физического оборудования, backup/restore и RBAC.
- 50 000 тестов не заявляются: в DEV51 фактически собрано 1424 автоматических теста. Следующий прирост покрытия должен быть предметным, по матрице поведения Workbench и инженерных процессов.
