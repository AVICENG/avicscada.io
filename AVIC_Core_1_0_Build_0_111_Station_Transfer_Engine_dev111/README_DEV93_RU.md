# AVIC Core 1.0 — DEV93

## Назначение сборки

DEV93 улучшает понятность инженерного интерфейса для работы с сетями и временем. Основной принцип: объяснять сетевые параметры простым русским языком, показывать безопасный порядок действий и не требовать от инженера угадывать неизвестные настройки.

## Изменения

- Переработана страница «Сети и подключение оборудования»: пошаговый маршрут, словарь IP/подсеть/шлюз/маршрутизатор/шлюз протоколов/DNS/порт/Ping.
- Добавлены понятные объяснения, почему Ping не подтверждает работу BACnet/Modbus.
- Добавлено объяснение связи между разными подсетями и особенностей BACnet/IP через маршрутизируемые сети.
- Переработана страница «Время и синхронизация станций»: выбор станции из списка, русские названия часовых поясов, пример Москвы и Владивостока, понятное объяснение UTC и местного времени.
- Скрыты дополнительные параметры разрешения синхронизации времени полевых контроллеров под отдельный раскрываемый блок с предупреждением.
- Улучшены подсказки ручного сетевого плана: IP будущего компьютера, адрес сети с маской, маршрутизатор и DNS.
- Добавлено русскоязычное руководство по сетям и времени.

## Границы реализации

DEV93 не реализует межстанционное соединение, не перенастраивает Windows Time Service, не выполняет реальную NTP-проверку и не отправляет время в полевые контроллеры. Это явно указано в интерфейсе и документации.

## Проверка

Результаты тестов и проверок находятся в `BUILD_TEST_LOG_DEV93_RU.md`.
- При создании нового расписания часовой пояс автоматически берётся из Time Manager выбранной станции; ручной ввод часового пояса в редакторе расписания убран.
