# AVIC Core 1.0 — DEV156

## Цель
Исправить Windows-совместимость восстановления системной резервной копии.

## Причина
`sqlite3.Connection` как контекстный менеджер управляет транзакцией, но не закрывает соединение при выходе из `with`. Во время restore открытая SQLite-база оставалась заблокированной; Windows отклоняла `os.replace(stage, target)` и затем не позволяла удалить временный каталог.

## Изменения
- Соединение для `PRAGMA integrity_check` теперь закрывается в `finally` до атомарного перемещения восстановленного каталога.
- Версия пакета повышена до 1.0.0.dev156.

## Проверки
- Основание: реальный Windows CI DEV154, тест `test_encrypted_system_backup_inspect_and_restore`, 31 260 passed / 1 failed / 1 skipped. Ошибка подтверждена стеком `PermissionError [WinError 5]` на `os.replace` и последующей блокировкой `.config-locks.sqlite3`.
- Повторное выполнение полного CI для DEV156 ожидается; до завершения Windows/Linux матрицы исправление не считается принятым.
