# AVIC Core 1.0 — DEV87

DEV87 продолжает DEV86. Цель сборки — убрать дублирующие навигационные деревья на главной странице и в FBD Studio и сделать контекстное управление проектами/станциями доступным из общего инженерного дерева.

## Что изменено
- Home: центральная старая колонка навигации скрыта; используется общая выдвижная панель.
- FBD Studio: локальная копия инженерного дерева скрыта; дерево открывается через общий левый rail. Правая библиотека FBD-блоков остаётся на месте.
- Правый щелчок по корню `AVIC`: создать проект.
- Правый щелчок по проекту: создать станцию или изменить название проекта.
- Правый щелчок по станции: изменить название станции.
- Перетаскивание физических и FBD-точек из общей панели сохранено.

## Что не заявляется готовым
- Контекстные команды для сети, протокола, устройства и точки ещё не завершены.
- В Graphics и Web Pages остаются собственные рабочие панели редакторов; это не считается доказательством полного объединения всех внутренних деревьев.
- Не добавлены реальные BACnet/Modbus polling и запись, полный FBD Runtime или передача FBD-значений на мнемосхемы.
- Браузерная визуальная приёмка на Windows должна быть выполнена пользователем.
