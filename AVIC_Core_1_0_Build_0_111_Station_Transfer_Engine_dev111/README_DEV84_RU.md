# AVIC Core 1.0 — DEV84

DEV84 продолжает DEV83. Основная задача сборки — привести навигацию рабочих пространств к общей левой панели и укрепить протокол-независимую привязку физических точек оборудования к FBD.

## Что изменено

1. Общая левая навигация используется в Home, FBD, Graphics и Web Pages.
2. В FBD-дереве остаётся инженерная иерархия проекта, станции, сети, протокольного канала, устройства и точек. Физические точки оборудования можно перетащить на FBD-доску.
3. В каталоге точек доступны метаданные источника: протокол, устройство, адрес, производитель/модель, native identity и тип объекта.
4. FBD хранит ссылку на исходную точку в контракте `avic.external-point-binding`; точка не дублируется.
5. Числа на FBD отображаются с двумя знаками после запятой по умолчанию, без изменения внутреннего значения.

## Установка

```powershell
python -m pip install -e ".[dev]"
python -m pip check
python -m avic_core --data-dir .\avic_data init
python -m avic_core.ui --host 127.0.0.1 --port 8001 --data-dir .\avic_data
```

Откройте `http://127.0.0.1:8001/`. Переходы Home / FBD / Graphics / Web Pages выполняются через общую левую навигацию.

## Работа с точками в FBD

1. Создайте проект и станцию.
2. Выполните Discovery/импорт поддерживаемого устройства в Network Manager.
3. В FBD откройте ветку `Сети и устройства`, затем протокольный канал, устройство и его точки.
4. Перетащите физическую точку на FBD-доску или непосредственно на совместимый порт.
5. FBD сохраняет ссылку на исходную точку и её протокольную идентичность.

## Ограничения DEV84

- Это не завершённый Live Point Engine: автоматический фоновый опрос и подписки на значения ещё не реализованы.
- DEV84 не включает FBD Runtime, исполняющий схему в реальном времени с физическим оборудованием.
- Текущий BACnet опрос остаётся отдельной операцией чтения, а Modbus TCP — разовым чтением регистров; полноценный импорт/циклический опрос Modbus-точек ещё не завершён.
- Запись команд в контроллеры отключена. FBD external binding помечается `readOnly=true`.
- BACnet Server, публикация FBD-точек как BACnet-объектов и COV не реализованы в этой сборке.
- Общая левая полоса навигации едина; внутренние контекстные деревья редакторов пока сохраняют специализированные представления. Полное выделение общего Engineering Tree в отдельный переиспользуемый компонент остаётся следующим архитектурным этапом.
- Визуальная приёмка в Windows-браузере не выполнялась.
