AVIC Core DEV78 — установка на Windows

1. Распаковать архив в отдельную новую папку. Не устанавливать поверх DEV77.
2. Открыть CMD в папке проекта.
3. Выполнить:
   python -m venv .venv
   .venv\Scripts\activate
   python -m pip install -e ".[dev]"
   python -m pip check
   python -m avic_core.ui --host 127.0.0.1 --port 8001 --data-dir .\data
4. Открыть http://127.0.0.1:8001/logic

DEV78 исправляет геометрию портов и соединений, а также очистку временных
значений симуляции. Это не подтверждение полного браузерного acceptance.
Если слева дерево не загружается, проверить сообщение в панели дерева и
ответ /api/engineering/tree; прислать точный текст ошибки.
