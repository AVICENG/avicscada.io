# Журнал сборки и испытаний DEV89

## Изменения
1. Усилена проверка типов входных значений симуляции.
2. Добавлена диагностика вычисления по каждому FBD-блоку.
3. Добавлены сведения о происхождении данных `POINT_INPUT` из PointRuntime: point_id, источник, качество, timestamp, единица измерения и revision.
4. Запрещено переопределять `POINT_INPUT` через аргумент симуляции: это не позволяет подменить физический сигнал и обойти контроль качества.
5. Сохранены запреты на запись в полевые точки и публикацию результатов в PointRuntime.

## Результаты проверок в текущей Linux-среде
- Целевой набор DEV89 + PointRuntime + FBD binding + FBD regression: **12 542 passed**.
- `python -m compileall -q avic_core tests`: успешно.
- `python -m avic_core --help`: успешно.
- Wheel `avic_core-1.0.0.dev89-py3-none-any.whl`: собран успешно.
- Полный `python -m pytest -q`: запущен, но выполнение было остановлено лимитом времени 300 секунд на отметке около 46%; это не является ни успешным, ни проваленным завершением полного набора.
- `python -m pip check`: обнаружен конфликт глобального окружения `moviepy 2.2.1` требует `pillow<12.0`, установлена `pillow 12.3.0`. Конфликт не был создан изменениями DEV89; сборка wheel от него не зависит.

## Не проверено / ограничения
- Полный регрессионный набор DEV85 (31 041 passed в Windows-приёмке DEV85) для DEV89 не подтверждён.
- Windows-приёмка DEV89 не выполнялась.
- Браузерная визуальная приёмка не выполнялась.
- Реальные BACnet/Modbus устройства не подключались.
- Это разовая симуляция по запросу, не циклический runtime.
- FBD Studio authoring-граф (отдельный FBD Studio формат) этим изменением не компилируется и не исполняется.
- Нет записи в OUTPUT-точки, публикации FBD-выходов, расписания исполнения или управления оборудованием.
