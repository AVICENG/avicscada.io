AVIC Core 1.0 DEV93 — установка и проверка (Windows)

1. Распакуйте ZIP в отдельную папку. Не распаковывайте поверх DEV85, DEV91 или DEV92.
2. Откройте CMD в папке проекта.
3. Выполните по очереди:

   python -m pip install -e ".[dev]"
   python -m pip check
   python -m pytest -q
   python -m compileall -q avic_core
   python -m avic_core --help

4. Запустите AVIC тем же способом, которым запускали предыдущую сборку.
5. Откройте раздел «Сети и топология»: проверьте русские подсказки и пошаговое объяснение.
6. Откройте «Время и синхронизация»: выберите станцию, задайте часовой пояс по месту объекта, нажмите «Сохранить часовой пояс», затем «Показать текущее время станции».
7. Откройте «Расписания»: при выборе станции поле часового пояса должно заполняться из Time Manager и быть только для чтения.

Важно:
- DEV93 не меняет сетевые параметры Windows или IP полевых устройств.
- Сохранение NTP-политики в Core пока не настраивает Windows Time Service.
- Разрешение синхронизации времени контроллера сохраняется, но фактическая передача времени в контроллер не выполняется.
- Полная регрессия репозитория и Windows-приёмка в среде сборки не выполнялись; проверку нужно выполнить на вашем компьютере.
