# DEV79 — изменения

- Добавлено отображение сохранённых FBD Studio проектов, страниц и FBD Points в основном инженерном дереве AVIC под соответствующей станцией.
- Добавлены создание FBD-проекта из дерева и контекстные действия открытия/печати проекта и страницы/создания страницы.
- Добавлена загрузка конкретного FBD-документа и страницы по URL-параметрам; добавлен запуск печати после загрузки.
- Правая панель FBD Studio теперь предназначена только для библиотеки доступных FBD-блоков с поиском и категориями.
- Добавлены контекстные команды для проекта, страниц, блоков, портов, линий и пустого поля доски.
- Добавлен drag-and-drop FBD Points в виде входных модулей со ссылкой на исходную точку; Core Points остаются перетаскиваемыми из инженерного дерева редактора.
