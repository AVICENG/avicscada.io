# AVIC FBD Studio — DEV184: компиляция межстраничных Connective

## Цель

Связать визуальные Connective / To Connective в FBD Studio с исполняемой моделью Core FBD. Ранее редактор сохранял `references`, но `compile_preview` запрещал любую непустую коллекцию ссылок.

## Реализовано в DEV184

- Серверная проверка структуры Page Reference: страницы, source block/output, proxy block, тип сигнала, уникальность идентификаторов и endpoint.
- Проверка соответствия proxy и исходного output; To Connective остаётся навигационным маркером.
- Компилятор исключает CONNECTIVE и TO_CONNECTIVE из вычислительных узлов.
- Локальные ссылки от выхода CONNECTIVE раскрываются в Core `StrategyConnective` от реального исходного блока к фактическому входу-потребителю.
- Межстраничные связи проходят общую проверку типов, занятости входов и циклов после раскрытия aliases.
- Core Runtime получает штатные `StrategyConnective`; симуляция использует единый граф независимо от открытой страницы.
- Компиляция по-прежнему создаёт отдельный Core FBD-документ; запись в полевое оборудование не включается.
- Повторная компиляция той же ревизии учитывает и обычные links, и Core connectives.

## Проверки DEV184

Добавлены регрессионные сценарии:
- компиляция двухстраничной схемы с Connective;
- отсутствие CONNECTIVE/TO_CONNECTIVE в исполняемом списке узлов;
- выполнение сигнала на второй странице;
- отказ при отсутствующем proxy;
- отказ при несовместимом типе сигнала.

## Границы DEV184

- DEV184 не реализует безопасное дублирование страницы с внешними references. Текущий UI `copyActivePage` требует отдельного исправления, чтобы новые UID и references создавались согласованно.
- Диалог анализа последствий при удалении страницы/Connective также остаётся отдельной задачей.
- Это не включает полевые записи: FBD Runtime остаётся read-only относительно физических устройств.
- Результат полного CI будет внесён после завершения Windows self-hosted запуска.
