- Записываются событие и audit-запись с перечнем стратегий и причиной блокировки.

- Добавлена архитектурная спецификация границы Workbench / Supervisor / Field Runtime, команд Stop/Start/Restart/Kill, watchdog, TTL/epoch и безопасного восстановления.

## Ограничения

DEV177 не отделяет FBDExecutionService в отдельный процесс. Он защищает только от штатного Core.close(). Принудительное завершение процесса ОС или отказ питания по-прежнему останавливает локальный FBD scheduler. Для промышленной автономности необходим отдельный Field Runtime service и отказные испытания.

## Статус

**Архитектурный защитный этап, не промышленная готовность.** Следующий этап — перенос scheduler и владельца стратегий в отдельный Field Runtime процесс.
