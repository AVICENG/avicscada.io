# AVIC Core — DEV246: интеграция каталога драйверов в Engineering Workbench

Дата: 27.11.2026

## Цель

Сделать фактическое состояние протокольных драйверов видимым инженеру в интерфейсе SCADA и не путать наличие профиля/транспорта с полной промышленной готовностью.

## Изменения

- В Engineering Workbench → «Драйверы» добавлен единый каталог всех 16 встроенных протоколов.
- Для каждого протокола отображаются lifecycle, read/discovery/write capabilities, зарегистрирован ли runtime factory, поддерживаемые движки и доступность зарегистрированных Rust/C worker.
- Добавлена цветовая индикация:
  - 🟢 Полностью принято — только после тестов и аппаратной приёмки; автоматически не присваивается.
  - 🟡 Runtime factory уже подключён к Driver Manager, но есть ограничения/не завершена приёмка.
  - 🔴 Runtime factory отсутствует или драйвер запланирован.
- Для всех записей явно показано, что field write запрещён.
- Каталог загружается из существующего API `GET /api/drivers/catalog`, не дублируя список протоколов на стороне браузера.
- Добавлен API regression test на 16 записей, четыре текущих Python runtime factory (Modbus/BACnet/KNX/MQTT), отсутствие runtime у S7 и OPC UA и запрет write capability.
