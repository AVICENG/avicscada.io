# Engineering Draft / Save Manager — DEV163

## Назначение

Общий слой долговременных черновиков инженерных редакторов. Черновик не равен сохранённой конфигурации станции и не равен опубликованной/применённой конфигурации.

Поддерживаемые типы редакторов на уровне хранилища: `fbd`, `graphics`, `web-page`.

## Правила

1. Переход между разделами не ожидает завершения сетевого сохранения и не блокируется.
2. Черновик хранится отдельно от основной конфигурации.
3. Серверная запись версионируется через compare-and-swap (`expected_draft_revision`); конфликт не перезаписывает более новую версию.
4. В черновике сохраняются `base_revision` исходного объекта и отдельная `draft_revision`.
5. Удаление черновика требует точной текущей ревизии.
6. Содержимое ограничено 5 MiB и должно быть конечным JSON-объектом.
7. Черновик не публикуется, не запускается и не применяется автоматически.

## API

- `GET /api/stations/{station_id}/engineering-drafts` — список черновиков станции.
- `GET /api/engineering-drafts/{editor}/{station_id}/{resource_id}` — получить черновик.
- `PUT /api/engineering-drafts/{editor}/{station_id}/{resource_id}` — записать новую ревизию черновика.
- `DELETE /api/engineering-drafts/{editor}/{station_id}/{resource_id}?expected_draft_revision=N` — удалить конкретную ревизию.

PUT body: `base_revision`, `expected_draft_revision`, `content`.

## Хранение и безопасность

SQLite: `databases/engineering_drafts.sqlite3`, WAL, транзакция `BEGIN IMMEDIATE`. Изменяющие API требуют локального оператора и проходят существующую проверку Origin. Содержимое не интерпретируется как код и не применяется автоматически.

## Ограничения DEV163

Это фундамент хранения и API, а не завершённая сквозная функция UI. Подключение каждого редактора к автоматическому локальному/серверному сохранению, диалог восстановления, конфликтное сравнение и end-to-end тесты браузерного закрытия должны быть выполнены до объявления Save Manager полностью готовым. Браузерный `beforeunload` не является механизмом надёжного сохранения: браузер не гарантирует завершение асинхронного запроса при закрытии.
