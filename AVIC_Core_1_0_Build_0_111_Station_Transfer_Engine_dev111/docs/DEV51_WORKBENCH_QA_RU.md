# DEV51 — карта ручной и автоматической проверки Workbench

| Элемент | Ожидаемое поведение | Автоматизировано в DEV51 | Ограничение |
|---|---|---|---|
| Переключатель Навигатор/Палитра | Меняет левую панель, сохраняет выбор | Да | Нет drag-and-drop вставки |
| Поиск палитры | Фильтрует компоненты и пустые категории | Да | Пока стартовый каталог |
| Locator Bar | Переход по названию раздела/видимому имени/ID | Да | Нет полного path grammar/autocomplete |
| Назад/Вперёд | Восстанавливает посещённые страницы | Да | Пока история страниц, не история каждого component view |
| View Changer | Открывает выбранный раздел/представление | Частично | Для ряда типов используется отдельная страница |
| Правый клик по разделу дерева | Открыть/обновить | Да | Команды зависят от типа узла |
| Правый клик по объекту | Объектные команды и views | Частично | Не вся матрица IQVISION |
| Двойной щелчок по объекту | Открыть представление по умолчанию/выбранное | Частично | Для контейнеров раскрывает дерево; для leaf открывает раздел |
| Главное меню | Переходы к страницам доменов | Да | Не все backend операции существуют |

## Проверки Chromium

Выполнены headless сценарии переключения панелей, фильтрации палитры, перехода по Locator Bar, истории назад/вперёд, контекстного меню раздела, открытия раздела из контекстного меню, меню Scheduler и отсутствия ошибок JS при старте. Результаты отражены в `BUILD_051_RU.md`.

## Ручная приёмка Windows

После установки архива пользователь должен проверить визуальное отображение на своём разрешении, дерево реальных Project/Station/Network/Device/Point и серверные действия контекстных меню на реальной тестовой конфигурации. Не запускать Discovery/полевые команды на производственной OT-сети без отдельного разрешения.
