# AVIC Core — DEV245: изоляция транспорта Modbus Worker

Дата: 27.11.2026

## Назначение

Устранить побочное создание Python Modbus TCP клиента при выборе внешнего Rust/C worker. Это важно для изоляции транспортного стека: выбранный worker должен единолично владеть своим протокольным соединением.

## Изменения

- В `DriverManagerService._build_modbus_adapter` сначала проверяется и исполняется выбранный engine.
- Для `engine="c"` вызывается C libmodbus Worker без создания Python `ModbusTcpClient`.
- Для `engine="rust"` вызывается Rust Worker без создания Python `ModbusTcpClient`.
- Python `ModbusTcpClient` создаётся только для `engine="python"`.
- В регрессионный тест C-worker добавлена проверка: попытка создать Python-клиент при выборе C engine немедленно проваливает тест.
- Обновлена документация драйверов Modbus/BACnet/KNX.
