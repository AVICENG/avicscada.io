# AVIC Core — журнал сборки DEV200

Дата: 27.11.2026
Ветка: `ci/fbd-connective-compiler`

## Изменения

- Исправлена проверка Windows user SID в HostIdentity: регулярное выражение теперь корректно принимает стандартный SID формата `S-1-5-21-...`.
- В Driver Manager опубликована операция `assert_driver_entitlement()` для безопасного повторного использования другими Core-сервисами.
- ProtocolDeviceImportService повторно проверяет подписанный feature entitlement при импорте точек, внутри блокировки Driver Manager и до транзакции репозитория.
- Это закрывает сценарий отзыва/истечения функции драйвера после создания DriverInstance, но до импорта найденных точек.
- Обновлена русскоязычная документация лицензионных ограничений и импорта.

## Регрессионные проверки

- Добавлен тест: отзыв feature entitlement блокирует импорт.
- Тест подтверждает отсутствие частичных изменений: Device, Point и binding map остаются неизменными.
- Полный GitHub Actions matrix: Ubuntu + Windows 2025, Python 3.11 / 3.12 / 3.13 — выполняется.
- Результаты CI не объявляются успешными до завершения всех шести jobs.
- Локальные Windows испытания пользователя для этой сборки ещё не проводились.

## Известные ограничения / следующие задачи круга

- BACnet/IP и Modbus TCP остаются read-only; физическая приёмка с реальным оборудованием обязательна отдельно.
- Trend IP/vCNC остаётся PLANNED до получения разрешённой протокольной спецификации или документированного тестового интерфейса.
- Общий import pipeline пока поддерживает BACnet/IP и Modbus TCP; KNXnet/IP discovery/import не подключён.
- Нужен общий параметризованный adapter contract suite для проверки публикации в PointRuntime, качества, восстановления, владельца драйвера и station isolation.
- Не реализованы все этапы production package manager, driver signing и сторонние пакеты.
