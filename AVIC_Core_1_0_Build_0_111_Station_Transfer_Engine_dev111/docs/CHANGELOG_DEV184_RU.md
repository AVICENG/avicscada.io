# AVIC Core 1.0 — DEV184

Дата: 26 ноября 2026
Пакет: `1.0.0.dev184`
Статус: Draft / проверка Windows CI ожидается

## Изменения FBD Studio

- Серверная проверка межстраничных Page Reference, CONNECTIVE proxy и TO_CONNECTIVE marker.
- Компилятор раскрывает CONNECTIVE в Core `StrategyConnective`; TO_CONNECTIVE остаётся навигационным объектом и не превращается в вычислительный узел.
- Проверяются соответствие типов портов, занятость входов и циклы полного графа после раскрытия межстраничных ссылок.
- Маркер компилятора `COMPILER=2` исключает повторное использование Core-артефакта, созданного предыдущим компилятором.
- Добавлены регрессионные тесты межстраничной симуляции, неправильных ссылок/типов, циклов и идемпотентности компиляции.
- Копирование страницы: новые UID блоков, уникальные module tags и page code, сохранение входящих Connective с новыми reference ID.
- Исходящие Connective при копировании страницы не дублируются и не перенаправляют старых потребителей на копию.
- CONNECTIVE и TO_CONNECTIVE запрещено копировать отдельно: это пара объектов одной навигационной ссылки.
- FBD Points автоматически не копируются, чтобы не создавать скрытые лицензируемые точки и не менять исходные bindings.
- Удаление страницы или блока с зависимостями требует подтверждения; связанные references, proxy/markers, линии и authoring FBD Points очищаются совместно.
- Проверка страницы игнорирует TO_CONNECTIVE как навигационный marker, не требующий логического подключения.

## Безопасность Windows

- Host Identity на Windows настраивает защищённый DACL через Windows Security API и Python `ctypes`.
- PowerShell не запускается; системная Execution Policy не меняется.
- Разрешённые principals: текущий Windows SID, Local System и Builtin Administrators.
- Runtime-публикация остаётся виртуальной; запись в физические контроллеры не включается.

## Поддерживаемые блоки компилятора

`BOOL_INPUT`, `FLOAT_INPUT`, `POINT_INPUT`, `SCHEDULE`, `AND`, `OR`, `NOT`, `ADD`, `SUB`, `MUL`, `DIV`, `SELECT`, `COMPARE_GT`, `COMPARE_LT`, `LIMIT`, `SCALE`, `HYSTERESIS`, `BOOL_OUTPUT`, `FLOAT_OUTPUT`.

Другие типы FBD Studio не считаются скомпилированными: компилятор должен явно сообщить о неподдерживаемом типе, а не пропускать его.

## Важные границы

- Компиляция создаёт отдельную Core FBD-стратегию; автоматическая публикация в runtime не выполняется.
- Изменение Studio не изменяет уже скомпилированную стратегию автоматически. Для применения изменений требуется новая компиляция и отдельная управляемая публикация.
- Удаление authoring FBD Point не является удалением уже созданных виртуальных точек старых Core-артефактов. Их безопасная очистка должна учитывать работающие/rollback-стратегии и будет отдельной задачей жизненного цикла compiled artifacts.
- Запись в физические контроллеры не включается.
