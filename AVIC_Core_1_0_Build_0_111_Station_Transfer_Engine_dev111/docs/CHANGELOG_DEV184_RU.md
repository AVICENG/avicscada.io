# AVIC Core 1.0 — DEV184

Дата: 26 ноября 2026

## Изменения
- FBD Studio: серверная проверка Page Reference / CONNECTIVE proxy.
- FBD Studio: компиляция межстраничных ссылок в Core StrategyConnective.
- TO_CONNECTIVE сохранён как навигационный маркер и исключён из исполняемых узлов.
- Проверка типов, занятости входов и циклов после раскрытия Connective.
- Добавлены тесты межстраничной компиляции и offline simulation.
- Windows Host Identity переведён на нативный DACL API без PowerShell; сохраняется принцип наименьших привилегий.
- CI: переход обычных проверок на частный Windows self-hosted Runner; Linux/Python 3.11–3.13 оставлен как ручная дополнительная матрица.

## Ограничения
- Безопасное дублирование страницы с внешними Connective ещё требует отдельной реализации.
- Удаление страницы с зависимостями требует отдельного диалога подтверждения.
- Запись в физические контроллеры не включается.

## Готовность
DEV184 — промежуточная инженерная сборка. Готовность будет определена после полного Windows CI и проверки регрессий.
