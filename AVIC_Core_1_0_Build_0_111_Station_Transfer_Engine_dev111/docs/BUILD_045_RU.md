# AVIC Core 1.0 — DEV45

## Назначение
DEV45 — исправляющая сборка инженерного дерева и безопасного удаления проектов/станций на базе DEV44. DEV44 сохранена без изменений.

## Реализовано в этой сборке
- Контекстное меню проекта и станции содержит команды удаления.
- Для удаления доступен предварительный просмотр состава затрагиваемых записей по типам.
- Удаление проекта/станции выполняется только после явного подтверждения каскада, если есть связанные записи.
- Удаление конфигурации выполняется одной SQLite-транзакцией; при конфликте/ошибке транзакция откатывается.
- В журнал аудита записываются тип, идентификатор и количество удалённых объектов.
- Физическое оборудование не получает команд и не изменяется.

## Ограничения
- DEV45 пока не превращает отдельные страницы `/pages` и `/graphics` в единый canvas. Это отдельная задача следующего этапа, не заявляется как готовая.
- Контекстное меню в этой сборке охватывает проект/станцию и существующие типы сетевого дерева; полноценные операции перемещения всех типов узлов, multi-select, drag-and-drop и undo/redo ещё не реализованы.
- Удаление страницы/папки уже имеет отдельную реализацию WebPagesService и остаётся отдельным контекстом.
- Перед эксплуатацией требуется пройти ручной браузерный тест и Windows acceptance.

## Проверка
Запуск тестов: `python -m pytest -q`. Новые тесты: `tests/test_project_station_delete_dev45.py`.

## Запуск
`python -m pip install -e ".[dev,http]"`
`python -m uvicorn avic_core.ui.__main__:app --host 127.0.0.1 --port 8080`

Открыть `http://127.0.0.1:8080`. Не публиковать порт в Интернет: клиентская авторизация и production TLS не входят в DEV45.
