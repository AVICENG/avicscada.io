# Сквозной инженерный цикл AVIC — DEV62

## 1. Сеть и Discovery

1. Откройте Workbench и создайте проект/станцию.
2. Откройте сетевые интерфейсы и выберите интерфейс с нужной IPv4-подсетью.
3. Создайте физическую сеть и канал BACnet/IP для станции.
4. Запустите BACnet Discovery вручную. Сканирование ограничено выбранным интерфейсом и read-only политикой.
5. Откройте устройство через BACnet Inspect. Manufacturer/model показываются только при наличии подтверждённых свойств или зарегистрированного vendor ID; неизвестные значения остаются пустыми.
6. Перед импортом вызовите `POST /api/stations/{station_id}/devices/import-preview`. Проверьте новые точки, дубликаты и неизвестные native ID.
7. Выполните импорт выбранных точек. До реального чтения их качество остаётся `UNCERTAIN`.
8. История сканирования доступна через `/api/network/discovery-sessions`.

## 2. Мнемосхема и FBD

1. Откройте `/graphics`, создайте мнемосхему или тестовую приточную установку.
2. Добавьте HVAC-символы и привяжите к точкам роли `value`, `feedback`, `alarm`, `quality`.
3. Создайте FBD-документ через `/logic` или API.
4. Используйте библиотеку блоков. Типы входов/выходов проверяются при сохранении связей.
5. `LIMIT`, `SCALE`, `COMPARE_LT` доступны в библиотеке и работают в симуляции.
6. Привязка FBD-выхода к элементу мнемосхемы сохраняет связь между инженерными документами.
7. Симуляция не запускает оборудование и не выполняет field writes.

## 3. Расписания, аварии, история

Сервисы расписаний, аварий, событий и истории сохраняют данные отдельно. API поддерживает недельные события, специальные даты, копирование дней, оценку расписания, жизненный цикл аварии, подтверждение, заметки и историю переходов. Полноценное выполнение расписания в производственном цикле пока не включено.

## 4. Platform и безопасность

`GET /api/platform/status` возвращает инвентаризацию объектов и зарегистрированных Runtime-станций. Security package содержит аутентификацию, хеширование паролей, MFA, сессии, recovery и RBAC primitives, однако обязательное применение этих механизмов ко всем Workbench endpoints ещё не завершено. Workbench mutations остаются loopback-only development guard.

## 5. TONN и Linux

В архитектуре сохраняется отдельное направление для будущего AVIC Linux Controller Agent: идентичность контроллера, безопасное provisioning, защищённый канал, конфигурация точек, диагностика, обновления и автономная работа. В DEV62 агент и протокол не реализованы. BACnet/IP и Modbus TCP не объявляются заменой TONN.
