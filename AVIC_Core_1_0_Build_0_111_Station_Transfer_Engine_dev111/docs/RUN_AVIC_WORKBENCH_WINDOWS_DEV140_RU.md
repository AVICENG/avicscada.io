# Запуск AVIC Engineering Workbench на Windows — DEV140

## Важно перед запуском

DEV140 — рабочая инженерная сборка, а не готовый промышленный релиз. Она запускает локальный веб-интерфейс и локальную базу данных. Полевые драйверы автоматически не запускаются; BACnet Discovery и Modbus-запросы выполняются только после явного действия инженера.

В DEV140 изменения через API намеренно разрешены только loopback-клиенту (127.0.0.1/localhost). Не выставляйте порт Workbench в Интернет, не запускайте сервер с `--host 0.0.0.0` и не отключайте локальную проверку. Поэтому GitHub Codespaces/облачный preview сейчас не подходит для полноценной интерактивной демонстрации: удалённый браузер не является локальным loopback-клиентом, а ослаблять эту защиту ради демо нельзя.

## Требования

- Windows 10/11 x64.
- Python 3.11–3.13; для первичного показа рекомендуется Python 3.13.
- Git необязателен, если скачан ZIP ветки.

## Вариант A — GitHub Desktop

1. В GitHub Desktop откройте репозиторий `AVICENG/avicscada.io`.
2. Выберите ветку `dev113-network-drivers` через **Current branch**.
3. Выполните **Fetch origin**, затем **Pull origin**, чтобы получить последний commit ветки.
4. Через **Show in Explorer** откройте репозиторий.
5. Перейдите в каталог `AVIC_Core_1_0_Build_0_111_Station_Transfer_Engine_dev111`.

## Вариант B — ZIP из GitHub

Откройте репозиторий, переключитесь на ветку `dev113-network-drivers`, затем используйте **Code → Download ZIP**. После распаковки откройте вложенный каталог проекта `AVIC_Core_1_0_Build_0_111_Station_Transfer_Engine_dev111`.

## Установка и запуск

Откройте PowerShell или CMD в каталоге проекта:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python -m avic_core.ui --host 127.0.0.1 --port 8000 --data-dir .\_avic_data_dev140
```

Если PowerShell запрещает активацию окружения, вместо активации можно запускать команды напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m avic_core.ui --host 127.0.0.1 --port 8000 --data-dir .\_avic_data_dev140
```

Откройте в браузере: `http://127.0.0.1:8000`.

Остановка: `Ctrl+C` в окне терминала.

## Что можно посмотреть

- общее инженерное рабочее пространство и навигацию;
- проекты, станции, дерево объектов;
- сетевые инструменты и BACnet Discovery;
- каталог драйверов и управление экземплярами;
- Point Manager и Runtime;
- FBD / Logic;
- редактор мнемосхем и SVG-библиотеку;
- Web Pages / Page Builder;
- расписания, события, диагностику и другие рабочие разделы.

Состав интерфейса шире реально завершённых функций. В навигации есть разделы со статусами partial/planned/designed; наличие пункта меню не означает завершённую реализацию. Для тестирования полевого обмена требуется доступ к контроллеру и отдельная проверка сети/протокола.

## Безопасность и данные

- Для первого показа используйте отдельный каталог `_avic_data_dev140`.
- Не запускайте одновременно несколько экземпляров с одним каталогом данных.
- Не подключайте контроллеры и не нажимайте Discovery без понимания выбранного сетевого интерфейса и подсети.
- Не используйте производственные контроллеры для первичного ознакомления.
- Не публикуйте локальный порт через роутер, туннель или общий reverse proxy.
- Если браузер не открывает страницу, проверьте, что терминал всё ещё запущен и порт 8000 свободен.

## Текущий статус DEV140

Инструкция описывает запуск интерфейса. Приёмка кода DEV140 отдельно зависит от результатов CI и Windows acceptance run; наличие этой инструкции не является подтверждением прохождения тестов.
