# AVIC Core 1.0 — журнал сборки DEV201

## Область
Driver Manager / жизненный цикл read-only адаптеров: надёжное завершение после ошибки освобождения транспортных ресурсов.

## Реализовано
- Исправлен stale-session сценарий: после остановки polling worker ошибка `adapter.close()` больше не оставляет остановленную сессию в реестре Driver Manager.
- При ошибке закрытия экземпляр переводится в `ERROR` с `enabled=False`; событие `driver.instance_stop_failed` записывается в Audit.
- При timeout остановки worker адаптер не закрывается и записи реестра сохраняются: это предотвращает закрытие транспорта под выполняющимся I/O.
- Добавлен тест повторного запуска после ошибки `close()` с новым адаптером.

## Ограничения и статус
- Если `adapter.close()` сам не может освободить ресурс, AVIC честно фиксирует `ERROR`; фактическое освобождение транспорта гарантировать невозможно при ошибке самого адаптера.
- Timeout worker оставляет экземпляр в состоянии остановки до завершения I/O; принудительное закрытие сокета не выполняется.
- DEV201: реализовано, автоматическая проверка ожидает CI; не считать завершённым до зелёной матрицы.
