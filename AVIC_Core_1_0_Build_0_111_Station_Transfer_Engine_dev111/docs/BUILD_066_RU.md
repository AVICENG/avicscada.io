# AVIC Core 1.0 — DEV66: Iso3D HVAC / ITP SVG Library

Дата сборки: 20.11.2026  
Версия: `1.0.0.dev66`  
База: DEV65. Базовая папка DEV65 не перезаписана.

## Причина сборки

Пользователь отклонил плоские условные пиктограммы DEV65 как непригодные для инженерных мнемосхем и запросил объёмную HVAC/ИТП-графику уровня Niagara: заслонки, воздуховодные секции и фасонные части, нагрев/охлаждение, разные вентиляторы, теплообменники и оборудование ИТП.

## Изменения

1. Переработаны все 28 ранее существовавших SVG-ресурсов без изменения их ID.
2. Добавлены дополнительные типы HVAC/ИТП; общий каталог вырос до 59 SVG в 19 категориях.
3. Векторный стиль переведён на объёмную ортографическую изометрию: грани корпусов, стальные градиенты, тени, панели, фланцы, крепёж, разрезы и внутренние компоненты.
4. Цветовая семантика: горячий контур — красный, холодный — синий; вентиляторные роторы имеют именованные SVG-группы для будущей анимации.
5. API `/api/graphics/library` объявляет `style=isometric-3d`, `version=2.0.0`, список 59 assets и категории.
6. Graphics Workbench увеличивает область предпросмотра карточек и задаёт размер добавляемого символа по его назначению.
7. Wheel package-data включает `static/svg-library/*.svg`.
8. Сохранены пользовательский SVG-import DEV65, Web Pages Editor, FBD, все сервисы и старые symbol keys.

## Визуальная сверка

Ориентиры по общему визуальному подходу и таксономии сверялись с Niagara Graphics Guide (Tridium, 2021), разделы `kitPxHvac`, `kitPxGraphics`, `kitPxN4svg`, и с публичными примерами объёмных HVAC-мнемосхем. Изображения оригинальные: файлы Niagara/сторонних платных библиотек не копировались.

## Что не означает DEV66

- Не является копией оригинальной коммерческой библиотеки Niagara.
- Не является true-3D CAD моделью с физической геометрией.
- Вращение вентиляторов и изменение лопаток заслонок пока не активируются Runtime автоматически.
- Не добавляет автоматическую привязку красно-синих контуров к точкам, динамическое заполнение теплообменника или команды управления.
- Не заменяет браузерную приёмку пользователя.

## Контракт

- Stable IDs: старые ID оставлены; новые добавлены без переименования прежних.
- SVG viewBox: `0 0 320 200`.
- SVG static resources доступны через `/api/graphics/library/{symbol_id}/svg`.
- Каталог доступен через `GET /api/graphics/library`.
- Встроенные assets — allowlist; пользовательские загрузки остаются в отдельном sanitizer/import flow DEV65.
