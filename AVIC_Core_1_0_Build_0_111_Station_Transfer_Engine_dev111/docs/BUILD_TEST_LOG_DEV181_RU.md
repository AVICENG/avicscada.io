# AVIC Core DEV181 — Supervisor process-exit regression

Версия: 1.0.0.dev181  
Базовый commit: f3d99d6226dd7e3e0264aea4063ba16773ba1f31

## Изменения
- Добавлен интеграционный тест, запускающий Supervisor в отдельном временном процессе.
- Тест проверяет, что detached Field Runtime agent остаётся жив после завершения Supervisor и закрытия IPC listener.
- Версия пакета обновлена до 1.0.0.dev181.
- Уточнена документация о границе доказанного поведения.

## Проверки
- Код и тестовый сценарий добавлены.
- Фактический pytest, Windows acceptance и CI в этой сборке не подтверждены.
- GitHub Actions на DEV180 не запускал ни одного шага: все четыре matrix jobs завершились до назначения runner; logs endpoint вернул BlobNotFound.

## Ограничения
- Агент остаётся жив, но не переподключается к новому Supervisor после полного рестарта: endpoint и token эфемерны.
- FBD execution engine не подключён; active_strategies остаётся 0.
- Нет системной установки службы, автозапуска, watchdog/restart policy и реального управления оборудованием.
- Этот тест не является промышленной приёмкой полевой автономности.
