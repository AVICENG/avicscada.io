# AVIC Repository — интеграция DEV100

## Что изменено

- В общем инженерном дереве ветка `Репозиторий` теперь отображается непосредственно под каждой станцией.
- Выбор ветки открывает `/repository?station=<station_id>`.
- Workspace читает `station` из URL и выбирает именно эту станцию, а не первую станцию в списке.
- `/repository` использует существующий Core `WebPagesService`, `GraphicsService`, общую навигацию и Core API.
- Не добавлялись отдельные сервер, БД, авторизация, сущности точек или собственные идентификаторы оборудования.

## Границы владения

Репозиторий владеет веб-страницами, HTML/CSS/JS-контентом, размещением компонентов и ссылками на графику. Core остаётся владельцем станций, устройств, драйверов, точек, значений/качества, мнемосхем, аварий, расписаний и прав доступа. Связи с точками должны использовать стабильные Core ID.

## Проверки

Добавлен тест, который проверяет наличие ветки под станцией, переход с `station_id`, выбор переданной станции и активное состояние раздела Repository. Тесты и компиляция фиксируются в `BUILD_TEST_LOG_DEV100_RU.md`.

## Ограничения

- Это интеграция навигации и контекста станции, а не полный перенос всех функций DEV23.
- CRUD API Web Pages по-прежнему защищён временным loopback/Origin guard. Это не полноценная аутентификация и не RBAC.
- Публикация страниц в клиентскую сеть остаётся отключённой.
- Полный перенос редактора ресурсов, шаблонов, стилей и скриптов из DEV23 ещё не выполнен.
- Команды оборудования из графики не разрешаются этим изменением.
