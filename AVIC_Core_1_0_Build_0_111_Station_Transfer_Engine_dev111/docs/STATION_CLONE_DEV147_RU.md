# DEV147 — Station Clone

## Реализовано
Добавлен режим клонирования в StationTransferManager.commit_import. Клон получает новые UUID для всех инженерных сущностей и отдельные идентификаторы для пользовательских SVG, расписаний, событий расписаний и рёбер зависимостей.

Внутренние ссылки переназначаются на новые объекты: Station, Project, Device, Point, Graphics, PointBinding, FBD, Web Pages, schedules, schedule bindings, time permissions, analytics и dependency graph. Имя станции задаётся при клонировании.

Клон остаётся NOT_ACTIVATED. Сетевые адреса и native identity очищаются экспортным профилем, драйверы/каналы выключены, разрешения синхронизации времени сброшены. Перед запуском требуется site binding и commissioning.

## Границы текущего этапа
Реализован сервисный путь клонирования и end-to-end тест. UI-мастер и API загрузки/выгрузки пакетов ещё не подключены. Автоматическое развёртывание на контроллеры не выполняется.
