# AVIC Core 1.0 — DEV56: инженерный маршрут и контроль полноты

**База:** DEV55. **Направление IQVISION:** Configuration Manual §4 Engineering Procedure, с проверками связанных этапов §8–10.

## Назначение

DEV56 добавляет не отдельную демонстрационную страницу, а единый read-only контроль инженерной готовности станции. Он связывает уже существующие подсистемы и показывает, какие реальные объекты сохранены, где есть разрывы и какой следующий шаг требуется.

## Реализовано

- Новый `EngineeringWorkflowService` в `avic_core/engineering/workflow.py`.
- API `GET /api/stations/{station_id}/engineering-workflow`.
- Рабочая страница «Пусконаладка → Инженерный маршрут станции» в Workbench.
- Список станций загружается из фактического Project/Station дерева; приоритетно выбирается текущая станция Workbench.
- Пять проверяемых этапов:
  1. Сеть и каналы: физическая сеть, выбранный интерфейс, протокольный канал и корректная привязка канала к сети той же станции.
  2. Драйверы и устройства: устройства должны иметь драйвер в пределах той же станции, явный `read_only` и поддерживаемое неактивное состояние `STOPPED`/`CONFIGURED`.
  3. Point Manager: точки считаются только если принадлежат устройствам выбранной станции.
  4. FBD/Wiresheet: сохранённая схема и блоки, подсчёт связей.
  5. PX/Мнемосхемы: сохранённая страница и символы, подсчёт point- и logic-bindings.
- Диагностика возвращает коды и сообщения для отсутствующего драйвера, небезопасного/неопределённого режима, неожиданного состояния драйвера, отсутствующей физической сети канала и невыбранного сетевого интерфейса.
- Станционная область соблюдается через фактические связи объектов; чужие точки/драйверы/страницы не засчитываются.
- Страница отображает прогресс, счётчики, незакрытые этапы и следующее действие.
- `publish_ready` всегда `false`: наличие инженерных артефактов не означает commissioning acceptance, production runtime deployment или OT readiness.
- В API явно возвращается безопасность: `field_writes_enabled=false`, `driver_autostart=false`, `simulation_is_offline=true`.

## Как пользоваться

1. Откройте Workbench.
2. Выберите в инженерном дереве станцию.
3. Откройте раздел **Эксплуатация → Пусконаладка**.
4. В списке выберите станцию (текущая станция выбирается автоматически, если она известна Workbench).
5. Нажмите **Проверить готовность**.
6. Исправляйте этапы по порядку: сеть/канал → драйвер/устройство → точки → FBD → мнемосхема.
7. Повторите проверку после изменений.

Проверка только читает сохранённую конфигурацию. Discovery не запускается автоматически. Драйверы не стартуют. Физические контроллеры не изменяются.

- `python -m compileall -q avic_core tests` — passed.
- `node --check` для JS Workbench — passed.
- Тестовые матрицы DEV55, Graphics DEV54, Point List DEV52, Alarm Console DEV53 и DEV56 запускались отдельными командами; детальные цифры приведены в `BUILD_TEST_LOG_DEV56_RU.md`.

## Что НЕ реализовано и не должно считаться закрытым

- §4 IQVISION закрыт только в части единой диагностики маршрута. Это не полный workflow wizard: нет автоматического orchestration discovery/import/commissioning, журналов commissioning steps, sign-off и отчётов.
- Нет полноценного Driver Manager UI: управление пакетами, установкой/обновлением/удалением драйверов, конфигурационными формами, версиями, signature verification и lifecycle ещё впереди.
- Trend IQ3: есть read-only integration/inspection foundation; полноценные Trend System/Module Discovery, импорт, reconnect/recovery и реальный Windows acceptance не выполнены.
- TONN/TONN8: отдельный адаптер не реализован. BACnet не используется как подмена TONN.
- Third-party driver SDK/package lifecycle не реализован.
- Нет production runtime, cyclic task scheduler, online watch, publish/rollback и полевых записей.
- Нет подтверждённой работы с физическими контроллерами и Windows acceptance.
- Полная авторизация всех API и production RBAC/session enforcement остаются отдельной работой.

## Статус

**DEV56 — инженерный workflow/readiness foundation реализован и проверен тестами; функциональная паритетность первых десяти разделов IQVISION не достигнута.** Не считать готовым к промышленной эксплуатации.
