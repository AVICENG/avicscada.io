# AVIC Core 1.0 — DEV46: Unified Engineering Editor

## Цель сборки
Сделать редактор страниц и мнемосхем единой рабочей областью Web Pages, не открывая отдельные окна браузера.

## Реализовано
- Вкладка «Редактор мнемосхем» встроена непосредственно в Web Pages Editor.
- Graphics Workbench открывается во встроенной панели и получает выбранную станцию/мнемосхему.
- После сохранения мнемосхемы встроенный редактор сообщает родительской рабочей области об изменении; список документов и привязок обновляется.
- Переход к назначенной мнемосхеме выполняется внутри текущей рабочей области.
- Для дерева сайтов/папок/страниц добавлено контекстное меню по правому клику и кнопке `···`.
- Контекстные команды зависят от типа узла: создание вложенной папки/страницы, переименование, перемещение, удаление; для страницы — переход в визуальный режим или режим кода.
- Двойной щелчок по странице открывает визуальный редактор.
- DEV45 исправления удаления проекта/станции сохранены в исходной базе сборки.

## Важные границы
- Встроенный Graphics Workbench пока сохраняет собственную внутреннюю панель инструментов и свойства, но визуально работает внутри общей области редактора.
- Режим Preview остаётся изолированным sandbox iframe.
- Публикация, выполнение команд управления из веб-страниц и production-authentication не включены.
- Перемещение узлов в дереве страниц ограничено допустимыми родителями и проверками сервиса.
- Это интеграция редакторов на уровне единой рабочей области и навигации; внутренняя модель графического документа пока отдельная от модели HTML-страницы, связь оформляется через проверяемые привязки.
