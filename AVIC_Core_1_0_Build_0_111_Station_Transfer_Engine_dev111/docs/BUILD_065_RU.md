# AVIC Core 1.0 — DEV65: SVG Import & Web Pages Authoring

Дата: 20.11.2026  
Версия пакета: `1.0.0.dev65`  
База: исходный проект DEV64. DEV64 не перезаписывается.

## Назначение

DEV65 закрывает два конкретных пробела редакторской среды:

1. импорт пользовательских SVG-символов в библиотеку выбранной станции;
2. визуальное проектирование структуры сайта/страниц и их содержания.

Это development-сборка. Изменения не включают публикацию страниц на производственный сервер, Runtime для динамических значений, управление контроллерами или полный RBAC.

## Импорт SVG

### Возможности

- импорт `.svg` до 1 МБ из Graphics Workbench;
- название и категория символа;
- отдельное хранение в SQLite `custom_svg_library.sqlite3` в контексте Core;
- изоляция каталога по `station_id`;
- поиск, фильтрация по категориям, предпросмотр и добавление на лист Graphics Editor;
- повторное открытие мнемосхемы с сохранёнными пользовательскими symbol keys;
- удаление символа только после проверки, что он не используется в мнемосхемах;
- аудит импорта и удаления с SHA-256.

### Ограничения безопасности импорта

Импорт выполняет разбор XML и очистку SVG на сервере. Запрещены DTD/ENTITY, скрипты, обработчики `on*`, `foreignObject`, встраиваемые документы, `image`, аудио/видео, анимация, внешние URL, внешние XML namespace и CSS `@import`. Разрешены ограниченные векторные элементы, стили и ссылки только на существующие локальные `#id` внутри SVG.

Лимиты: 1 МБ исходного файла, 10 000 XML-узлов, глубина 50. Неизвестные атрибуты без активного содержимого отбрасываются; неподдерживаемые/активные элементы отклоняются.

### Использование

1. Откройте Engineering Workbench и выберите проект/станцию.
2. Откройте «Мнемосхемы / Graphics Workbench».
3. Выберите нужную станцию в левом верхнем списке.
4. В блоке «Импорт SVG-файла» выберите `.svg`, задайте название и категорию.
5. Нажмите «Импортировать в библиотеку станции».
6. Найдите символ через поиск или категорию, затем щёлкните по нему или перетащите на лист.
7. Сохраните мнемосхему.

Импортированный символ доступен только в библиотеке своей станции. Символ нельзя удалить, пока он используется в сохранённых мнемосхемах этой станции.

### HTTP API

- `GET /api/stations/{station_id}/graphics/symbols` — полный каталог встроенных и пользовательских символов;
- `GET /api/stations/{station_id}/graphics/svg-assets` — пользовательские SVG выбранной станции;
- `POST /api/stations/{station_id}/graphics/svg-assets` — импорт;
- `GET /api/graphics/custom-symbols/{symbol_id}/svg` — очищенное SVG-содержимое;
- `DELETE /api/stations/{station_id}/graphics/svg-assets/{symbol_id}` — удаление неиспользуемого символа.

Изменяющие запросы защищены существующим development guard Workbench (loopback/local operator). Это не замена полноценному пользовательскому RBAC.

## Разработка страниц

### Структура

- создание корневого сайта;
- создание папок и страниц внутри сайта/папок;
- выбор родителя при создании;
- переименование, перемещение, дублирование страницы, удаление;
- перемещение узлов вверх/вниз по порядку навигации;
- проверка уникальности URL slug среди страниц и папок одного родителя;
- сохранение с optimistic revision и проверкой принадлежности станции.

### Визуальные компоненты

На холсте доступны восемь типов:

- заголовок;
- текст;
- информационная карточка;
- кнопка/ссылка;
- изображение;
- разделитель;
- значение (пока placeholder, без Runtime);
- встроенная мнемосхема, назначенная странице.

Компонент можно выбрать, перетаскивать по холсту, дублировать, переставлять в порядке редактирования, удалять и настраивать через инспектор: текст, ссылка/URL изображения, ширина, высота, размер шрифта, выравнивание, цвет и фон. Разделитель поддерживает тонкую высоту от 1 px.

### Использование

1. Откройте «Страницы / Web Pages» из Engineering Workbench.
2. Выберите станцию.
3. Нажмите «Сайт» и создайте корневой сайт.
4. Выберите сайт, создайте папки, затем страницы.
5. Выберите страницу и используйте палитру на вкладке «Визуальный редактор».
6. Выберите компонент на холсте. Измените его свойства в правом инспекторе.
7. Перетащите компонент мышью в требуемое положение.
8. Нажмите «Сохранить».
9. Переключитесь на «Предпросмотр».

Для размещения мнемосхемы: откройте вкладку «Редактор мнемосхем», выберите существующую схему и нажмите «Привязать к странице». После этого добавьте компонент «Мнемосхема» в визуальной палитре и сохраните страницу.

Для ручной разметки доступны отдельные редакторы HTML/CSS/JS. Предпросмотр запускается в iframe с `sandbox="allow-scripts"`; JavaScript страницы не получает same-origin доступ к Workbench.

### HTTP API

- `GET /api/stations/{station_id}/web-pages` — дерево;
- `POST /api/web-pages` — создание сайта/папки/страницы;
- `GET /api/web-pages/{node_id}` — открыть;
- `PUT /api/web-pages/{node_id}` — сохранить страницу и layout;
- `POST /api/web-pages/{node_id}/move` — переместить узел;
- `POST /api/web-pages/{node_id}/reorder` — изменить порядок среди соседей;
- `POST/DELETE /api/web-pages/{node_id}/graphics[/{graphic_id}]` — привязать/отвязать мнемосхему;
- `DELETE /api/web-pages/{node_id}?expected_revision=...` — удалить узел и вложенное дерево.

## Проверенные ограничения

- Публикация/production hosting страниц отключены (`publish_enabled=false`).
- Компонент «Значение» показывает placeholder `— / Нет данных Runtime`; динамическая подписка на точку ещё не реализована.
- Для ссылки/изображения разрешены локальный путь или допустимый HTTP(S) URL; `javascript:`, `data:`, `vbscript:` и protocol-relative URL `//host/...` отклоняются.
- Полноценные responsive breakpoints, CSS grid/flex designer, браузерная публикация и versioned asset manager не входят в DEV65.
- Runtime, полевые записи и командные привязки остаются отключены.
- Визуальное браузерное подтверждение в Chromium в среде сборки недоступно из-за `ERR_BLOCKED_BY_ADMINISTRATOR`; обязательна приёмка в Windows браузере пользователя.
