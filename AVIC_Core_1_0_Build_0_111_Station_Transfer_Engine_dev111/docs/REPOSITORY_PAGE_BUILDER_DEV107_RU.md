# Web Application Page Builder — DEV107

## Назначение

Page Builder создаёт операторские страницы станции в ветке Repository → Web Application. Данные страниц хранятся в Core Repository как `WebPageNode`; графические документы, точки и ресурсы остаются собственностью соответствующих Core-сервисов. Repository не создаёт дубликаты Point Runtime или Graphics.

## Навигация

- Общий узел «Репозиторий» станции открывает `/repository?station=<station-id>&section=WebApplication`.
- Узел Web Application и конкретные узлы сайта/папки/страницы открывают тот же редактор; при выборе страницы она загружается в редактор.
- Узлы Graphics открывают отдельный Graphics Workbench. Старый `pages.html` не используется.

## Создание страницы

1. Выберите станцию.
2. Откройте Repository → Web Application.
3. Нажмите «Сайт» и задайте имя.
4. Выберите сайт и нажмите «Страница»; при необходимости сначала создайте папку.
5. Выберите созданную страницу в дереве.

## Компоновка

Палитра содержит заголовок, текстовую надпись, изображение, значение точки, мнемосхему, разделитель, карточку и декоративную кнопку. Элемент можно добавить нажатием по палитре или перетаскиванием на холст. Геометрия редактируется в свойствах X/Y/ширина/высота.

Для значения точки выбирается стабильный ID физической или виртуальной Core-точки. При сохранении проверяется существование точки и её принадлежность той же станции. Качество не-GOOD отображается как состояние качества, а не как нормальное значение.

Изображения загружаются в Repository Assets станции. Разрешены PNG/JPEG/GIF/WebP, до 3 МБ, с проверкой сигнатуры файла. Мнемосхема должна быть назначена странице; при публикации её конфигурация фиксируется в snapshot, а значения привязок остаются read-only live из Point Runtime.

## Сохранение и публикация

- Сохранение использует `expected_revision` и optimistic concurrency.
- Публикация проверяет layout, point bindings и назначенные Graphics документы.
- Снимок публикации неизменяем относительно последующих правок исходной мнемосхемы.
- История публикаций хранит до 50 версий; доступны unpublish и rollback через API.
- Публичный маршрут имеет вид `/published/<station-id>/<page-path>`.
- Live значения на опубликованной странице обновляются через read-only Point Runtime polling.

## Ограничения

- Кнопка в Page Builder пока декоративная и не отправляет команды.
- Command Manager DEV106 не интегрирован в операторскую страницу и остаётся SIMULATION_ONLY.
- Нет customer-grade login/session, server-side RBAC и MFA; изменяющие операции защищены loopback-only development guard.
- Предпросмотр редактора не заменяет браузерное acceptance-тестирование опубликованной страницы.
- Нет customer-grade reverse-proxy/HTTPS deployment profile.

## Приёмочный маршрут

Создать проект и станцию → открыть Repository из общего дерева → создать сайт и страницу → добавить заголовок, надпись, изображение, точку и мнемосхему → сохранить → опубликовать → открыть URL → проверить read-only обновление значений и неизменность snapshot Graphics после изменения исходного документа.
