# AVIC Core 1.0 — DEV65

DEV65 — development-сборка **SVG Import & Web Pages Authoring** на базе DEV64. Предыдущие исходники DEV64 сохранены; удалённых файлов базовой сборки нет.

## Изменения DEV65

- Безопасный импорт пользовательских SVG-файлов размером до 1 МБ в библиотеку конкретной станции.
- Очистка XML/SVG от скриптов, событий, внешних ресурсов, DTD/ENTITY и неподдерживаемых активных элементов.
- Хранение пользовательских SVG в SQLite, поиск/категории, просмотр и использование в Graphics Editor.
- Запрет удаления импортированного SVG, пока он используется мнемосхемой.
- Аудит импорта/удаления SVG.
- Визуальный редактор страниц с восемью компонентами: заголовок, текст, карточка, кнопка/ссылка, изображение, разделитель, значение-placeholder и мнемосхема.
- Инспектор свойств, перемещение компонентов мышью, изменение размеров, дублирование, изменение порядка, удаление и сохранение.
- Дерево «Сайт → Папка → Страница»: создание, переименование, перемещение, дублирование страницы, сортировка, удаление.
- Сохранение с optimistic revision, валидация layout и URL.

## Ограничения

- DEV65 не включает публикацию страниц на production hosting.
- Компонент «Значение» пока показывает placeholder; point binding с Runtime не подключён.
- Responsive breakpoints и полноценный визуальный CSS Grid/Flex designer ещё не реализованы.
- Runtime execution и field writes остаются отключёнными.
- Полноценный пользовательский RBAC остаётся отдельной задачей.
- Browser acceptance в Chromium среды сборки недоступна из-за `ERR_BLOCKED_BY_ADMINISTRATOR`; требуется проверка на Windows пользователя.

DEV65 — расширенный редакторский прототип, а не готовая SCADA и не полная функциональная паритетность с IQVISION.
