# AVIC Core 1.0 — DEV92

## Тема сборки

Network Planning & Deployment: ручной проектный план адресации будущего компьютера AVIC, автоматическая привязка к локальному интерфейсу, проверка соответствия при установке и одиночная безопасная Ping-диагностика.

## Реализовано

1. `NetworkPlan` — валидация IPv4 подсети, IP станции, шлюза и DNS.
2. `PhysicalNetwork` — сохранение режима `auto`/`manual`, проектного IP, gateway и DNS.
3. API создания сети поддерживает ручной план без существующего локального интерфейса.
4. API deployment-check сопоставляет план с активными интерфейсами и возвращает один из трёх статусов.
5. API Ping выполняет один ICMP Echo с ограниченным тайм-аутом, без shell и без сканирования диапазона.
6. Дерево станции передаёт сведения об адресации сети; контекстное меню содержит Ping и проверку привязки.
7. BACnet direct unicast inspection и импорт допускают адреса за пределами локальной подсети; локальный broadcast Discovery остаётся привязан к выбранному интерфейсу. Для manual-сети опрос/импорт требует точного совпадения текущего IP и подсети с планом.
8. Добавлена русская документация и тесты DEV92.

## Архитектурные правила

- Станция AVIC, физическая сеть, протокольный канал, устройство и точка — разные сущности.
- Несколько сетей/подсетей и несколько протоколов допускаются.
- Шлюз/маршрутизатор не считается механизмом присвоения IP устройствам.
- Проектный IP не применяется автоматически к ОС или контроллеру.
- Ping и Discovery запускаются только явным действием инженера.

## Не заявляется как готовое

- Автоматическая настройка Windows NIC, DHCP, gateway, DNS, VLAN, NAT и маршрутов.
- Полный IP Tools (traceroute, TCP port scan, ARP table, route table, DNS diagnostics).
- BACnet BBMD configuration wizard и межсетевой discovery.
- Проверка на реальном Windows объектном компьютере и реальных контроллерах в этой среде.
- Полная интеграция FBD Schedule с Core ScheduleService и Web Schedule Widget — отдельный следующий вертикальный срез.
