# AVIC Core — журнал изменений и проверок DEV197

Дата: 26.11.2026  
Ветка: `ci/fbd-connective-compiler`  
Предыдущая версия пакета: DEV196

## Цель цикла

Устранить расхождение между отображаемым количеством лицензируемых точек и фактическим ограничением при создании/подключении точек. Обеспечить правило: обнаруженная точка не расходует лимит до подключения к рабочей инженерной функции; одна и та же точка учитывается только один раз.

## Изменения

1. В доменную модель `Point` добавлены `point_type`, `licensed_active`, `published`, `licensed_usage`.
2. `summarize_point_usage` возвращает множество уникальных активных ID и общий счётчик.
3. `CoreObjectService` проверяет переходы между неактивным и активным состоянием в транзакции репозитория. Проверяется также активация уже существующей точки.
4. BACnet Discovery Import и общий Protocol Point Import сохраняют новые обнаруженные точки как неактивные.
5. FBD регистрирует использование точки при сохранении блока `POINT_INPUT`.
6. Graphics регистрирует использование точки при сохранении мнемосхемной привязки.
7. Использования имеют отдельные ключи по документам. Удаление одной привязки не освобождает точку, пока остаётся другая. Удаление последнего отслеживаемого использования снимает активность и освобождает слот.
8. Чтение сущностей репозиторием получило необязательное подключение к текущей транзакции, чтобы обновление лицензируемого состояния было атомарным с сохранением FBD/Graphics.
9. Добавлены тесты на неактивный импорт, активацию, запрет превышения лимита, совместное использование FBD+Graphics и освобождение слота после удаления последней привязки.

## Ограничения и незавершённые части

- Автоматическое отслеживание использования реализовано для FBD и Graphics.
- Для Alarm, Historian, Scheduler и Control требуется подключить аналогичную регистрацию и снятие usage reference.
- Текущая обратная совместимость трактует старые физические точки без `licensed_active` как активные. Новые discovery/import записи явно помечаются неактивными.
- Не завершены лицензирование драйверных пакетов на уровне установщика, Host-ID transfer/revocation workflow и полноценный экран лицензии в Workbench.
