# FBD-проект: пакетирование и Schedule

## Формат пакета
`.avicfbd.json` — JSON-документ со следующими полями:
- `schema`: `avic.fbd.project-package`
- `schemaVersion`: `1`
- `createdAt`
- `project`: данные редактора (страницы, блоки, связи, ссылки, FBD-точки)
- `integrity.algorithm`: `SHA-256`
- `integrity.digest`: SHA-256 от компактного `JSON.stringify(project)`.

Это проверка целостности, не цифровая подпись и не подтверждение доверенного автора.

## Открытие
1. File → Open FBD file…
2. Прочитать пакет.
3. Проверить SHA-256 для нового формата.
4. Проверить страницы, ID блоков и ссылок.
5. Подтвердить замену текущего документа.
6. Импортировать структуру; прежний legacy JSON остаётся поддержан.

## Schedule
- Новый блок `SCHEDULE`.
- Выход выбирается BOOL или числовой.
- Недельные интервалы: день недели, начало, конец, значение, приоритет.
- Исключения: имя, начальная/конечная дата, значение, приоритет.
- Указание IANA timezone, например `Europe/Moscow`.
- Default value при отсутствии активного события.
- Переход через полночь поддерживается.
- Исключения выше недельных событий; временный override выше исключений до `expiresAt`.

Симуляция не пишет в контроллер. Для эксплуатации необходима следующая интеграция с Core Scheduler, Runtime, Point Quality, PointRuntime и безопасным Command Manager.
