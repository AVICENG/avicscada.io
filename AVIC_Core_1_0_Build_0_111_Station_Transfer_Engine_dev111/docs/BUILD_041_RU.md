# AVIC Core 1.0 — DEV41

## Engineering Workbench: физические сети и протокольные каналы

DEV41 продолжает DEV40 без удаления существующих возможностей.

### Реализовано
- Компоновка Workbench: верхнее меню в стиле инженерной станции, слева дерево, центральная изначально пустая белая рабочая область, справа инспектор. Нереализованные команды меню отключены и подписаны; они не имитируют рабочие функции.
- `PhysicalNetwork` — сохраняемый объект физической сети в контексте станции; хранит выбранный IPv4-интерфейс, адрес и подсеть.
- `ProtocolChannel` — отдельный сохраняемый объект протокола, привязанный к физической сети. В DEV41 доступны конфигурации BACnet/IP и Modbus TCP.
- Инженерное дерево строит иерархию Project → Station → Physical Network → Protocol Channel → Device → Point. Старые устройства, созданные до DEV41, остаются видимыми как legacy-сетевые группы.
- Создание сети и канала доступно через контекстное меню правой кнопки мыши и диалог Workbench.
- BACnet Discovery запускается вручную из контекста физической сети/канала BACnet/IP. Результаты можно исследовать и импортировать в выбранную станцию и сеть.
- Удаление сети/канала блокируется при наличии зависимых каналов/устройств. Удаление конфигурации не меняет физическое оборудование.
- Компактное дерево: белый фон, серое выделение, небольшие SVG-пиктограммы, цветовая семантика, однострочные названия с многоточием справа; вложенные уровни визуально смещаются справа налево.

### Ограничения
- BACnet/IP Discovery и импорт — read-only. Автоматический фоновый опрос не включается.
- Modbus TCP канал можно создать и сохранить, но автоматический Modbus Discovery/импорт контроллеров в DEV41 не реализован; интерфейс явно сообщает об ограничении. Ручные Modbus read/identify API DEV40 сохранены.
- Управляющие записи в полевые устройства не добавлены.
- Аутентификация и полноценный серверный RBAC остаются отдельной незавершённой задачей. Локальная защита Workbench DEV40 сохранена.
- Требуется Windows-приёмка пользователя; Linux-тесты не заменяют её.

### Модель работы с сетью
1. Создать/выбрать проект и станцию.
2. Правой кнопкой по станции → «Создать физическую сеть».
3. Указать имя и конкретный сетевой интерфейс компьютера. AVIC не меняет IP Windows.
4. Правой кнопкой по сети → «Добавить протокол» → BACnet/IP или Modbus TCP.
5. Для BACnet/IP — правой кнопкой по сети/каналу → Discovery. Запрос отправляется только после явного действия инженера.
6. Исследовать найденный контроллер, выбрать устройство/точки и добавить в конфигурацию AVIC.
7. Импортированное оборудование отображается в ветви выбранной физической сети.

### Версия и проверка
- Пакет: `1.0.0.dev41`.
- Полный локальный Linux regression suite: результат фиксируется в `BUILD_TEST_LOG_DEV41_RU.md`.
- Обязательная следующая проверка: установка wheel на Windows 10 и полный `python -m pytest -q`.
