# AVIC Core 1.0 — DEV67: модульная ПВУ и SVG-анимация

**Версия:** `1.0.0.dev67`  
**База:** DEV66 Iso3D HVAC / ITP Library  
**Назначение:** добавить полноценный набор соединяемых секций одной приточной установки и состояние-зависимую анимацию на листе Graphics Workbench.

## 1. Состав модульной установки

Порядок демонстрационной сборки слева направо:

1. заслонка наружного воздуха;
2. фильтры;
3. пластинчатый рекуператор;
4. водяной нагреватель;
5. водяной охладитель;
6. приточный центробежный вентилятор;
7. открытый выходной короб после вентилятора.

Каждый элемент — отдельный редактируемый SVG-файл в `avic_core/ui/static/svg-library/`. Все семь используют одинаковый `viewBox="35 62 317 185"`, общие координаты оболочки/фланцев и единый разрез корпуса. Последняя секция не имеет глухой боковой облицовки: открыт внутренний воздушный тракт.

## 2. Состояния SVG

Встроенные SVG содержат CSS-классы:

- `state-damper-open` — поворот группы лопаток входной заслонки;
- `state-fan-running` — непрерывное вращение рабочего колеса;
- `state-airflow` — видимая линия, движущиеся штрихи и частицы потока воздуха.

Graphics Workbench встраивает эти семь штатных SVG непосредственно в основной SVG-лист. Это необходимо, чтобы классы состояния могли управлять внутренними группами символа. Пользовательские импортированные SVG остаются отдельными ресурсами библиотеки и не исполняют скрипты.

## 3. Привязка точек и логика

Для заслонки и вентилятора доступны роли `feedback` и `value`. Приоритет отдаётся `feedback`, затем используется `value`.

Состояние считается включённым только при `quality == GOOD` и значении:

- `1`, `true`, `ON`, `OPEN`, `RUN`, `RUNNING`, `ACTIVE`, `ВКЛ`, `ОТКРЫТ`, `ОТКРЫТО` — ВКЛ;
- `0`, `false`, `OFF`, `CLOSED`, `STOP`, `STOPPED`, `INACTIVE`, `ВЫКЛ`, `ЗАКРЫТ`, `ЗАКРЫТО` — ВЫКЛ;
- числовые значения выше `0.5` — ВКЛ, ниже или равные `0.5` — ВЫКЛ.

Если качество не `GOOD`, состояние считается неопределённым/выключенным и анимация не запускается.

Воздушный поток показывается только при выполнении обоих условий:

`FanRunning == true AND OutdoorDamperOpen == true`

Вентилятор вращается по своему состоянию. Заслонка открывается по собственной обратной связи. Поток не показывается при остановленном вентиляторе или закрытой заслонке.

Снимок точек запрашивается Workbench каждые 1,5 секунды. Перерисовка выполняется только при изменении value/quality/timestamp.

## 4. Безопасность

- Анимация только визуализирует данные.
- Командная запись в контроллер не включается.
- Локальный предпросмотр ВКЛ/ВЫКЛ использует локальное состояние страницы и не вызывает API записи в поле.
- Для `prefers-reduced-motion: reduce` бесконечные анимации отключаются.
- API создания демонстрационной схемы защищён тем же loopback-only guard, что и остальные операции изменения Workbench.

## 5. API

`POST /api/stations/{station_id}/graphics/ahu-demo`

Создаёт документ Graphics размером 2050×720 и сохраняет семь секций с единой координатной сеткой и последовательностью слева направо. API не запускает Runtime, драйверы и полевые команды.

`GET /api/graphics/library` включает все 66 символов, в том числе новые семь секций. Каждый SVG доступен по `svg_url` соответствующего символа.

## 7. Границы готовности

DEV67 обеспечивает SVG-геометрию, демонстрационную компоновку, привязку к точечным значениям и UI-анимацию. Это не подтверждает готовность циклического Runtime, живого BACnet/Modbus опроса, физического управления, публикации или RBAC. Для фактической анимации на реальном объекте Core должен получать и обновлять значения точек от рабочего драйвера/Runtime.
