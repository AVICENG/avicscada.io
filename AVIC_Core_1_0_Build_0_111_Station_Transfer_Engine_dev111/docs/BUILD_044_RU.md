# AVIC Core 1.0 — DEV44 Web Pages & Unified Editor

## Назначение
DEV44 добавляет в DEV43 локальную инженерную среду управления Web Pages. Данные страниц хранятся в SQLite через существующий репозиторий AVIC Core; каждая страница и папка принадлежит конкретной станции.

## Реализовано
- Отдельное рабочее место `/pages`, доступное также через меню «Инженерия → Web Pages · Unified Editor».
- Иерархия Site → Folder → Page с сохранением узлов, чтением дерева, созданием и удалением.
- Переименование узлов, перемещение между сайтами/папками через меню узла или drag-and-drop.
- Slug папок также сохраняется и проверяется на конфликт; сайты остаются корневыми узлами, страницы и папки требуют родителя.
- Рекурсивное удаление папки/сайта с удалением дочерних узлов в правильном post-order.
- URL-адреса страниц из slug и slug папок; транслитерация русских названий папок; валидация slug страницы и запрет одинаковых slug в одной папке.
- Редактор HTML, CSS и JavaScript; исходники хранятся в модели страницы.
- Изолированный предпросмотр через iframe `sandbox="allow-scripts"`; пользовательский JS предпросмотра не получает same-origin-доступ к Workbench.
- Визуальная рабочая область с текстовыми блоками и перетаскиваемыми блоками размещения мнемосхем.
- Назначение и снятие мнемосхем на странице; межстанционная привязка запрещена. Существующая GraphicsService сохраняет привязки элементов мнемосхем к точкам и проверяет принадлежность точки той же станции.
- Optimistic concurrency по revision; аудит создания, изменения, перемещения, удаления и привязки мнемосхем.
- Защита изменяющих API локальным ограничителем Workbench (loopback + Origin), соответствующим текущей DEV43. Это не полноценная пользовательская аутентификация.
- Исправлена загрузка списка станций в Graphics Workbench и добавлено открытие конкретной мнемосхемы по ссылке из Web Pages.
- Исправлен маршрут выбора узла в основном инженерном дереве: обработчик выбора в capture phase; кнопка `···` видима постоянно и имеет отдельную зону нажатия; сохранены обработчики контекстного меню и двойного щелчка.

## API
- `GET /api/stations/{station_id}/web-pages`
- `POST /api/web-pages`
- `GET /api/web-pages/{node_id}`
- `PUT /api/web-pages/{node_id}`
- `POST /api/web-pages/{node_id}/move`
- `DELETE /api/web-pages/{node_id}?expected_revision=N`
- `POST /api/web-pages/{node_id}/graphics`
- `DELETE /api/web-pages/{node_id}/graphics/{graphic_id}?expected_revision=N`

## Сценарий инженера
1. В Workbench создать проект и станцию.
2. Открыть «Инженерия → Web Pages · Unified Editor».
3. Выбрать станцию; создать Site, затем Folder и Page.
4. Для страницы задать имя и slug. Адрес отображается в верхней панели.
5. Во вкладке «HTML / CSS / JS» внести код и нажать «Сохранить».
6. Во вкладке «Визуальный редактор» добавить текстовые блоки, перетащить их и сохранить.
7. Во вкладке «Мнемосхемы и привязки» назначить мнемосхему. Для редактирования графических элементов и точечных привязок открыть существующий редактор Graphics.
8. Проверить страницу во вкладке «Предпросмотр».
9. Для изменения структуры перетащить узел на Site/Folder или открыть `···` и выбрать действие.

## Ограничения и безопасность
- Это инженерный authoring/workbench, не production web hosting.
- Публичная публикация, IP/domain binding, TLS/сертификаты, customer login, session management, MFA и серверный RBAC не реализованы в DEV44. Публикация явно выключена в API.
- Веб-страницы не имеют публичного маршрута просмотра и не должны выставляться в интернет.
- JS выполняется только в sandbox preview, но перед промышленной публикацией всё равно потребуется отдельная модель безопасных компонентов, CSP, sanitizer, asset pipeline и threat-model review.
- Визуальный редактор DEV44 поддерживает позиционирование простых блоков и блоков-ссылок на мнемосхемы; полноценный responsive layout designer, breakpoint editor, reusable components, nav builder, alarm/event widgets и живое runtime data rendering — следующие этапы.
- Команды управления оборудованием из Web Pages не поддерживаются; field writes остаются выключенными.
- Требуется отдельная ручная Windows-приёмка интерфейса (клики, `···`, правый клик, двойной клик, resize, drag-and-drop) перед признанием UX-приёмки завершённой.

- `python -m compileall -q avic_core` — успешно.
- `python -m pytest -q` — 223 passed.
- `node --check` для JS из `index.html` и `pages.html` — успешно.
- `python -m pip check` — внешнее несоответствие окружения: `moviepy 2.2.1` требует `pillow<12`, установлена `pillow 12.3.0`; не вызвано зависимостями AVIC Core.

## Статус
DEV44 — функциональная инженерная сборка авторинга Web Pages с проверенными backend CRUD/перемещением/URL/привязкой мнемосхем и локальным UI. Не является production-ready публикационной платформой или готовой защищённой клиентской веб-панелью.
