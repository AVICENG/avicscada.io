# DEV42 — Постоянная навигация AVIC Workbench

Левая узкая панель основных разделов остаётся на экране во всех рабочих разделах, включая отдельную страницу Graphics Workbench. Инженерное дерево и инспектор свойств — независимые панели: дерево можно скрыть, освобождая место рабочей области, при этом навигационные иконки остаются доступны. Состояния панелей запоминаются браузером.

## Проверка инженером на Windows
1. Установить wheel DEV42.
2. Запустить Web Workbench штатной командой из инструкции установки.
3. Проверить, что слева остаётся узкая панель иконок.
4. Нажать кнопку дерева вверху панели: дерево должно скрыться, а рабочая область расшириться.
5. Перейти в «Мнемосхемы», «FBD / Logic», «Сети», «Устройства» — узкая панель должна оставаться на месте.
6. Обновить страницу и проверить сохранение состояния дерева.
7. Проверить независимое скрытие инспектора.
8. Открыть редактор мнемосхем: постоянная панель должна оставаться видимой и обеспечивать возврат к основным разделам.

## Ограничения
DEV42 не меняет серверную авторизацию, права доступа, модель драйверов или готовность графического редактора. Контекстные меню требуют отдельного функционального аудита.
