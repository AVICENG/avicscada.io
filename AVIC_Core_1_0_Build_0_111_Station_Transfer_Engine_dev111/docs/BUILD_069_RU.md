# AVIC Core 1.0 — DEV69: FBD point integration и анализ Trend TSITE

Дата: 20.11.2026  
База: DEV68 (полный архив DEV68 содержит изменения DEV67)  
Версия пакета: `1.0.0.dev69`

## Назначение

DEV69 развивает FBD Workbench в направлении реального инженерного сценария: использование уже заведённых точек станции в функциональной схеме и навигация между страницами стратегии.

## Реализовано в коде

- Новый блок `POINT_INPUT` — источник сигнала из существующей точки AVIC.
- Перенос точки на рабочую область FBD перетаскиванием из панели «Точки станции»; также доступно добавление нажатием.
- Серверная проверка, что точка принадлежит той же станции, что и FBD-стратегия.
- Вывод типа сигнала точки из типа точки: bool, int, float, string; неизвестные типы не принимаются.
- При сохранении схемы ссылка на точку повторно проверяется на сервере.
- При симуляции точка с качеством, отличным от GOOD, блокирует вычисление. Это не позволяет использовать сомнительный сигнал в логике.
- Чтение точки выполняется без командной записи в контроллер.
- На странице отображаются маркеры To/From для межстраничных Connective; нажатие выполняет Go To на связанную страницу.
- Добавлен read-only parser формата Trend TSOM `.TSITE` XML.

## Исследованный проект Trend

Файл `Otradnoe_korp_A.TSITE` успешно разобран как XML TrendProject. Подтверждённая структура:
- 4 Site;
- 14 LAN;
- 173 Device;
- 227 Module;
- 5 351 Param.

Коды DeviceType и частоты в этом файле: `I` — 13, `C` — 50, `q` — 13, `<` — 96, `!` — 1. Эти коды сохранены как исходные идентификаторы; parser не угадывает их значение.

Параметры модулей сохраняются как исходные поля `Name`, `Type`, `Value`. Они не преобразуются автоматически в точки или блоки, поскольку для этого необходимы подтверждённые схемы устройств и семантика параметров.

## Ограничение библиотеки блоков

Текущий каталог AVIC в этой рабочей копии содержит 13 типов блоков, включая новый `POINT_INPUT`. Это не полная библиотека SET 6.3. Автоматически объявлять остальные блоки по названиям параметров или по кодам модулей нельзя.

## Что не объявляется готовым

- Полный импорт Access `.TSET` / `.TSETBak2` со стратегиями и графическими связями: файлы распознаны как Microsoft Access Jet Database, но в текущей Linux-среде отсутствует Jet/ACE или mdbtools-драйвер для извлечения таблиц.
- Полная библиотека SET 6.3: в текущей рабочей копии нет исходного архива `System Engineering Tool.zip` с `Strategy Library/*.blk2` / `*.blk3`, `Library Index.mdb` и профилями устройств. Без этих исходников нельзя достоверно заявить полный перенос всех модулей.
- Полный визуальный редактор To/From/Undefined Connective с интерактивным соединением мышью как в SET.
- Автоматическая ортогональная маршрутизация с обходом модулей и сохранением трасс.
- Sequence steps, автоматическая нумерация модулей и проверка допустимости модулей на целевом контроллере.
- Интерактивная Windows-браузерная приёмка.

## Безопасность

FBD продолжает работать в режиме `SIMULATION_ONLY`; полевые записи не выполняются. `POINT_INPUT` — только источник чтения. Контроллерные команды не создаются и не отправляются.
