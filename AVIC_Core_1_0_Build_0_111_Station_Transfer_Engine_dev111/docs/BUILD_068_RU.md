# AVIC Core 1.0 — DEV68: FBD Strategy Pages & Cross-page Connectives

**Версия:** `1.0.0.dev68`  
**База:** DEV67 AHU Modular Animation  
**Назначение:** первый архитектурный этап перестройки FBD Workbench по рабочим принципам Trend SET 6.3, без переноса закрытого кода SET.

## 1. Что реализовано

- У каждой FBD-стратегии есть сохраняемые Strategy Pages; при создании документа создаётся «Страница 1».
- Добавление, переименование и удаление страниц через API; последнюю страницу удалить нельзя.
- Блоки имеют `page_id`; принадлежность странице сохраняется при повторном открытии.
- Редактор показывает активную страницу, позволяет переключаться между страницами и выполнять базовое управление страницами.
- Межстраничный Connective связывает выходной порт блока на одной странице со входным портом блока на другой странице.
- Проверяются типы портов, принадлежность блоков/страниц одной стратегии, занятость входного порта и циклические зависимости.
- Connective сохраняется отдельно от обычного провода и участвует в offline-симуляции как межстраничная передача значения.
- Операции со страницами и Connective увеличивают ревизию документа; конфликт конкурентного сохранения остаётся защищён.
- Изменение модели не выполняет полевые записи. Режим остаётся `SIMULATION_ONLY`.

## 2. API

- `POST /api/fbd/{document_id}/pages`
- `PATCH /api/fbd/{document_id}/pages/{page_id}`
- `DELETE /api/fbd/{document_id}/pages/{page_id}`
- `POST /api/fbd/{document_id}/connectives`
- `DELETE /api/fbd/{document_id}/connectives/{connective_id}`

`GET /api/fbd/{document_id}` возвращает `pages`, `connectives`, `nodes[].page_id` вместе с графом.

## 3. Как использовать

1. Откройте или создайте FBD-стратегию.
2. В верхней панели выберите страницу либо нажмите «+ Страница».
3. Добавляйте блоки из библиотеки на активную страницу.
4. Обычные связи соединяют порты блоков внутри одной страницы.
5. Для межстраничной связи выберите исходный блок и нажмите «Создать Connective от выбранного блока». Далее выберите выход, страницу назначения, блок назначения и вход.
6. Сохраните стратегию. Межстраничные связи сохраняются сервером и учитываются offline-симуляцией.

## 4. Сопоставление с SET 6.3 и ограничения DEV68

Руководство SET 6.3 описывает Display Area, Strategy Pages, Connective/To Connective/Undefined Connective, перетаскивание Connective к входу, автоматическую маршрутизацию проводов, поиск использования узлов, sequence steps и операции с библиотекой стратегий.

DEV68 реализует модель многостраничной стратегии и межстраничную передачу значения, но пока **не является полной визуальной копией SET 6.3**. В частности, ещё не завершены:
- визуальные графические символы To/From/Undefined Connective, размещаемые непосредственно на листе;
- drag-and-drop соединение «выход → To Connective → Connective на другой странице → вход»;
- полноценная ортогональная маршрутизация с обходом модулей;
- автоматическая нумерация модулей и sequence steps;
- поиск «где используется узел», просмотр последовательности и редактор event-driven sequence;
- полноценный импорт/экспорт и редактирование Strategy Library SET-типа;
- расширенная библиотека функциональных модулей и визуальная форма модулей уровня SET.

Существующие блоки DEV67 остаются доступными. Модель FBD по-прежнему имеет ограниченный набор типов и простое карточное отображение; его нельзя считать завершённым SET-like block renderer.

## 5. Безопасность и совместимость

- Симуляция выполняется локально/офлайн и не пишет в контроллеры.
- Полевые команды остаются отключёнными.
- DEV67 graphics, SVG library, AHU sections и анимационные привязки сохранены в базе сборки.
- Перед выпуском обязательны полный pytest, compileall, проверка inline JavaScript и приёмка на Windows.

## 6. Файлы

- `avic_core/logic_fbd.py` — StrategyPage, StrategyConnective, валидация и симуляция.
- `avic_core/ui/app.py` — HTTP API страниц и Connective.
- `avic_core/ui/static/logic.html` — переключатель страниц и команды редактора.
- `tests/test_fbd_set_parity_dev68.py` — регрессионные тесты многостраничной стратегии.
