# Модульная ПВУ: эксплуатация анимации

## Добавление схемы

1. Откройте Graphics Workbench.
2. Выберите станцию.
3. Нажмите `Тестовая ПВУ · 7 секций`.
4. Будет создана последовательная схема: заслонка → фильтр → рекуператор → нагреватель → охладитель → вентилятор → открытый выходной короб.
5. Сохраните документ.

## Привязка сигналов

Выберите секцию заслонки и добавьте привязку `Обратная связь` к точке положения/состояния заслонки (или `Значение`, если отдельная feedback-точка не заведена). Для секции вентилятора аналогично привяжите feedback или value точки работы вентилятора.

Анимация запускается только при качестве `GOOD`. При `1` заслонка переводится в открытое положение; при `0` возвращается в закрытое. При `1` вентилятора вращается рабочее колесо; при `0` оно останавливается. Движение воздуха отображается, когда вентилятор включён и входная заслонка открыта.

## Локальный тест

Кнопка `Анимация: Авто` циклически переключает режимы:

- `Авто` — состояние берётся из привязанных точек;
- `Тест анимации: ВКЛ` — только локальный предпросмотр открытой заслонки, вращающегося вентилятора и потока;
- `Тест анимации: ВЫКЛ` — только локальный предпросмотр остановленного состояния.

Предпросмотр не отправляет команды в контроллер.

## Важные ограничения

Значения обновляются из point snapshot Core. Если подключённый драйвер/Runtime не обновляет точки, картинка не сможет показать физическое изменение оборудования. Командная запись из Graphics отключена. Значения не `GOOD` не считаются командой включения.
