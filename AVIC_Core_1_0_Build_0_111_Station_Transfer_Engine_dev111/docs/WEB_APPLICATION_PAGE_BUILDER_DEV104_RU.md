# AVIC Web Application — визуальный редактор страниц DEV104

## Назначение

DEV104 добавляет рабочий сценарий создания операторских Web-страниц станции из инженерного дерева. Раздел **Repository → Web Application** открывает редактор страниц. Раздел **Repository → Graphics** продолжает открывать Core Graphics Workbench; старый `pages.html` не используется как новый редактор.

## Сценарий инженера

1. В общем инженерном дереве раскрыть станцию → Repository → Web Application.
2. В редакторе создать корневой сайт. На одну станцию пока допускается один корневой сайт Web Application.
3. Создать папку/раздел и страницу. Для страницы автоматически формируется URL slug с транслитерацией русских букв.
4. Выбрать страницу в дереве. Она загружается в центральную рабочую область.
5. Добавлять элементы из библиотеки справа: заголовок, надпись, изображение, значение точки, ссылка на мнемосхему, разделитель, карточка, декоративная кнопка.
6. Перетаскивать элементы палитры на рабочую область; элементы можно перемещать мышью. Позиция, размер, текст, цвет, фон и выравнивание настраиваются в панели свойств.
7. Изображение можно загрузить с компьютера. Файл хранится как `RepositoryAsset` в общем SQLite Core Repository в области станции. Разрешены PNG/JPEG/GIF/WebP, максимум 3 МБ на файл. SVG как загружаемый файл намеренно не принимается; SVG-символы остаются в отдельной проверяемой библиотеке графики.
8. Для компонента «Значение точки» выбрать существующую точку из каталога Core. Сохраняется постоянный ID точки. Точка обязана принадлежать той же станции; неподключённый или чужой ID не допускается.
9. Сохранить черновик, открыть предпросмотр и опубликовать.
10. Опубликованная страница доступна по адресу `/published/{station_id}/{page-url}`. Опубликованный снимок не меняется при редактировании черновика. Повторная публикация создаёт новую версию. Последние 50 версий сохраняются; API поддерживает откат к выбранной версии.

## Поведение опубликованной страницы (DEV105 дополнение)

- Компонент «Мнемосхема» теперь отображается непосредственно внутри опубликованной страницы через встроенный runtime, а не как ссылка на Graphics Workbench.
- При публикации в immutable snapshot страницы сохраняется снимок GraphicDocument: геометрия элементов, выбранные символы, постоянные ID точек и конфигурации привязок. Изменение исходной мнемосхемы после публикации не меняет опубликованную страницу до повторной публикации.
- SVG-символы берутся из локальной проверенной библиотеки AVIC. Значения и статусы в мнемосхеме пересчитываются по сохранённым привязкам из общего Point Runtime раз в 2 секунды.
- Анимация вентилятора разрешается только при GOOD качестве и положительном feedback binding типа STATUS/ANIMATION. Потеря качества блокирует анимацию и выводит состояние качества.
- Runtime встроенной графики доступен только когда соответствующая мнемосхема присутствует в опубликованном снимке страницы этой же станции.


- Страница рендерится сервером из проверенной визуальной модели, а не исполняет пользовательский HTML/JavaScript.
- Текст и атрибуты экранируются; опасные URL-схемы и protocol-relative URL отклоняются.
- Для изображений из Repository действует станционная область; ресурс доступен извне только после включения в опубликованный снимок страницы.
- Значения точек читаются из общего Point Runtime станции и обновляются одним запросом каждые 2 секунды.
- При качестве, отличном от GOOD, значение не показывается как достоверное: отображается состояние качества/COMM_LOST.
- CSP запрещает произвольные скрипты и объекты; разрешён только nonce-скрипт обновления значений, необходимый опубликованной странице.
- Публикация, загрузка и изменение выполняются через local-operator guard Workbench. Это временный локальный контур, а не законченная многопользовательская RBAC-модель.

## Ограничения DEV104 — не считать реализованным

- Это визуальный Page Builder, не полноценный файловый Web IDE: нет отдельных пользовательских `index.html`, CSS/JS-файлов, маршрутизатора SPA, редактора исходного HTML/CSS/JS и импорта ZIP-сайта.
- Нет папок/файлов произвольных типов и менеджера шрифтов/видео; загрузка ограничена растровыми изображениями.
- Кнопка на странице декоративная. Запуск/останов оборудования, уставки и ручной режим не подключены к Page Builder; для этого потребуется интеграция с Core Command Manager, server-side RBAC, lease/подтверждениями и read-back.
- Публикация пока станционная локальная внутри текущего Workbench, без внешнего reverse proxy/HTTPS deployment, публичного домена, клиентского RBAC и workflow согласования.
- История хранит до 50 снимков публикаций на страницу; это не полноценная система управления версиями всех файлов приложения.

## Дополнение DEV105: embedded Graphics Runtime API

- `GET /published-graphics/{station_id}/{document_id}?page_id={page_id}` — отображение сохранённого снимка мнемосхемы внутри опубликованной страницы.
- `GET /published-graphics/{station_id}/{document_id}/bindings?page_id={page_id}` — вычисление сохранённых привязок из live Point Runtime; конфигурация берётся из снимка публикации, а не из текущего черновика мнемосхемы.


- `GET /api/stations/{station_id}/web-pages` — дерево страниц.
- `POST /api/web-pages` — создание сайта/папки/страницы.
- `GET /api/web-pages/{node_id}` / `PUT /api/web-pages/{node_id}` — чтение/сохранение с optimistic revision.
- `POST /api/stations/{station_id}/repository-assets` — загрузка растрового изображения (raw body, MIME в Content-Type, имя в query `filename`).
- `GET /api/stations/{station_id}/repository-assets` — список изображений станции.
- `GET /api/repository-assets/{asset_id}` — выдача изображения.
- `POST /api/web-pages/{node_id}/publish` — публикация снимка.
- `POST /api/web-pages/{node_id}/rollback` — публикация выбранного предыдущего снимка.
- `POST /api/web-pages/{node_id}/unpublish` — снять страницу с публикации.
- `GET /published/{station_id}/{page_path}` — опубликованная операторская страница.

## Хранение и безопасность

WebPageNode и RepositoryAsset хранятся в существующем Core Repository, с `station_id` scope. Отдельная файловая БД не создаётся. Сохранение страницы использует optimistic concurrency. Привязки значений и загруженные изображения проверяются на принадлежность той же станции. Удаление/перемещение/аудит наследуют текущие ограничения WebPagesService; полная server-side RBAC ещё не завершена.
