# Направление архитектуры: будущие контроллеры AVIC на Linux

## Решение по продукту
TONN/TONN8 рассматривается как полезный архитектурный ориентир для будущего семейства собственных контроллеров AVIC на Linux, а не как обязательная зависимость или требование копировать закрытый протокол Trend. Совместимость с TONN/TONN8 не заявляется.

## Предлагаемая модель
- AVIC Core — верхний уровень: проекты, станции, инженерные объекты, пользователи, аудит, история, аварии и расписания.
- Linux Controller Agent — отдельный сервис на контроллере; запускается как управляемая служба ОС, имеет собственный watchdog и журнал.
- Northbound Controller Protocol — документированный версионируемый протокол обмена между Core и агентом.
- Southbound Drivers — отдельные драйверы оборудования на контроллере (BACnet/IP, Modbus TCP и будущие протоколы), изолированные от основного процесса агента.
- Point/Asset Model — единые идентификаторы, типы, единицы, качество, timestamp, происхождение и состояние связи.

## Обязательные требования до реализации
1. Взаимная аутентификация и TLS с ротацией сертификатов; никаких общих заводских паролей.
2. Явная регистрация/привязка контроллера к установке и станции; отзыв и повторная регистрация.
3. Согласование версий протокола и возможностей, без молчаливого downgrade.
4. Store-and-forward для событий/истории при потере связи, ограничение диска и контроль целостности.
5. Heartbeat, watchdog, диагностика ресурсов, время/NTP и статус качества данных.
6. Разделение телеметрии и команд; команды только через отдельный авторизованный путь с lease, interlocks, audit, expiry и подтверждением результата.
7. Локальная автономность: потеря связи с Core не должна останавливать локальные безопасные контуры управления.
8. Подписанные обновления, A/B или атомарное обновление, rollback и проверка совместимости.
9. Минимальная поверхность атаки, firewall allowlist, secure boot где доступно, секреты в системном хранилище.
10. Полная симуляция и аппаратная стендовая приёмка до production.

## Не делать сейчас
Не объявлять TONN протоколом AVIC; не обещать совместимость; не добавлять фиктивный TONN-драйвер в рабочий каталог; не разрешать удалённое управление до готовности command security и interlocks.

## Статус DEV57
