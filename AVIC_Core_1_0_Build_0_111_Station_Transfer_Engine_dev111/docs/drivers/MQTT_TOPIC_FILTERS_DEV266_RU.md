# MQTT Topic Filters в AVIC — DEV266

AVIC принимает MQTT Topic Filter, а не только точные имена тем.

## Поддерживаемые правила

| Filter | Topic | Результат |
|---|---|---|
| `plant/+/temp` | `plant/ahu/temp` | совпадение |
| `plant/+/temp` | `plant/ahu/zone1/temp` | нет совпадения |
| `plant/#` | `plant` | совпадение |
| `plant/#` | `plant/ahu/temp` | совпадение |
| `#` | `$SYS/broker/uptime` | нет совпадения |
| `$SYS/#` | `$SYS/broker/uptime` | совпадение |

- `+` заменяет ровно один уровень, в том числе пустой.
- `#` заменяет ноль или более уровней и допускается только последним сегментом.
- Wildcard должен занимать сегмент целиком: `plant/+/temp` допустим, `plant/ahu#` запрещён.
- Wildcard-фильтры не захватывают системные темы, начинающиеся с `$`, если сам фильтр не начинается с `$`.

## Маршрутизация

Один принятый MQTT sample сопоставляется со всеми настроенными bindings, чьи фильтры совпали с topic. Каждая точка проходит собственное декодирование JSON/raw и scaling, после чего публикация выполняется только через общий Point Runtime.

## Границы этапа

Matcher и Python-side маршрутизация реализованы. Сам Paho C Worker ещё не подключён к брокеру; native MQTT subscribe/receive и end-to-end IPC acceptance — отдельный следующий этап.
