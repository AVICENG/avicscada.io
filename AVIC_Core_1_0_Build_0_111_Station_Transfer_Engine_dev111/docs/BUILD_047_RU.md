# AVIC Core 1.0 — DEV47: Scheduler Manager Foundation

## Цель
Перевести направление Scheduler из навигационного макета в первую работающую вертикальную подсистему Core и встроить её рабочее место в основную инженерную оболочку.

## Реализовано
- Отдельный persistent `ScheduleService` и SQLite-хранилище `schedules.sqlite3`.
- Типы расписаний BOOLEAN, NUMERIC, ENUM, STRING со строгой проверкой значений.
- Недельные события по дням недели с минутной точностью; проверка пересечения интервалов.
- Календарные исключения на дату или диапазон дат, временной интервал и приоритет 1–16.
- Конфликт одинакового приоритета для пересекающихся исключений блокируется.
- Разрешение эффективного значения: временный ручной override → специальное календарное событие → недельное событие → Default.
- Override имеет обязательные actor/reason и ограниченный срок (до 7 дней).
- Вычисление локального времени с IANA timezone, действующего источника, следующего реального переключения и следующего значения.
- Оптимистическая проверка ревизий при редактировании событий.
- Привязка совместимых выходных/двунаправленных точек той же станции; входные точки и несовместимые типы отклоняются.
- Запись создания/изменений/привязок/override в AuditService.
- API CRUD для расписаний, weekly events, special events, bindings, override и evaluate.
- Встроенное рабочее место Scheduler в основном Workbench: создание, список, недельные события, исключения, вычисление текущего результата, привязки и временный override.

## Критическая граница безопасности
Scheduler в DEV47 формирует **schedule intent**, но не пишет в значения Point и не отправляет команды контроллерам. В ответе API это явно обозначено `INTENT_ONLY_NO_FIELD_WRITE`. Физическое управление появится только после отдельного Command Manager с арбитражем приоритетов, interlock, подтверждением, read-back и журналированием.

## Ограничения DEV47
- Нет полноценной 24-часовой drag/resize-сетки; интерфейс пока использует редактируемый список интервалов.
- Нет годовых/ежегодных календарных правил, ссылок на отдельные Calendar objects и календарных шаблонов.
- Нет Schedule Selector и Trigger Schedule.
- Нет периодической фоновой оценки расписаний; вычисление выполняется по запросу API/Workbench.
- Нет доставки расписания в контроллеры и нет автоматической записи в Point.
- UI пока не реализует Copy Day / Paste Day / Apply M-F.
- Не выполнена браузерная приёмка на Windows в этой среде.

- `node --check` для inline JavaScript основного Workbench: успешно.

- Scheduler service tests: типы, конфликты, ревизии, timezone, приоритеты, override, persistence, next change и point binding.

## Статус
**Scheduler Core MVP реализован и покрыт автоматическими тестами. Scheduler как законченная промышленная подсистема ещё не готов:** требуется полноценная сетка редактора, recurring calendar, selector/trigger, циклический runtime, Command Manager и Windows browser acceptance.
