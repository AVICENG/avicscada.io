# AVIC Core 1.0 — DEV77: Unified Engineering Tree + FBD Studio 1.1.1

**База:** DEV69 + сохранённый исходник AVIC FBD Studio 1.1.1  
**Версия пакета:** `1.0.0.dev77`  
**Назначение:** заменить старый экран `/logic` новым FBD Studio и встроить его в единое инженерное дерево AVIC.

## 1. Что сделано

- Старый HTML-редактор DEV69 на маршруте `/logic` заменён интерфейсом AVIC FBD Studio 1.1.1.
- Сохранены возможности нового Studio: перемещение блоков, соединение портов, удаление выбранного блока/связи, страницы, межстраничные Connective, свойства, Tracker, контекстные команды, Undo/Redo, локальная симуляция и экспорт пакета.
- Левая панель получает актуальную иерархию через Core API `/api/engineering/tree`:
  `Проект → Станция → Сеть → Протокол → Устройство → Точки`.
- Под выбранной станцией отображается ветка FBD: FBD-проект → страницы → FBD Points.
- При переходе между станциями редактор загружает отдельный серверный FBD Studio документ этой станции.
- Точки из Core Point Catalog фильтруются по `station_id`; дерево показывает реальные точки с текущим значением и качеством. Точку можно перетащить на лист или добавить двойным щелчком.
- В `EngineeringTreeService` и `PointViewService` добавлены направление и тип точки, чтобы редактор не терял различие INPUT/OUTPUT при импорте.
- Меню, toolbar, контекстные меню, дерево и панели приведены к светлой визуальной системе основного AVIC Workbench.
- FBD Studio документ сохраняется в Core SQLite через отдельный `FBDStudioService`, с привязкой к станции, ревизиями и optimistic concurrency. `localStorage` остаётся только локальной резервной копией/миграционным источником.
- Для серверного FBD Studio документа введены лимиты: 8 MiB, 250 страниц, 5 000 модулей, 10 000 связей.

## 2. Разделение авторинга и исполнения

Серверный `FBDStudioDocument` хранит полную авторскую модель Studio 1.1.1. Он явно помечается `document_kind=authoring-only`, `runtime_compiled=false`. Это не подмена Core LogicDocument/LogicNode и не заявление о том, что все блоки Studio уже имеют подтверждённые исполняемые формулы в Core.

Локальная симуляция Studio остаётся автономной. Полевые записи BACnet/Modbus не выполняются. Перенос каждого поддерживаемого блока и связи в компилируемый Core-граф, compile diagnostics и безопасная staged publish остаются отдельным следующим этапом интеграции.

## 3. Изменённые ключевые файлы

- `avic_core/ui/static/logic.html` — новая поверхность FBD Studio 1.1.1, единое дерево AVIC, Core Point Catalog, autosave.
- `avic_core/logic_fbd_studio.py` — серверное хранение авторских документов, валидация размера/структуры и ревизии.
- `avic_core/ui/app.py` — API list/create/get/save FBD Studio.
- `avic_core/ui/engineering_tree.py` — направление и тип точки в дереве.
- `avic_core/domain/point_views.py` — направление точки в каталоге.
- `tests/test_fbd_studio_persistence_dev77.py` — новые проверки API и маршрута `/logic`.
