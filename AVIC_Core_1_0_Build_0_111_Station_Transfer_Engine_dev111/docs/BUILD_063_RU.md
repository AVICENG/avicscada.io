# AVIC Core 1.0 — DEV63 Parity30, Regression Guards & UI Refinement

## Основа

DEV63 создана копированием полного исходного дерева DEV62. Это надстройка, не пересборка с нуля. Исторические документы и тесты DEV49–DEV62 сохранены. Версия пакета/API: `1.0.0.dev63`.

## Что добавлено

1. `docs/IQVISION_FIRST_30_PARITY_RU.md` — сравнение 20 глав Configuration Manual + приложений A1–A10 (позиции 21–30), с явным отделением Trend optional и будущего TONN/Linux Agent.
2. Общая высококонтрастная тема в четырёх Workbench entrypoints: белый/светло-серый фон, чёрный тонкий текст, нейтральные серые выделения, синий инженерный акцент, цветные статусы на нейтральной подложке; зелёные выделения заменены.
3. Release-guard tests для доступности четырёх UI маршрутов, применения общей темы, сохранности ключевых модулей и API route inventory.
4. Исправлен 500 при некорректном UUID в `GET /api/web-pages/{node_id}`: теперь контролируемый HTTP 400.
5. Release guards обходят все 45 GET API routes и 55 mutation method routes с безопасными probe-данными; внутренние ссылки всех четырёх HTML редакторов проверяются.
6. Версия API/package обновлена до DEV63; исторические сборки в документации не переписаны.

## Что НЕ объявляется реализованным

DEV63 не реализует автоматически все пропуски A2–A10. В частности, IQ4 B-BC, support bundle, lexicon editor, resource manager, printing, SQL history export, history CSV export и полный Application Director остаются gap items в матрице. В сборку добавлены их проверяемые требования и release gates, а не фиктивные рабочие экраны.

## Проверки

Результаты приведены в `BUILD_TEST_LOG_DEV63_RU.md`. Все 30 960 собранных тестов прошли в трёх непересекающихся запусках; единый запуск pytest превысил лимит 600 секунд на ~74%, поэтому не считается завершённым полным прогоном. Windows и браузерная приёмка остаются обязательными внешними этапами.
