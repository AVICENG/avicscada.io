# SVG-библиотека AVIC — DEV64

## Что это

Встроенная библиотека из 28 отдельных SVG-ресурсов. Это не набор unicode-значков и не 8 типов, нарисованных условными JavaScript-фигурами: каждый символ хранится отдельным `.svg`-файлом в `avic_core/ui/static/svg-library/`.

## Использование

1. Запустите AVIC Workbench.
2. Откройте меню **Инженерия → SVG-библиотека символов**.
3. В Graphics Editor выберите станцию и существующую мнемосхему либо создайте новую.
4. Найдите символ поиском или выберите категорию.
5. Нажмите символ либо перетащите миниатюру на холст.
6. Настройте положение, размер, угол, имя и привязки к точкам.
7. Сохраните мнемосхему.

## Категории

| Категория | Символы |
|---|---|
| Вентиляция | Приточная установка, вентилятор, фильтр, нагреватель, охладитель, рекуператор |
| Насосное оборудование | Циркуляционный, вертикальный, линейный насос |
| Арматура | Запорный клапан, регулирующий клапан, трёхходовой клапан, заслонка |
| Датчики и измерение | Датчик, датчик температуры, датчик давления, датчик расхода, термометр, манометр |
| Тепло и холод | Теплообменник, котёл, чиллер, компрессор |
| Ёмкости и резервуары | Расширительный бак |
| Трубопроводы | Трубопровод, отвод 90°, тройник, воздуховод |

## Контракт и безопасность

Метаданные доступны через `GET /api/graphics/library`, а содержимое ресурса — через `GET /api/graphics/library/{symbol_id}/svg`. ID символа — стабильный ключ, который хранится в `GraphicElement.symbol_key`.

Endpoint отдаёт только SVG из встроенного allowlist и выставляет `X-Content-Type-Options: nosniff`. Произвольная загрузка пользовательского SVG в DEV64 отсутствует. Это намеренное ограничение до готовности отдельного SVG sanitizer и проверки внешних ссылок, скриптов, обработчиков событий и активного содержимого.

## Что ещё не готово

Нет пользовательского менеджера загрузки/редактирования библиотеки, Include/графических шаблонов, импорта внешних пакетов символов и клиентской публикации. Наличие SVG на редакторском холсте само по себе не означает Runtime-анимацию или управление оборудованием.
