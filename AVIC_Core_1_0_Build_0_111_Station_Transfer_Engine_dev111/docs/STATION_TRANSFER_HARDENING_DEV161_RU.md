# DEV161 — усиление проверки Station Transfer

## Изменения

- Проверка ссылок инженерных сущностей теперь выполняется на этапе inspect, до staging, а не только при экспорте/финальном импорте.
- Добавлена проверка ссылок вспомогательных хранилищ: dependencies, time management, schedules, schedule bindings, custom SVG, point tags и point hierarchy.
- Проверяются принадлежность вспомогательных строк импортируемой станции и существование целевых сущностей/точек/расписаний.
- Идентификатор пакета SHA-256 вычисляется потоково блоками по 1 МиБ; архив не читается целиком в память только ради хеша.
- Добавлены негативные тесты на повреждённые ссылки вспомогательных таблиц.

## Ограничения

- Проверка SHA-256 подтверждает целостность содержимого относительно манифеста, но не подлинность издателя.
- Криптографическая подпись издателя и цепочка доверия ещё не реализованы.
- Site Binding/Commissioning, автоматическое сопоставление оборудования и удалённое развёртывание остаются отдельными этапами.

## Приёмка

Полный CI для актуального коммита должен пройти на Windows и Linux. До завершения матрицы DEV161 не считается принятым.
