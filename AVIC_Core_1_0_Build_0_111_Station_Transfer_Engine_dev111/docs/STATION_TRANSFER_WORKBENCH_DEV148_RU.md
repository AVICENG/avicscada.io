# DEV148 — Безопасный сценарий Station Transfer в Workbench

## Реализовано
- Отдельная страница Workbench «Перенос и клонирование станции».
- Каталог исходных станций и целевых проектов.
- Экспорт `.avicstation` только при остановленном Station Runtime и остановленных драйверах.
- Загрузка пакета потоково, без передачи серверного пути от клиента; предел размера — 512 МБ.
- Проверка структуры ZIP, контрольной суммы, количества объектов, ссылок и совместимости версии Core.
- Явное предупреждение о неподписанном пакете и отдельное подтверждение инженера.
- Изолированный staging и повторная проверка пакета до commit.
- Раздельные действия «Перенос» и «Клонирование», отдельное финальное подтверждение IMPORT/CLONE.
- Клон получает новые идентификаторы сущностей, SVG, расписаний, FBD-узлов и графических элементов; внутренние ссылки переназначаются.
- Импортированная станция регистрируется в Runtime как STOPPED и остаётся NOT_ACTIVATED.
- Станция не запускается автоматически; драйверы и каналы не стартуют, команды контроллерам не отправляются.
- Временные токены истекают через 15 минут, максимум 16 незавершённых операций. После перезапуска Workbench staging очищается.

## Защитные ограничения
- Все изменяющие операции и каталог доступны только с loopback; Origin проверяется по точному hostname.
- Сервер сам генерирует имена файлов и случайные токены; пути файлов от клиента не принимаются.
- Пакет не имеет цифровой подписи издателя. SHA-256 проверяет целостность относительно манифеста, но не доказывает подлинность издателя.
- Несовместимая версия Core блокирует staging; автоматическая миграция не выполняется.
- Секреты, runtime history, журналы и лицензии не переносятся.
- Адреса устройств, native identity, NTP и разрешения синхронизации очищаются экспортным профилем.
- Система не выполняет site binding, запуск драйверов и команды полевому оборудованию.

## Не заявляется как готовое
- Криптографическая подпись издателя и цепочка доверия.
- Полноценный серверный RBAC/SSO; в этой сборке действует локальный loopback guard.
- Автоматический Deployment Manager и удалённое развёртывание.
- Автоматическое сопоставление оборудования и commissioning на новой площадке.
