# AVIC Core 1.0 — DEV50

## Назначение сборки

DEV50 укрепляет проверяемость DEV49: добавлена расширенная матрица поведенческих проверок сервисов, исправлен штатный запуск Workbench из командной строки, зависимости разработки включают Uvicorn и tzdata.

## Изменения

- Версия пакета: `1.0.0.dev50`.
- Добавлен `tests/test_iqvision_matrix_1000_dev50.py`: 1164 параметризованных сценария по журналу событий, истории значений и качеству данных, алгоритмам rollup, графу зависимостей, маршрутам уведомлений, тегам/иерархии точек и агрегированию.
- Исправлен запуск `python -m avic_core.ui`: аргументы командной строки `--host`, `--port`, `--data-dir`, `--reload`; приложение запускается через Uvicorn.
- `uvicorn` и `tzdata` добавлены в набор `dev`; `tzdata` добавлена в основные зависимости для одинакового поведения IANA time zones на Windows.
- Добавлена русская инструкция `INSTALL_DEV50_RU.txt`.

## Контроль тестов

- Собрано pytest: **1417 тестовых случаев** (253 теста базового набора DEV49 + 1164 новых параметризованных; точное число фиксируется командой `python -m pytest --collect-only -q`).
- Новая матрица: **1164 passed**.
- Полный прогон в среде подготовки был прерван внешним лимитом времени после отображения 96% прогресса; полный результат не заявляется как успешный. Полный прогон необходимо выполнить в Windows-папке пользователя.

## Важные ограничения

DEV50 не объявляет IQVISION parity достигнутым. Текущий DEV49 UI имеет отдельные рабочие страницы и API, но не обеспечивает полный единый редактор PX/графики, полноценный Wiresheet/FBD, palette binding, полный Point Database Manager, Alarm Classes/Portal и законченный Security/ESignature workflow. Сверенная карта пробелов находится в `docs/IQVISION_PARITY_MATRIX_RU.md`.
