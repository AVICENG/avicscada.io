# DEV54 — Разработчик мнемосхем и привязки точек

## Основание по IQVISION
IQVISION Configuration Manual v2.30, §13 «Create Schematics (PX Pages)»: создание PX-страниц, размер/фон, элементы, динамический текст, анимированная графика, привязка точек, повторное использование и Easy Graphics Tools. Также учтена пользовательская модель страниц из §4 User Manual.

## Что реализовано
- Отдельный Graphics Workbench, встроенный в инженерную среду.
- Создание и повторное открытие станционных документов мнемосхем.
- HVAC-библиотека: насос, вентилятор, клапан, заслонка, датчик, теплообменник, ёмкость, трубопровод.
- Готовый шаблон «Тестовая приточная установка»: вентилятор ПВ-1, фильтр, обратный клапан, датчик, теплообменник и участок воздуховода.
- Привязки по ролям value, feedback, alarm, quality. Командная запись запрещена.
- Список точек показывает драйвер и его состояние, протокол, адрес устройства, имя устройства/точки, тип, единицу, текущее значение и качество.
- Привязанное значение и цвет качества выводятся рядом с символом. GOOD — зелёный, UNCERTAIN — янтарный, прочие состояния — красный.
- Привязка мнемосхемы к Web Page и сохранение структуры страниц остаются в общем Web Pages Editor.
- Полная предварительная проверка документа перед транзакцией: ID, принадлежность документа, уникальность ID/ролей, типы символов, числовые значения, конечность чисел, размеры, координаты в пределах холста, слой, число привязок и принадлежность точки станции.
- Оптимистическая блокировка по revision и атомарная запись. Ошибка в любом элементе не должна частично менять документ.

## Что проверять вручную
1. Создать проект и станцию.
2. Открыть «Мнемосхемы» и нажать «Тестовая ВУ».
3. Выбрать вентилятор ПВ-1, добавить точку из BACnet/Modbus/Trend-импорта в роль «Значение».
4. Сохранить, закрыть/открыть мнемосхему, убедиться в сохранении привязки.
5. Создать сайт/папку/страницу в «Страницы», назначить ей мнемосхему и сохранить страницу.
6. Проверить отказ для точки другой станции, повторной роли, команды, дублирующего ID, NaN/Infinity и выхода за границы холста.

## Ограничения и честный статус
- Это инженерный редактор и визуализация значений, уже присутствующих в модели точек. DEV54 не заявляет о полноценном цикле live polling полевых BACnet/Modbus/Trend-драйверов.
- Нет записи в контроллеры, слайдеров и кнопок регулирования: безопасная read-only политика сохранена.
- Нет полноценной PX-совместимости Niagara: отсутствуют image assets/palettes, динамические анимированные SVG-состояния, графики истории, расписания, dashboards, relativisation, Easy Widgets и Palette Builder.
- Страница создаётся в Web Pages Editor; отдельный механизм publish/production route не включён.
- Не использовать как систему управления действующим инженерным объектом до подключения и полевой приёмки Runtime/драйверов/RBAC.
