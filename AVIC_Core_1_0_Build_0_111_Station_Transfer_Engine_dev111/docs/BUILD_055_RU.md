# AVIC Core 1.0 — DEV55: FBD и связь с мнемосхемами

База: DEV54. Руководство-ориентир: IQVISION Configuration Manual v2.30, §13 (PX/Schematics) и связанные разделы инженерной логики/Wiresheet. DEV55 закрывает первый сквозной вертикальный сценарий FBD → мнемосхема, но не заявляет полную функциональную паритетность Niagara/IQVISION.

## Реализовано

- Отдельная сохраняемая FBD-схема с ревизией и optimistic concurrency.
- Каталог из 9 типизированных блоков: BOOL/FLOAT Input, AND, OR, NOT, ADD, COMPARE_GT, BOOL/FLOAT Output; категории Digital, Analog, Logic, Math, Compare, Data.
- Редактор `/logic`: добавление блоков из библиотеки, перемещение по полотну, редактирование имени и входных значений, соединение выходов со входами, отображение проводов, сохранение и симуляция.
- Валидация до записи: типы портов, направление связи, занятые входы, повторные/чужие ID, отсутствующие блоки и порты, лимиты графа, конечность и границы координат, циклические зависимости.
- Детерминированная симуляция с временными overrides входов. Симуляция не меняет сохранённые входы и не пишет в контроллер.
- Шаблон логики вентилятора ПВ-1: `Команда Пуск AND Защита исправна → Разрешение ПВ-1 → Вентилятор RUN`.
- Персистентная связь BOOL-выхода FBD со знаком вентилятора на мнемосхеме той же станции. Связи видны после повторного открытия мнемосхемы.
- В редакторе мнемосхем добавлен выбор FBD-схемы и BOOL-выхода для вентилятора.
- Навигация Workbench открывает FBD Workbench с контекстом выбранной станции.

## Безопасность и ограничения

- FBD в DEV55 — инженерная модель и симулятор, не runtime-контроллер.
- Нет deploy/publish FBD в реальный runtime, циклического task scheduler, online watch, hot reload и field writes.
- Библиотека пока базовая (9 блоков), не все 16 запланированных категорий и не весь набор Niagara/IQVISION.
- Нет таймеров, счётчиков, PID, расписаний, macros/subcharts, пользовательских блоков, версии/пакетирования библиотек и AI Builder.
- Привязка FBD→символ сохраняет ссылку и проверяет тип BOOL/станцию/тип символа; live-обновление SVG от результата симуляции пока не реализовано.
- Windows acceptance и реальная OT-проверка не выполнены.

## API

- `GET /api/fbd/library`
- `GET|POST /api/stations/{station_id}/fbd`
- `POST /api/stations/{station_id}/fbd/fan-demo`
- `GET|PUT /api/fbd/{document_id}`
- `POST /api/fbd/{document_id}/simulate`
- `POST /api/fbd/graphics-bindings`

Изменяющие API доступны только локальному оператору Workbench. Запись в OT не предусмотрена.
