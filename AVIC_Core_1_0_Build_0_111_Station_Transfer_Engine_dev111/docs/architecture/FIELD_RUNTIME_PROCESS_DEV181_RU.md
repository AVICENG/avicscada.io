# DEV181 — проверка переживания остановки Supervisor

DEV181 добавляет интеграционный тест границы процессов: Supervisor запускается во временном дочернем процессе, публикует PID отдельного Field Runtime agent и завершается. Тест проверяет, что агент остаётся жив после завершения родительского процесса и закрытия его IPC listener.

Это проверка только уровня ОС-процесса. Она **не доказывает**:
- переподключение агента к новому экземпляру Supervisor;
- сохранение конфигурации endpoint/учётных данных после рестарта Supervisor;
- работу FBD-движка, циклов управления или полевых выходов;
- watchdog, автозапуск службы Windows/Linux или отказоустойчивость контроллера.

Текущая архитектурная проблема остаётся: endpoint и token создаются в памяти экземпляра Supervisor. После его полного завершения агент продолжает жить и повторяет подключение к старому endpoint, но новый Supervisor не имеет устойчивого способа обнаружить и аутентифицировать этот агент. Следующий этап — постоянная регистрация агента, защищённое хранение credentials и протокол безопасного восстановления с epoch/session fencing.
