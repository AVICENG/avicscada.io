# Network Manager — состояние и требования

## Текущая база
В DEV46 сохранены модели PhysicalNetwork и ProtocolChannel, BACnet/IP discovery/read, Modbus TCP read/identify, Device Import, identity resolver и engineering tree. Обнаружение по умолчанию должно оставаться пассивным/ограниченным и инициироваться инженером.

## Целевой сценарий
1. Выбрать физический интерфейс и сегмент.
2. Создать протокольный канал с явными параметрами.
3. Выполнить ограниченное безопасное обнаружение.
4. Просмотреть Manufacturer, Model, Source и Confidence раздельно; неизвестные данные не угадывать.
5. Выбрать устройства и точки для импорта.
6. Проверить native identity, тип, единицы, качество и дубликаты.
7. Подтвердить импорт; записать событие и аудит.

## Правило
Производитель/модель распознаются общей функцией для разных протоколов, а не отдельным частным механизмом BACnet. Не выполнять запись/перепрограммирование неизвестного оборудования.

## Статус
DEV47 не меняет сетевую подсистему; она сохраняется из DEV46 и требует отдельной сквозной Windows acceptance.

## DEV92 — проектная адресация и развёртывание

DEV92 добавляет два режима создания сети: `auto` (привязка к активному интерфейсу текущего компьютера) и `manual` (сохранение адресного плана будущего компьютера AVIC без локального интерфейса). В ручном режиме задаются IPv4 будущей станции, CIDR, необязательный gateway и DNS. Параметры проверяются, но не применяются к ОС.

Для проверки после установки предусмотрен deployment-check: точное совпадение адреса, совпадение подсети при другом IP либо отсутствие проектной сети на текущем компьютере. Контекстное меню сети также предоставляет одиночный Ping. ICMP timeout ограничен, массовое сканирование не выполняется.

Маршрутизируемые устройства могут иметь IP в другой подсети. Modbus TCP обращается к указанному host/port через системную маршрутизацию. BACnet broadcast Discovery остаётся локальным; межсетевой BACnet требует BBMD/Foreign Device Registration или соответствующей маршрутизации. Явный BACnet unicast inspection допускает удалённый адрес через таблицу маршрутизации, но не обещает доступность.

Подробности и ограничения: `docs/NETWORK_PLANNING_DEPLOYMENT_DEV92_RU.md`.
