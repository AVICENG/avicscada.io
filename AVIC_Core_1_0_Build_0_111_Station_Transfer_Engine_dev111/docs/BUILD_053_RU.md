# DEV53 — Alarm Console по IQVISION User Manual §6

## Основание
IQVISION User Manual v2.30, раздел 6: Alarm Console, Alarm History, Alarm Portal. AVIC реализует функционально близкий русскоязычный рабочий сценарий; это не утверждение о полной совместимости с продуктом Trend.

## Реализовано в DEV53
- Карточка конкретной аварии с источником, приоритетом, временем возникновения и подтверждения.
- Цветовые состояния консоли: красный — ACTIVE, жёлтый — ACKNOWLEDGED, зелёный — RETURNED_TO_NORMAL, нейтральный — NORMAL.
- Фильтры по станции, состоянию, приоритету и текстовому поиску.
- Выбор нескольких записей и групповое подтверждение.
- Примечания оператора с автором и UTC-временем; заметки сохраняются в SQLite и аудируются.
- История переходов остаётся отдельным представлением, не смешивается с текущим состоянием.
- API чтения карточки, списка заметок и добавления заметки.

## Ограничения
- Alarm Portal как отдельный Windows-процесс и системные всплывающие уведомления не реализованы.
- Звуковое оповещение и Silence не реализованы.
- Получатели Alarm Console и распределение тревог по удалённым консолям пока не реализованы.
- Действия из UI используют текущий локальный операторский контекст; полноценная пользовательская RBAC-сессия должна быть подключена до промышленной эксплуатации.
- История сейчас ограничивается лимитом API; выбор произвольного временного периода ещё не добавлен.

## Проверки
См. `BUILD_TEST_LOG_DEV53_RU.md`. Функции заметок покрыты параметризованными тестами на перезапуск БД, авторство, валидацию и неизвестный идентификатор.
