## Изменения
- FBD Studio Page Reference проходит серверную структурную проверку.
- Компилятор раскрывает связи с CONNECTIVE proxy в Core StrategyConnective.
- TO_CONNECTIVE остаётся навигационным маркером и исключён из исполняемых узлов.
- Добавлены проверки типов, занятости входов и циклов после раскрытия Connective.
- Добавлены тесты межстраничной компиляции, offline simulation и защиты от повторного использования артефакта старого компилятора.
- Windows Host Identity: PowerShell ACL-скрипт заменён на нативные Windows Security API через ctypes; DACL защищён, разрешения ограничены текущим SID, SYSTEM и Administrators.
- CI использует частный Windows self-hosted Runner; Ubuntu/Python 3.11–3.13 оставлен как ручная дополнительная матрица.

## Известные ограничения
- Копирование страницы сохраняет входящие Connective; исходящие связи не дублируются, чтобы не менять прежних потребителей.
- FBD Points не дублируются автоматически: это предотвращает скрытое увеличение лицензируемого числа точек и сохраняет исходную привязку.
- Удаление страницы с зависимостями требует подтверждения и очищает связанные proxy/links.
- Запись в физические контроллеры не включается.
