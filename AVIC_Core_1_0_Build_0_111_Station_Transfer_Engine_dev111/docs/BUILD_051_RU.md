# AVIC Core 1.0 — DEV51 IQVISION Workbench Reconstruction

## Назначение сборки

DEV51 начинает перестройку пользовательской среды AVIC по модели инженерного Workbench IQVISION: единое рабочее окно, навигация по объектам, сменяемые панели, locator/path bar, view changer, вкладки и контекстные команды. Это не заявление о полной функциональной эквивалентности IQVISION.

## База разработки

- База: `AVIC_Core_1_0_Build_0_50_IQVision_Parity_dev50`.
- Версия пакета: `1.0.0.dev51`.
- Основные исходные руководства, использованные для структуры: IQVISION User Manual, IQVISION Configuration Manual, Point Database Manager Manual из предоставленного архива `lib(1).zip`.
- Локализация интерфейса: русский язык; названия стандартных представлений IQVISION оставлены рядом с русскими названиями там, где это помогает инженеру.

## Реализовано в DEV51

1. Левая панель переключается между «Навигатор» и «Палитра»; выбор запоминается в localStorage.
2. Палитра содержит начальные категории графических/HVAC-компонентов, FBD-блоков и эксплуатационных объектов, а также поиск по элементам.
3. Добавлена строка пути (Locator Bar), переход по названию раздела/объекта и кнопки навигации назад/вперёд. Горячие клавиши: Alt+Left и Alt+Right.
4. Добавлен View Changer: автоматическое представление, свойства, список точек, FBD, мнемосхема, Scheduler, Alarm Console, History/Trend.
5. Для узлов инженерного дерева расширено контекстное меню: свойства, открытие представления, копирование пути, переход к списку точек/истории и объектные команды создания/удаления/опроса там, где они уже поддержаны сервисами.
6. Для статических узлов навигации добавлено контекстное меню с открытием и обновлением представления.
7. Верхнее меню реорганизовано по рабочим доменам: файл, проект, станция, сеть, устройства, точки, инженерия, расписания, аварии, платформа, окно, справка. Команды, для которых существуют страницы, открывают эти страницы вместо disabled-заглушек.
8. Устранена ошибка инициализации обработчика отсутствующего `welcomeWizard`, которая останавливала выполнение оставшейся части `init()`.
9. Обновлена версия пакета и метки сборки до DEV51.

## Известные ограничения — не выдавать за реализованное

- Палитра пока является навигационной/справочной панелью начальных компонентов. Drag-and-drop и фактическая вставка объектов в PX/FBD не реализованы.
- View Changer маршрутизирует к существующим страницам AVIC. Полная модель нескольких типов представлений одного объекта и Niagara-подобные вкладки views ещё не завершены.
- Locator Bar разрешает названия страниц и видимые имена/ID объектов; полноценный устойчивый component path parser и автодополнение ещё впереди.
- Контекстные меню покрывают текущие типы Project, Station, PhysicalNetwork, ProtocolChannel, Device, Point. Полная матрица команд IQVISION и разрешений ещё не реализована.
- FBD/Wiresheet, полноценный PX Editor, полный Point Database Manager, Palette binding, полноценный Alarm Portal и полный набор History extensions остаются отдельными задачами.
- Переключение демонстрационного рабочего профиля не является серверной авторизацией или RBAC.
