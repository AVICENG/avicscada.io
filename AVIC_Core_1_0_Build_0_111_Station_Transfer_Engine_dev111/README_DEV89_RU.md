# AVIC Core 1.0 — DEV89

## Назначение
DEV89 укрепляет вычислительный путь существующего FBDService (`LogicDocument`). Результат симуляции теперь сопровождается диагностикой каждого вычисленного блока и подтверждённым источником значения.

## Что изменено
- Для каждого блока возвращается `node_diagnostics`: тип блока, состояние вычисления, выходной порт, значение и источник.
- Для `POINT_INPUT` возвращаются point_id, source, quality, timestamp, unit и revision из PointRuntime.
- Переопределение входов симуляции разрешено только для виртуальных входных блоков. Физический `POINT_INPUT` нельзя подменить тестовым значением.
- Проверяются типы виртуальных входов, конечность аналоговых чисел, bool/int/string.
- Результат явно сообщает `SIMULATION_ONLY`, `field_writes_performed=false`, `runtime_published=false`.

## Важное ограничение
Это **не непрерывный FBD Runtime и не публикация выходов**. Выполняется отдельный расчёт по запросу. Нет циклического планировщика, записи в OUTPUT-точки, BACnet/Modbus I/O, публикации FBD Studio-графов и реального управления оборудованием. Никаких полевых записей DEV89 не выполняет.
