# AVIC Core 1.0 — журнал сборки DEV195

Дата: 26.11.2026  
Базовая ветка: `ci/fbd-connective-compiler`  
Предыдущая версия: `1.0.0.dev194`  
Новая версия: `1.0.0.dev195`

## Реализовано

1. В Page Builder добавлен каталог привязки компонента «Значение» к физическим Core Points и виртуальным FBDExposedPoint выбранной станции.
2. Каталог показывает имя точки, устройство/протокол, значение, единицу и качество.
3. В layout сохраняется стабильный point ID; серверная проверка при сохранении и публикации подтверждает тип точки и принадлежность той же станции.
4. Компонент «Кнопка / ссылка» выводится как ссылка только при заданном и прошедшем проверку href; текст и URL HTML-экранируются.
5. Существующий immutable publication snapshot, live read-only Point Runtime, версии, unpublish и rollback сохранены без изменения семантики.
6. Добавлен регрессионный тест UI/API для point catalog, live published value, ссылки и запрета межстанционной привязки.
7. Версия Core повышена до `1.0.0.dev195`.
