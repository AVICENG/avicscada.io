# Журнал сборки и тестирования DEV85

## База и версия
- Источник: DEV84, полученный из архива `AVIC_Core_1_0_Build_0_84_Unified_Navigation_Point_Binding_dev84.zip`.
- Версия пакета: `1.0.0.dev85`.
- DEV85 не перезаписывает DEV84; сборка находится в отдельном каталоге.

## Реализовано
- Одна общая левая навигация в Home, FBD, Graphics и Web Pages.
- Одна общая выдвижная панель Engineering Tree во всех четырёх рабочих пространствах.
- Общее дерево показывает проект/станцию/сеть/протокол/устройство/физические точки и FBD-проекты/страницы/FBD-точки.
- Физическая точка из общего дерева передаётся на FBD-доску существующим drag payload `point`; FBD-точка — payload `fbd-point`.
- Добавлен `PointRuntimeService`: чтение, снимок, публикация входного измерения, подписки/отписки, контроль типов/качества/timestamp и проверка владельца-драйвера.
- Значения публикуются в существующий `Point` по его UID, а не в отдельную копию.
- FBD simulation читает текущую точку через Point Runtime.
- FBD-доска опрашивает runtime snapshot каждые 2 секунды и показывает live value/quality для привязанных физических точек.
- Добавлены read-only API `GET /api/points/{point_id}/runtime` и `GET /api/engineering/points/runtime`.

## Полная регрессия
- Коллекция pytest содержит примерно 31 000 тестовых случаев, включая крупные параметризованные parity-наборы.
- Полный прогон не завершился в доступное окно времени. После исправления одного устаревшего статического тестового ожидания прогон `pytest -x -q` достиг примерно 41% без нового сообщения об ошибке, затем был остановлен по лимиту времени.
- Попытки прогона оставшейся регрессии без трёх крупнейших параметризованных модулей также не завершились в выделенное окно времени. Полный набор нельзя объявлять пройденным.
- Выявленный устаревший тест `test_simulation_values_are_hidden_when_stopped_and_cleared_on_stop` обновлён: теперь обычные симуляционные значения скрыты в STOP, но привязанные физические точки продолжают показывать live value — это новое требуемое поведение.

## Проверка зависимостей
- `pip check` сообщает внешний конфликт общей среды: `moviepy 2.2.1` требует `pillow<12`, в среде установлена `pillow 12.3.0`.
- Wheel успешно собран с `--no-build-isolation`, поскольку сборочная среда не имеет доступа к PyPI для установки изолированных build-зависимостей.
- Конфликт Pillow не добавлен в зависимости AVIC.

## Ограничения и непройденные проверки
- Нет Windows-браузерной визуальной приёмки; DOM/маршруты и JavaScript проверены автоматически, но это не заменяет проверку пользователем в браузере Windows.
- BACnet IP Client и Modbus TCP Client ещё не подключены к циклу опроса `PointRuntimeService.publish`. Реальный polling оборудования не реализован в DEV85.
- Не реализован автоматический переход в STALE при потере связи/таймауте драйвера.
- Нет Command Manager и реальной записи в BACnet/Modbus контроллеры.
- Нет полного исполняемого FBD Runtime; FBD Studio остаётся редактором, а существующий FBDService simulation — отдельным симулятором.
- Нет BACnet Server для публикации FBD-точек наружу.
- Лицензионный подсчёт уникальных активных точек не изменён.
- Нельзя использовать DEV85 для управления реальным объектом.
