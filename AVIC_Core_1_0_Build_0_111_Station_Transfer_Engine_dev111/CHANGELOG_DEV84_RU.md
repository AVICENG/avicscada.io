# AVIC Core 1.0 — DEV84

## Общая навигация
- Введена единая левая навигационная полоса AVIC для рабочих пространств Home, FBD, Graphics и Web Pages.
- Убрана дополнительная верхняя навигационная полоса, которая дублировала разделы и визуально отделяла редакторы друг от друга.
- Состав навигации приведён к единому набору: Главная, Проекты, Сети, Устройства, Точки, Мнемосхемы, FBD, Web Pages, Аварии, Архивы, Безопасность, Диагностика.
- Сохранены собственные контекстные панели редакторов: инженерное дерево FBD, библиотека блоков, библиотека SVG и дерево Web Pages. Общая полоса отвечает за переход между рабочими пространствами.

## Мультипротокольные привязки FBD
- Каталог точек AVIC теперь возвращает в одном контракте протокол, идентификатор/имя/адрес устройства, производителя/модель, native identity и тип BACnet/другого драйвера.
- При перетаскивании точки оборудования на FBD создаётся ссылка на исходную точку, а не отдельная копия точки.
- В FBD-модуле сохраняется `avic.external-point-binding` с `pointId`, `protocol`, `deviceId`, `nativeIdentity`, типом, направлением, единицами и безопасным флагом `readOnly`.
- Контракт не привязан к BACnet: протокол передаётся как метаданные источника. Фактическое чтение/запись по-прежнему выполняет соответствующий драйвер.

## Отображение значений
- Для числовых значений на FBD-доске введено отображение с двумя десятичными знаками по умолчанию.
- Форматирование выполняется только на уровне представления; исходное числовое значение не округляется и не меняется.
- Точность можно переопределить параметром `displayPrecision` конкретного FBD-модуля.
