AVIC Core 1.0 — DEV55 FBD + Graphics Integration

1. Распакуйте архив в новую папку.
2. Откройте CMD в этой папке.
3. Выполните: python -m pip install -e ".[dev]"
4. Затем: python -m pytest --collect-only -q
5. Для полного набора используйте раздельные команды из BUILD_TEST_LOG_DEV55_RU.md.
6. Дополнительно: python -m compileall -q avic_core tests
7. Дополнительно: python -m avic_core --help
8. Запуск Workbench: python -m avic_core.ui

Проверка сценария:
- Создайте/выберите станцию.
- Откройте «Инженерия → FBD / Logic» или /logic?station=<UUID>.
- Нажмите «Тестовая логика вентилятора», сохраните и запустите симуляцию.
- Откройте «Мнемосхемы», создайте «Тестовая ВУ».
- Выберите символ вентилятора, выберите FBD-схему и блок «Разрешение ПВ-1», нажмите «Связать с логикой».
- Сохраните мнемосхему и откройте повторно: привязка должна остаться.

Безопасность: DEV55 не отправляет команды на контроллеры. Все FBD-вычисления — локальная симуляция.
