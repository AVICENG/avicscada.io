Настройка сети
Пример: 192.168.10.0/24 означает сеть с адресами устройств 192.168.10.1–192.168.10.254. Шлюз — адрес маршрутизатора, который соединяет эту сеть с другими. DNS помогает находить компьютеры по именам. Если шлюз или DNS неизвестны, оставьте поля пустыми и уточните их у администратора сети. Это только проектный план: AVIC не меняет настройки Windows, маршрутизатора или контроллеров.
Создание конфигурации не запускает опрос оборудования.
