Перенос и клонирование станции

Безопасная передача инженерной конфигурации между установками AVIC. Перенос сохраняет идентификаторы объектов; клонирование создаёт независимую копию с новыми идентификаторами.

Важно: пакет станции не содержит пароли, ключи, историю и аудит. Сетевые адреса и идентификаторы оборудования очищаются, драйверы и каналы остаются остановленными. Импорт не запускает станцию и не отправляет команды контроллерам.
