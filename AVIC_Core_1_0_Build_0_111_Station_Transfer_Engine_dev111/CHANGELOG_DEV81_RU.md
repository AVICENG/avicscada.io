# Изменения DEV81

- Трассировка соединений: тонкая, ортогональная polyline, без Bézier-кривых.
- Выбор линии кликом и отдельное удаление.
- Перемещение блока по всей поверхности, кроме портов.
- Рабочий инструмент текстовых заметок на FBD-доске.
- Диалог после создания FBD-точки показывает происхождение и предлагает навигацию к источнику.
- Уникальность имён страниц в проекте и FBD-проектов на станции.
- Серверное удаление FBD-проекта через DELETE с optimistic concurrency и audit event.
- Добавлены регрессионные тесты.
