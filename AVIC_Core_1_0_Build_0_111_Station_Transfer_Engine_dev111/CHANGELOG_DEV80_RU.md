# Изменения DEV80

1. Исправлена компоновка вкладок страниц: адаптивная сетка, перенос, обрезка длинных названий с title-подсказкой и вертикальная прокрутка для очень большого количества страниц.
2. Добавлены контекстные команды для вкладок, страниц из основного дерева, FBD-проектов, групп страниц/FBD Points, точек контроллеров и точек FBD.
3. Введён общий capture-обработчик правой кнопки мыши для редактора и его панелей; специализированные меню выбираются по типу объекта.
4. Верхние меню переведены на выпадающие списки реальных команд.
5. Инженерное дерево строит отдельные ветви для всех FBD-проектов станции, а не только для текущего открытого документа.
6. Добавлено открытие проекта и страниц по их документу/станции, создание нескольких FBD-проектов из дерева.
7. Перед сменой документа сбрасывается таймер автосохранения и сохраняется текущая ревизия.
8. Печать полного проекта и отдельных страниц доступна из верхнего меню, вкладок и контекстных меню дерева.
