# AVIC Core DEV82 — изменения

## Инженерное дерево и навигация
- Добавлена общая верхняя навигация на Dashboard, Pages, FBD и Graphics.
- FBD-проекты и страницы доступны из инженерного дерева; контекстные действия проекта/страницы сохранены.
- Удалён отдельный нижний левый каталог точек станции из FBD Studio: точки станции остаются в инженерном дереве, FBD Points отображаются внутри соответствующего FBD-проекта.
- В дереве FBD Points добавлены четыре группы: Analog Inputs, Discrete Inputs, Analog Outputs, Discrete Outputs.
- Сохранение FBD документа обновляет серверную проекцию инженерного дерева, чтобы созданные точки появлялись без ручной перезагрузки.

## Идентификация точек
- Добавлены AVIC UID, native identity, symbolic address, direction, provenance и licensing status в дерево.
- FBD symbolic address формируется из кода страницы, типа/номера блока и фактического имени порта, например `P1.PID_LOOP_4.PV`.
- Внутренняя native identity использует UID документа/страницы/блока/порта.
- Сервер проверяет уникальность UID, tag, native identity, symbolic address и path в документе.
- Сервер проверяет существование страницы, блока и выходного порта для FBD point source.
- Запрещено повторно публиковать один и тот же source output port в одном документе.
- Порядковый код страницы отображается как P1, P2 и т.д.; стандартные legacy-названия «Страница NN» мигрируют в короткие P-коды.

## FBD wiring и PID
- Для проводов используется отдельная невидимая зона hit-test и независимая тонкая SVG polyline с явным `fill=none`; выделение/удаление выполняется по hit-line.
- PID: уточнено соглашение Direct/Reverse (Direct: OUT растёт при росте PV), D остаётся по измерению, фильтр D, conditional anti-windup, безударный MANUAL/AUTO.
- Исправлен нулевой lastOutput при безударном возврате.
- Ограничения интегратора по умолчанию приведены к диапазону ±размах выхода вместо ±1000.
- PID-диалог расширен и ограничен 90% высоты окна; прокрутка внутренняя, кнопки остаются видимыми.

## Контракт и документация
- Добавлен `docs/AVIC_POINT_IDENTITY_CONTRACT_DEV82_RU.md`.
- Обновлены регрессионные тесты под принятые правила перетаскивания, навигации, проводов и PID.
