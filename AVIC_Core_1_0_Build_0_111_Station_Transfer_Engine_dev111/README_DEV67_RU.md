# AVIC Core 1.0 — DEV67

DEV67 продолжает DEV66 и добавляет модульную приточную установку с рекуперацией и SVG-анимацией.

- 7 соединяемых секций одного типоразмера;
- заслонка наружного воздуха, фильтр, рекуператор, водяной нагреватель, водяной охладитель, вентилятор, открытый выходной короб;
- вращение/открытие/поток по Boolean/value/feedback сигналам;
- локальный визуальный предпросмотр без записи в полевые контроллеры;
- API для создания тестовой модульной ПВУ.

Начните с `INSTALL_DEV67_RU.txt`; руководство по точкам и анимации: `docs/MODULAR_AHU_ANIMATION_RU.md`.

Это development-сборка. Полевая запись, готовый промышленный Runtime и серверный RBAC в DEV67 не включены. Браузерную визуальную приёмку нужно завершить на целевом Windows-ПК.
