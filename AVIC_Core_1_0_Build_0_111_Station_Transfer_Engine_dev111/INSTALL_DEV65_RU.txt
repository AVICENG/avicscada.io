AVIC Core 1.0 — DEV65 SVG Import & Web Pages Authoring

1. Распакуйте ZIP в отдельную папку, НЕ поверх DEV63/DEV64.
2. Откройте CMD в каталоге сборки.
3. Проверьте версию:
   python -c "import pathlib; print(pathlib.Path('pyproject.toml').read_text(encoding='utf-8').split('version = ')[1].splitlines()[0])"
4. Установите dev-зависимости:
   python -m pip install -e ".[dev]"
5. Проверьте компиляцию и зависимости:
   python -m compileall -q avic_core
   python -m pip check
6. Запустите Workbench на тестовом каталоге:
   python -c "import uvicorn; from avic_core.ui.app import create_ui_app; app=create_ui_app(data_dir=r'.\\_acceptance_data_dev65'); uvicorn.run(app, host='127.0.0.1', port=8765, log_level='info')"
7. Откройте http://127.0.0.1:8765

Импорт SVG:
- создайте проект и станцию;
- откройте «Мнемосхемы»;
- выберите станцию;
- выберите SVG-файл не больше 1 МБ, укажите название/категорию;
- нажмите «Импортировать в библиотеку станции»;
- добавьте символ на холст и сохраните мнемосхему.

Разработка страниц:
- откройте раздел «Страницы / Web Pages»;
- выберите станцию;
- создайте «Сайт», затем «Папка» и «Страница»;
- выберите страницу, добавьте элементы из визуальной палитры;
- выберите элемент, настройте свойства в инспекторе, переместите мышью;
- нажмите «Сохранить» и откройте «Предпросмотр».
- для встраивания мнемосхемы сначала назначьте её странице на вкладке «Редактор мнемосхем», затем добавьте компонент «Мнемосхема».

Важно:
- страницы пока не публикуются;
- компонент «Значение» не получает live point data, показывает placeholder;
- SVG import блокирует скрипты, внешние ссылки, DTD/ENTITY и неподдерживаемые активные SVG элементы;
- рабочие записи в полевые контроллеры и Runtime execution отключены;
- после запуска пришлите Windows вывод `python -m pytest -q` и проверьте реальные UI-сценарии.
