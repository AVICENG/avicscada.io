# AVIC Core 1.0 — DEV97

DEV97 добавляет два блока в исполняемое ядро FBD и компилятор FBD Studio → Core:

- `SCALE` — линейное масштабирование с настройками входного/выходного диапазона и опциональным ограничением результата (`clampOutput`);
- `HYSTERESIS` — двухпороговый переключатель с памятью состояния между циклами: включение при `IN >= HIGH`, выключение при `IN <= LOW`, удержание предыдущего состояния между порогами.

### Что изменилось

1. `FBDService` получил типизированный контракт HYSTERESIS и расчёт SCALE с опциональным clamp.
2. `FBDService.simulate()` принимает необязательное хранилище состояния. Оно обновляется только после успешного полного расчёта, поэтому ошибка в графе не оставляет частично изменённое состояние.
3. `FBDExecutionService` хранит состояние блоков в контексте стратегии между тиками. Новое поколение запуска начинает с начального состояния, заданного блоком.
4. Компилятор FBD Studio → Core принимает SCALE и HYSTERESIS. Параметры SCALE преобразуются в четыре явных входных константы Core; для незаполненных LOW/HIGH HYSTERESIS создаются входные константы из параметров Studio. Явные связи пользователя имеют приоритет над параметрами по умолчанию.
5. Деление на ноль в локальном предпросмотре FBD также теперь выдаёт ошибку, а не подменяется нулём.

### Ограничения

- Это расчёт FBD в программном Runtime/симуляции. Публикация в физические точки, команды BACnet/Modbus и запись в оборудование не включены.
- Состояние HYSTERESIS хранится в памяти процесса и не переживает перезапуск процесса; при новом запуске стратегии используется `initial_state`.
- Совпадение формул и граничных условий с каждым конкретным модулем Trend SET ещё требует сверки по его документации/испытаниям. Реализация описывает зафиксированную семантику AVIC, а не заявление о полном побитовом паритете Trend.
- PID, DELAY, LATCH и SWITCH не включены в компилятор DEV97.

См. `docs/FBD_BLOCKS_DEV97_RU.md`, `BUILD_TEST_LOG_DEV97_RU.md` и `INSTALL_DEV97_RU.txt`.
