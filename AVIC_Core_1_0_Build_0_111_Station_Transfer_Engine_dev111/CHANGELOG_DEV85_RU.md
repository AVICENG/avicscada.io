# AVIC Core 1.0 — DEV85

## Единое инженерное дерево и навигация
- Все четыре рабочих пространства — Home, FBD, Graphics и Web Pages — получают одну и ту же левую навигационную полосу из общего серверного шаблона.
- Добавлена общая выдвижная панель инженерного дерева, доступная из каждого рабочего пространства.
- Дерево показывает иерархию Проект → Станция → Физическая сеть → Протокол → Устройство → Точки, а также FBD-проекты, страницы и FBD-точки.
- Поиск фильтрует узлы общего дерева.
- Открытие FBD-проекта и страницы выполняется из общего дерева.
- Физические точки перетаскиваются из общего дерева в FBD; используется существующий контракт `point` и существующая обработка drop в FBD-доске.
- FBD-точки можно перетаскивать по контракту `fbd-point`.
- Контекстные библиотеки и специализированные панели редакторов сохранены; общий компонент отвечает за глобальную навигацию и доступ к общему дереву.

## Point Runtime — единая точка текущего значения
- Добавлен `PointRuntimeService` как единый in-process сервис публикации и чтения текущих значений.
- Значение, качество и timestamp обновляются на исходном объекте `Point`, не создавая копий точки.
- Добавлены `read`, `snapshot`, `publish`, `subscribe`, `unsubscribe`.
- Проверяются тип значения, конечность чисел, качество, timezone-aware timestamp, направление точки и идентификатор драйвера-владельца (если он задан).
- Исключение одного подписчика не отменяет уже зафиксированное обновление и не блокирует остальных подписчиков.
- Добавлены read-only API: `/api/points/{point_id}/runtime` и `/api/engineering/points/runtime`.
- FBD-симулятор читает актуальное значение и качество через Point Runtime, а не напрямую из сохранённого снимка точки.
- FBD-редактор обновляет отображаемые значения привязанных физических точек каждые 2 секунды; качество отображается отдельно.
- Внутреннее значение не округляется; форматирование FBD остаётся презентационным, по умолчанию два знака после запятой.

## Ограничения DEV85
- BACnet и Modbus драйверы пока не подключены к циклу опроса Point Runtime. Публикация реализована как внутренний драйверный контракт, но реальное сетевое чтение не включено.
- Нет контролируемого write path к полевым контроллерам.
- Нет исполняемого FBD Runtime для постоянного управления; текущая FBD Studio остаётся редактором, а `FBDService.simulate` — симуляцией.
- Нет BACnet Server.
- Лицензионный счётчик уникальных активных точек не изменялся и не объявляется завершённым.
- Нужна Windows-браузерная приёмка общего дерева, drag-and-drop и визуального поведения.
