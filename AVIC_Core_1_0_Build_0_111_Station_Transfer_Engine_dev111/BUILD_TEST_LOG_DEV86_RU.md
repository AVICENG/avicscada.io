# Журнал сборки и тестирования DEV86

## База и версия
- Источник: архив DEV85 `AVIC_Core_1_0_Build_0_85_Engineering_Tree_Live_Point_Engine_dev85(1).zip`.
- Версия пакета: `1.0.0.dev86`.
- DEV86 создан в отдельном каталоге; DEV85 не изменяется.

## Реализовано в DEV86
- Добавлена маршрутизация FBD-проводов с проверкой прямых сегментов на пересечение прямоугольников других блоков.
- Маршрутизатор строит ортогональные маршруты с обходными каналами над/под препятствиями и дополнительными горизонтальными каналами, если соседний блок перекрывает короткий выходной участок.
- Маршрут строится по фактическим координатам контактов и сохраняет ортогональные повороты.
- Выбранное соединение подсвечивается целиком контрастным оранжевым цветом и увеличенной толщиной.
- Подсказки входных и выходных контактов показывают имя блока, направление, номер контакта, имя сигнала и тип.
- Увеличена минимальная ширина обычных блоков; подписи и описания получили перенос строк, строки портов — отдельную минимальную высоту.
- Версионные метки Workbench в Home, Graphics и Web Pages обновлены с DEV67 на DEV86.
- Добавлены регрессионные тесты маршрутизации, выделения соединений, идентификации портов и компоновки подписей.

## Проверки
- Целевые тесты FBD: 20 passed.
- JavaScript syntax: `node --check` — успешно.
- Целевой FBD-набор: 20 passed.
- Дополнительные тесты Point Runtime / общей навигации / привязки точек: 17 passed.
- `compileall -q avic_core` — успешно.
- `node --check` для встроенного JavaScript FBD Studio — успешно.
- Wheel `avic_core-1.0.0.dev86-py3-none-any.whl` собран успешно.
- Полный `pytest -q` был прерван автоматическим ограничением среды выполнения через 60 секунд; полный регрессионный результат для DEV86 не получен.
- В контейнерной среде `pip check` показывает внешний конфликт `moviepy` ↔ `pillow 12.3.0`; это не зависимость AVIC и не повторяет Windows-среду пользователя, где DEV85 прошёл `pip check`.
- Windows UI acceptance — не выполнена в этой среде; требуется повторный запуск DEV86 на Windows и визуальная проверка схем с перекрывающимися блоками.

## Известные ограничения
- Трассировщик сейчас использует эвристический набор ортогональных каналов и выбирает кратчайший из проверенных маршрутов. Для очень плотных схем, где свободного канала не найдено, требуется дополнительная проверка и дальнейшее улучшение алгоритма.
- Не реализованы в этом срезе: единое дерево Workbench без дублирующего центрального навигатора; полноценный FBD Runtime → Graphics binding; реальное BACnet/Modbus чтение/запись через Point Runtime; окончательная проверка обозначений входов COMBINATION (нужно сверить таблицу условий и входные контакты, не ломая существующую семантику).
- DEV86 не является завершением FBD и не подтверждает реальную работу точек на мнемосхемах.

## Статус
DEV86 — целевая инженерная доработка визуальной трассировки и читаемости блоков. Готовность: **требует Windows визуальной приёмки**.
