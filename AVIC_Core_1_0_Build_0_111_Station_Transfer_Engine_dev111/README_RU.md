# AVIC Core 1.0 — DEV68: FBD Strategy Pages

DEV68 продолжает DEV67 без потери модульной ПВУ, 66 SVG-символов и SVG-анимации. Основное новое направление — многостраничная модель FBD по рабочим принципам Trend SET 6.3.

## FBD DEV68

- Strategy Pages: первая страница создаётся вместе с FBD-документом;
- добавление, переименование, переключение и удаление страниц;
- размещение FBD-блоков на конкретной странице;
- обычные связи внутри страницы;
- межстраничный Connective с проверкой типов, занятости входа и циклов;
- Connective передаёт значение между страницами в offline-симуляции;
- ревизии документа защищают от конкурентного перезаписывания;
- полевые записи остаются отключены.

## Сохранённые функции DEV67

- семь модульных секций ПВУ: заслонка, фильтры, рекуператор, нагреватель, охладитель, вентилятор и открытый выходной короб;
- SVG-анимация заслонки, вентилятора и воздушного потока;
- библиотека из 66 SVG-символов;
- локальный предпросмотр без команд в контроллер.

## Документы

- `INSTALL_DEV68_RU.txt` — установка и запуск;
- `docs/BUILD_068_RU.md` — состав DEV68, API и ограничения относительно SET 6.3;
- `BUILD_TEST_LOG_DEV68_RU.md` — фактические результаты тестирования;
- `CHANGELOG_DEV68_RU.md` — список изменений;
- `docs/BUILD_067_RU.md` — сохранённая реализация ПВУ и анимации;
- `docs/MODULAR_AHU_ANIMATION_RU.md` — описание точек и поведения анимации.

## Статус

DEV68 — development-сборка, а не завершённый клон SET 6.3. Визуальные To/From/Undefined Connective, drag-to-connective, полноценная авто-маршрутизация, sequence steps и полная библиотека блоков ещё требуют реализации. Браузерную визуальную приёмку и запуск на Windows нужно выполнить на целевом ПК.

**Режим FBD:** offline simulation only. Физические команды не отправляются.
