- Полный `python -m pytest -q` был запущен, но процесс превысил лимит выполнения 300 секунд примерно на отметке 19%. Это не является успешным полным регрессионным прогоном; окончательное число passed/failed не получено.

## Проверенные сценарии DEV92

- Ручной адресный план для будущего диспетчерского компьютера без локального интерфейса.
- Проверка IP станции, подсети, шлюза и DNS.
- Отказ для IP вне подсети, некорректного шлюза и совпадения адреса станции со шлюзом.
- Статусы deployment binding: exact match, subnet present/address mismatch, planned/not present.
- API сохранения manual network и отказ при ошибочной адресации.
- API одиночного Ping с ограничением timeout.
- Разрешение routed BACnet unicast inspection для адреса за пределами локальной подсети (проверено с fake client; физический маршрут не тестировался).
- Сохранение прежнего автоматического режима с привязкой к обнаруженному интерфейсу.
- Существующие тесты Network Manager, дерева, топологии, Station и Schedule Manager.
