# AVIC Core 1.0 — DEV155

## Цель
Связать существующий Web Pages publication API с интерфейсом Page Builder.

## Изменения
- Добавлены кнопки публикации, открытия опубликованной страницы и снятия с публикации.
- Перед публикацией редактор сохраняет черновик; при ошибке сохранения публикация не выполняется.
- Отображается статус публикации и номер опубликованной версии.
- Добавлены UI regression assertions в сквозной тест FBD → Graphics → Web Page.
- Версия пакета повышена до 1.0.0.dev155.

## Проверки
- Изменения сверены с существующими API `/publish` и `/unpublish` и полем `published_revision`.
- Сквозной тест уже покрывает создание страницы, назначение мнемосхемы, публикацию API, открытие URL и live bindings; DEV155 добавляет проверку UI-действий.
- Полный CI DEV155 ожидает запуска. До завершения матрицы Linux/Windows сборка не считается принятой.

## Ограничения
- Визуальный выбор версии для rollback пока не добавлен; rollback API существует.
- Customer-grade RBAC/MFA, HTTPS deployment и полноценный браузерный acceptance остаются отдельными задачами.
