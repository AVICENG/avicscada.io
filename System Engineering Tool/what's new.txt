SET Version 6.1

New Features
      .  Support for IQ3 v1.4 firmware
         SET supports the IQ3/XCITE/128 controller, and the XCITE/IO/8DI/8TI I/O module.

      .  Site Topology Applet.
         New applet that integrates with SET to provide the facility to map an IQ system. It also enables an electrical map to be produced showing the devices in the order they receive an electrical signal as it progresses around the network. 

      .  Time Module can be added to a strategy page
         For IQ3 controllers with v1.4 firmware of greater the Time module can be added to a strategy page. 
         This enables links to be made from the strategy to the modules time pulses, and to the daylight saving parameters Solutions.

      .  Solutions
         SET 6.1 introduces the concept of Solutions which enhances the strategy block concept to enable the entire configuration of a controller to be reused.

      .  Import/Export of Strategy Blocks
         Strategy blocks and solutions can be exported from once PC and imported onto another.

      .  Printing of Strategy Blocks
         Strategy blocks can be printed out to provide a paper record of the blocks strategy.

      .  Translation of Labels in Strategy Blocks
         The labels of sensors, digital inputs, knobs, switches and drivers used in strategy blocks can be translated. When the strategy block is used SET default language is used to determine the language of the labels used.

      .  Translation of Printout Labels
         The text that appears on the front page, title blocks, and tables that are printed out is now available in the following languages: English, XXXXXXXXXXXXXXXXXXXXXXXX

      .  Printing in Live Values and Live Edit
         It is now possible to print the current page including the live values in live values and lives edit.

Enhancements

      .  Larger Strategy Library
         The strategy library supplied with SET has been expanded to include: alarm handling, mathematical calculations, psychometric calculations, unit conversions, and specific strategies required for Trend products

      .  Alarm indication in Live Values and Live Edit
         Modules in an alarm conditions are shown in yellow in Alarm Live Values and Live Edit.

      .  Quick Edit
         The Command Line Toolbar now has en extra button  , which enables the Parameters dialogue box to be displayed for any module without having to locate it on a strategy page.

      .  Improvements to Live Edit
         It is now possible to copy and paste modules, and delete multiple modules during live edit. SET now checks for user rights to make changes when entering live edit, and warns if changes cannot be made.

      .  Index of Strategy Pages
         An index of the strategy pages can now be included in the project documentation

      .  Associated connectives can be set as undefined connective destination

      .  Improved method of adding and editing exceptions
         A calendar display has been added to the Timezone dialogue box that enables easy selection of exceptions.

      .  Controller Time Check 
	 When downloading from the strategy design project view the controller time and date is checked against the PC, errors outside a specified tolerance are flagged to the engineer who then has the option to synchronise.
