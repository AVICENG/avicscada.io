Création de modèles d'horaires exceptionnels

Grâce aux modèles d'horaires exceptionnels, il est possible de prédéfinir des horaires applicables exceptionnellement (jours fériés, etc.) et de les utiliser lorsque l'on ajoute une exception. Les modèles peuvent définir les temps d'occupation applicables à une seule journée (modèles de jours spéciaux) ou à une semaine complète (Modèles de configuration des semaines). Cette fonction permet le paramétrage de temps d'occupation différents pour chaque jour de la semaine. Chaque groupe de zones horaires peut renfermer ses propres modèles d'exceptions, ce qui permet l'utilisation d'un même nom d'exception dans différents groupes, mais avec des temps d'occupation différents.
