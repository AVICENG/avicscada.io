Ouverture de session

Avant de pouvoir utiliser le 963, il est indispensable d'ouvrir une session pour que le 963 sache à quelles informations et à quelles fonctions vous avez accès ;

Pour ouvrir une session :

1 connectez-vous au 963 Server comme indiqué dans la section « Connexion au 963 Server » de ce manuel ;

2 saisissez votre identifiant dans la zone Identifiant. Il s’agit de votre identifiant pour le 963 ;

3 saisissez votre mot de passe dans la zone correspondante.

Notez que les mots de passe tiennent compte de la casse ;

4 cliquez sur Ouvrir une session. La Page de démarrage du 963 Server s’affiche.

Cette page permet l’accès aux pages graphiques, aux Appareils, au Calendrier, à l’état du serveur, vous sert à fermer votre session et affichera les alarmes auxquelles vous avez accès et auxquelles le 963 Server accède en mode graphique.
