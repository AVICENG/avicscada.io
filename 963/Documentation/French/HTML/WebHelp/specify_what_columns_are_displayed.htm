Définition l’affichage des colonnes

Il est possible de choisir les colonnes à afficher dans l'Historique des alarmes et dans la liste des Alarmes entrantes.

Pour définir les colonnes à afficher :

1 visualisez soit les Alarmes entrantes, soit l’Historique des d'alarmes comme indiqué dans les sections « Visualisation des alarmes entrantes » et « Visualisation de l'historique des alarmes » de ce manuel ;

2 cliquez sur Définir la table. Une boîte de dialogue s'affiche :

3 cochez les cases figurant à côté du nom de la colonne pour sélectionner les colonnes à afficher ;

4 cliquez sur OK.

Notez que cette fonction n’est disponible que pour un accès au 963 Server en mode graphique.
