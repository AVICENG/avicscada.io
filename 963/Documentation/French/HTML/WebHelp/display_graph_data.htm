Affichage des données du graphique

Il est possible d’afficher les données utilisées pour la représentation du graphique sous forme d'une liste de points.

Pour afficher les données du graphique :

1 affichez un graphique compact ou un graphique de précision de la valeur dont les coordonnées sont à afficher, comme indiqué dans la section correspondante de ce manuel ;

2 cliquez sur l'onglet Liste. Les données du graphique s'affichent ;

3 si le graphique comporte plus d’une courbe, dans la zone Trace sélectionnée, cliquez sur la courbe dont vous souhaitez les données ; une liste de courbes apparaîtra en haut de la fenêtre ;

4 pour revenir à l’affichage du graphique, pointez sur l’onglet Graphe.
