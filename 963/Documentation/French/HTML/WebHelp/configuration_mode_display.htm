Configuration

L'écran de Configuration présenté ci-dessous permet l'accès à la configuration d’un appareil précis du système Trend. Il permet des réglages stratégiques simples. A partir de l'écran de configuration, tous les messages écran sont émis à partir du contrôleur et toutes les saisies au clavier sont envoyées au contrôleur en cliquant sur Soumettre.
