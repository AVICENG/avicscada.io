Display a linked TimeZone

The Group setup and status tab displays a list of the timezones that are linked to the diary group(s) selected in the Navigator. The list indicates the site, Lan, controller name, timezone label, item code, and device type. Buttons enable timezones to be added to the group, times to be sent to the controllers, actual times to be viewed, and group setting to be edited.

To display a linked time zone:

  1. Access the 963 Server.

  2. Click Diary. A separate window is opened containing the diary groups. All the diary groups or folders containing diary groups are listed on the left pane of the page.

  3. Select the required diary group by clicking it. If the required diary group is not visible navigate to it by clicking the required folder.
    Once you have selected the required diary group, a page is displayed that lists the Group Time Planner, Group setup and status, and Time Schemes for the selected diary group. By default, the Group Time Planner tab for the selected diary group is displayed.

  4. Click the Group setup and status tab. The Group setup and status page is displayed.
    The linked time zone is displayed.
