Import Time Schemes

You can reuse the times schemes across different diary groups. A time scheme can be imported from one diary group to another.

To import a time scheme:

  1. Access the 963 Server.

  2. Click Diary. A separate window is opened containing the diary groups. All the diary groups or folders containing diary groups are listed on the left pane of the page.

  3. Select the required diary group by clicking it. If the required diary group is not visible navigate to it by clicking the required folder.
    Once you have selected the diary group to which you want to add a time scheme, a page is displayed that shows the Group Time Planner, Group setup and status, and Time Schemes. Click the Time Schemes tab for the selected diary group.

  4. Click Import Time Scheme. The Import Week Sets dialogue box is displayed.

  5. Select a diary group from the left pane whose time schemes you want to import. All the time schemes from the selected diary group are listed in the Configured Time Schemes list.

Note: You can select Display week sets for selecting a time scheme for a week or Display special days for selecting a time scheme for a special day.

  1. Select a time scheme and click OK. A confirmation dialogue box appears.

  2. Click Yes to continue.

  3. The Download Options dialogue box is displayed.

  4. You can choose to download the changes either at the group schedule time or in the next available time slot. Select the appropriate option and click OK.
    If there are conflicts due to common time scheme names the Configure Time Scheme Replace dialogue box is displayed. Select the required option.

  5. The selected time schemes are imported.
