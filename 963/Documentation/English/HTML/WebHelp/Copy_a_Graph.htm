Copy a Graph

963 can copy graphs to the clipboard. You can paste the copied graphs on other applications, for example, MS Word, MS Excel, and so on.

To print a graph:

  1. Display a graph from a schematic page or from the Device Viewer.

  2. On the graph right click and click Copy to Clipboard. The graph is copied on the clipboard and you can paste it in any other application, for example, Microsoft Word.
