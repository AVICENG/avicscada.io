View Time Scheme Applicability

You can find out exactly where and when a time schem is being used. You can also delete an exception while viewing the time schemes for a selected diary group.

To view the time scheme applicability:

  1. Access the 963 Server.

  2. Click Diary. A separate window is opened containing the diary groups. All the diary groups or folders containing diary groups are listed on the left pane of the page.

  3. Select the required diary group by clicking it. If the required diary group is not visible navigate to it by clicking the required folder.
    Once you have selected the diary group to which you want to add a time scheme, a page is displayed that shows the Group Time Planner, Group setup and status, and Time Schemes. Click the Time Schemes tab for the selected diary group.

  4. Select Display week sets to view the weekly time scheme applicability or select Display special days to view the time scheme applicability for a special day.

  5. Select a time scheme from the list of Configure Time Schemes.

  6. Click Where are these times used?. The Where are these times used? dialogue box is displayed.

  7. All the instances of the selected time scheme are displayed. The display includes the start and end date of the time scheme. It also gives information on yearly recurrence.

  8. Click Cancel to close the dialogue box.
