Run a Manual Alarm Action

Manual alarm actions enable a specific action to be run by the user when an alarm occurs. This gives the operator control over the display and prevents the situation where 963 is too busy jumping to pages for the user to interact with the rest of the system.

To run a manual alarm action:

  1. Click in required alarm panel when it is displayed.
