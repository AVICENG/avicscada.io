View Alarms

If you accessing the 963 Server in graphic mode, it indicates when an alarm has been received in the Alarm Viewer which is displayed on the 963’s Start up page. Other actions such as the display of a message box may have been engineered.

Alarms are shown as they arrive on the Incoming Alarms tab of the Alarm Viewer. This list stores the last 100 alarms. After alarms have been processed, they will appear in the Alarm History tab. In both of the lists icons indicate whether or not an alarm has been actioned by a user. Colours are used to indicate whether the alarm is a set alarm or a cleared alarm. A red bell indicates a set alarm, and a green bell indicates a cleared alarm. If the alarm has been actioned by the user the bell with appear with a tick over it.
