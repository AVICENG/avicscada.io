Edit Time Scheme of an existing Diary Group

The Time Schemes tab displays the normal occupation times. Based on your requirement, you can edit an existing time scheme.

To edit time schemes to an existing Diary Group:

  1. Access the 963 Server.

  2. Click Diary. A separate window is opened containing the diary groups. All the diary groups or folders containing diary groups are listed on the left pane of the page.

  3. Select the required diary group by clicking it. If the required diary group is not visible navigate to it by clicking the required folder.
    Once you have selected the diary group to which you want to add a time scheme, a page is displayed that shows the Group Time Planner, Group setup and status, and Time Schemes. Click the Time Schemes tab for the selected diary group.

  4. Select a time scheme from the Configured Time Schemes list that you want to modify and click Edit. The Diary Week Set Editor tab is displayed for the selected time scheme.

  5. Modify the name, colour settings, and time as required.
    or
    Select and right click a time scheme from the grid. The following options are displayed. Select the appropriate option.

    Option

    Description
    Delete deletes the selected time scheme
    On all day sets the status to ON for the entire day
    Off all day sets the status to OFF for the entire day
    On all week sets the status to ON for the entire week
    Off all week sets the status to OFF for the entire week
    Cut day cuts the time scheme
    Copy day copies the time scheme
    Paste day pastes the copied time scheme
    Paste for working week pastes the time scheme for the working week, monday through friday
    Paste for week pastes the time scheme for the entire week, monday through sunday

     

  6. Click Submit.
