Relinquish Control of a BACnet Value

When 963 adjusts a value in a BACnet device it writes the value into the value's priority array. The value will remain in the array, and be used when it is the highest. If required the 963's adjustment can be removed from the array by relinquishing control.

To relinquish control of a BACnet value:

  1. Display the page containing the value for which you want to relinquish control, and click the button or picture that enables the value to be changed.

Or

View the value for which you want to relinquish control in the Device Viewer, right-click the value, and click Adjust Point.

The BACnet Device dialogue box is displayed.

  1. Click Relinquish control.

To relinquish control of a BACnet value in text mode:

  1. Display the page containing the value for which you want to relinquish control, and click the button or picture that enables the value to be changed,.

  2. Click next to the value.
