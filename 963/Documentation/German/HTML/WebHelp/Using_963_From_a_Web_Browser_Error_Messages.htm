Fehlermeldungen

Falls beim Versuch von einem Client aus auf den 963 Server zuzugreifen, die 963 nicht im TCP/IP-Netzwerk gefunden wird, zeigt der Web-Browser standardmäßig eine Fehlermeldung an. Diese Meldungen werden vom Browser selbst festgelegt und gleichen möglicherweise denen, die dem Bediener von der normalen Benutzung eines Web-Browsers her schon vertraut sind. Sollte beim Versuch, eine Verbindung zum 963 Server herzustellen, der Zugriff auf den 963 Server aus irgendeinem Grund teilweise oder vollständig verwehrt werden, zeigt der 963 Server folgende Fehlermeldungen an:

Fehlermeldung

Beschreibung

Lizenz abgelaufen

Momentan ist die maximale Anzahl der unter der vorliegenden Lizenz für den 963 Server zulässigen Clients angemeldet. Versuchen Sie es später noch einmal oder nehmen Sie Verbindung mit einem der derzeit angemeldeten Bediener auf und bitten Sie ihn, sich abzumelden.

Sie wurden abgemeldet

Der Bediener wurde vom 963 Server automatisch vom System abgemeldet. Schließen Sie den Web-Browser, um sich vollständig abzumelden.

Sie haben leider keine Erlaubnis für einen 963-Clientzugriff

Sie haben versucht, auf einen Teil des 963 Servers zuzugreifen, für den Sie keine Befugnis haben. Wenden Sie sich an den Verantwortlichen für den 963 Server und stellen Sie sicher, dass Sie eine Zugriffsberechtigung für die gewünschte Ressource haben.

Außerhalb der erlaubten Betriebszeiten, bitte setzen Sie sich mit Ihrem 963-Administrator in Verbindung

Die Arbeitsgruppe ist mit einer Zeitzonengruppe verknüpft, und der Bediener versucht, sich außerhalb der zulässigen Zeiten anzumelden.

Sie sind nicht autorisiert zu konfigurieren

Sie besitzen nicht die Berechtigung zur Konfiguration von DDC-Stationen. Wenden Sie sich an den Verantwortlichen für den 963 Server und stellen Sie sicher, dass Sie eine Zugriffsberechtigung für die gewünschte Ressource haben.
