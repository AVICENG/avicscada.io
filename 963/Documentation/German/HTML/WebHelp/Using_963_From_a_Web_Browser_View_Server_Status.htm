Serverstatus anzeigen

Bei Bedarf können Informationen zum Serverstatus angezeigt werden. Dies kann im Fall von Problemen für den Systemtechniker nützlich sein.

So zeigen Sie den Serverstatus an:

1 Greifen Sie auf den 963 Server zu, wie im Abschnitt „Verbindung zum 963 Server herstellen" in dieser Anleitung beschrieben..

2 Klicken Sie auf Serverstatus. Daraufhin werden Informationen zum Serverstatus angezeigt.
