Alarmfelder ausblenden

Ein aufgrund eines Alarms angezeigtes Alarmfeld kann für zwei Minuten ausgeblendet werden, falls der Alarm im Moment nicht bearbeitet werden kann (weil Sie beispielsweise gerade etwas wichtigeres zu tun haben).

So blenden Sie das aktuelle Alarmfeld aus:

1 Klicken Sie im betreffenden Alarmfeld auf .

So blenden Sie alle Alarmfelder aus:

1 Klicken Sie in einem beliebigen Alarmfeld auf .
