Eine Alarmaktion manuell auslösen

Manuelle Alarmaktionen ermöglichen es, dass der Bediener im Alarmfall eine bestimmte Maßnahmen treffen kann. Auf diese Weise kann der Bediener die Anzeige kontrollieren und verhindern, dass die 963 nur noch von einem Anlagenbild zum nächsten springt und er keine Möglichkeit hat, mit den übrigen Systemteilen zu arbeiten.
