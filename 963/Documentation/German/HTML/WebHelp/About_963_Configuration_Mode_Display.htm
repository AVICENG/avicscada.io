Konfigurations anzeige

Die Konfigurationsanzeige unten ermöglicht den Zugriff auf den Konfigurationsmodus einer spezifizierten DDC-Station. In diesem Modus können einfache Änderungen an der Strategie vorgenommen werden. Bei aktiviertem Konfigurationsmodus stammen alle Bildschirmeingabefelder von der DDC-Station, und alle Tastatureingaben werden durch Anklicken von Mitteilen an die DDC-Station übertragen.
