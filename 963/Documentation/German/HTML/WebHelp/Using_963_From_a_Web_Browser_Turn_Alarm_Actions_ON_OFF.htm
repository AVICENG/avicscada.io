Alarmaktionen ein-/ausschalten

Die Aktionen, die durch eingehende Alarmmeldungen ausgelöst werden, können vom Bediener ein- und ausgeschaltet werden.

So schalten Sie Alarmaktionen ein-/aus:

1 Rufen Sie die eingehenden Alarme auf, wie im Abschnitt „Eingehende Alarme anzeigen" in dieser Anleitung beschrieben..

2 Entfernen Sie die Markierung im Auswahlfeld Alarmaktion autom. ausführen.

Dies ist keine dauerhafte Einstellung.

Beachten Sie, dass diese Funktion nur verfügbar ist, wenn man auf den 963 Server im Grafikmodus zugreift.
