Alarmaktionen manuell auslösen

Sollte der automatische Start von Alarmaktionen deaktiviert oder es aus irgendeinem Grund notwendig sein, eine bestimmte Aktion zu wiederholen, dann können die Alarmaktionen manuell ausgelöst werden.

So lösen Sie eine Alarmaktion manuell aus:

1 Rufen Sie die eingehenden Alarme auf, wie im Abschnitt „Eingehende Alarme anzeigen" in dieser Anleitung beschrieben..

2 Klicken Sie auf den Alarm, für den die Aktion ausgelöst werden soll.

3 Klicken Sie auf Alarmaktion simulieren.

Beachten Sie, dass diese Funktion nur verfügbar ist, wenn man auf den 963 Server im Grafikmodus zugreift.
