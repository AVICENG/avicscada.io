Log På

Før 963 kan bruges, er det nødvendigt at logge på, så 963 ved, hvilke oplysninger og faciliteter, du kan få adgang til.

Sådan logges der på:

1 Gå til 963-Serveren som beskrevet i kapitlet ‘Tilslutning til 963-Serveren’ i denne vejledning.

2 Indtast dit brugernavn i boksen ‘Brugernavn’. Dette er dit 963-brugernavn.

3 Indtast dit password i boksen ‘Password’.

Bemærk: Ved indtastning af password skal der skelnes mellem store og små bogstaver.

4 Klik på ‘Log på’. 963-Serverens start-side fremkommer. Med denne side kan man få adgang til skematiske sider, Enhedsoversigten, serverstatus, man kan logge af, og hvis man har adgang, kan man se alarmoversigten, hvis man bruger Microsoft Internet Explorer version 4.02 eller senere eller Netscape version 6.1 eller senere.
