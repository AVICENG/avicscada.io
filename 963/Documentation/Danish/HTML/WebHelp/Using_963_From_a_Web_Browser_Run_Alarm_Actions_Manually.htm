Kør Alarmhandlinger Manuelt

Hvis automatisk kørsel af alarmhandlinger er deaktiveret, eller hvis det af en eller anden grund er nødvendigt at køre en bestemt handling igen, kan alarmhandlingerne køres manuelt.

Sådan køres en alarmhandling manuelt:

1 Gå til 963-Serveren.

2 Vis Alarmoversigten.

3 Klik på fanen ‘Indkommende Alarmer’.

4 Klik på alarmen, for hvilken handlingen skal køres.

5 Klik på ‘Efterlign Alarmhandling’.

Bemærk: Denne funktion er kun tilgængelig, hvis man bruger Microsoft Internet Explorer version 4.02 eller senere eller Netscape version 6.1 eller senere.
