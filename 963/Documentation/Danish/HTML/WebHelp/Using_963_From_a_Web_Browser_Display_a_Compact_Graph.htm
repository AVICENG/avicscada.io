Vis en Kompakt Graf

Man kan se kompakte grafers data logget i IQ-undercentraler. Hvis der spørges efter en kompakt log, sender undercentralen den højeste og laveste værdi fra loggen og hver anden værdi som en procent af værdierne. Dermed kan man sende data hurtigt og i store mængder, dog er der en fejlrate på 1% for værdierne i logkanalen. Dette er standard, når brugerne klikker på en sensor i 963.

Sådan vises kompakt grafdata logget på en undercentral:

1 Vis siden, der indeholder den værdi, for hvilken logget data skal indsættes på en graf. Klik derefter på den værdi, der skal vises som en graf.

Eller

Se værdien, der skal vises som en graf, i Enhedsoversigten, højreklik på værdien, og vælg ‘Justér Punkt’ fra menuen, der fremkommer.

Grafen fremkommer.

Man kan forstørre og formindske grafen for at gøre det lettere at se data. Grafdata kan vises som en punktliste, og registrerede grafer kan indlæses.

Bemærk: Denne funktion er kun tilgængelig, hvis man bruger Microsoft Internet Explorer version 4.02 eller senere eller Netscape version 6.1 eller senere.
