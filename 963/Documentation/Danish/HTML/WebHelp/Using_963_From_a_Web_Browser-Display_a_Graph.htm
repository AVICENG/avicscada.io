Vis en Graf

Hvis man bruger Microsoft Internet Explorer version 4.02 eller senere eller Netscape version 6.1 eller senere for at få adgang til 963-Serveren, kan man se grafer. Med 963 kan man se både kompakte og præcisionslogger. Hver graf kan bestå af op til 5 kurver og kan vise op til 1000 værdier på hver kurve. Med adgang til 963 fra andre browsere kan man kun se oplysninger gemt i en sensorlog som en punktliste.
