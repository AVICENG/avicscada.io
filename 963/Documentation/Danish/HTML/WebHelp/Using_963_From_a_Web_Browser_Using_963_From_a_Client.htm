Brug af 963 fra en Klient

Adgang til oplysninger fra 963 kan let fås via en Web-browser over ethvert TCP/IP-netværk (f.eks. firmaets intranet eller via internettet). Alt, hvad der skal til, er 963-Serverens URL og et kendskab til et gyldigt brugernavn og password. Når forbindelse med 963-Serveren er opnået, kan man gå fra side til side, foretage justering af analoge værdier, justering af digitale værdier, se grafer, se alarmer eller foretage konfiguration af IQ-undercentraler ved at klikke på det tilsvarene hotspot, afhængigt af adgangsniveauet for 963.

For at opnå fuld funktionalitet og et grafisk datadisplay fra 963-Serveren bør der bruges Microsoft Internet Explorer version 4.02 eller senere eller Netscape version 6.1 eller senere. Hvis man får adgang til 963-Serveren via andre typer browsere, er kun en del af disse funktioner tilgængelige, og det skematiske data vises som en simpel tekstbaseret tabel, der opdateres hvert 20. sekund. Tabellen nedenfor viser de funktioner, der er tilgængelige fra andre browser-typer.
