Kør en Manuel Alarmhandling

Med manuelle alarmhandlinger kan brugeren udføre specifikke handlinger, når der opstår en alarm. Derved får operatøren kontrol over displayet og forhindrer dermed en situation, hvor 963 har for travlt med at springe til forskellige sider og derfor ikke kan ’tale’ med resten af systemet.

Sådan køres en manuel alarmhandling:

1 Klik på i det nødvendige alarmpanel, når det fremkommer.
