Vis en Grafindstilling

Specifikationen for, hvilke kurver, der fremkommer på en graf, hvordan et grid osv. er oprettet, kan gemmes som en grafindstilling på serveren. Disse indstillinger kan indlæses på et senere tidspunkt. Grafindstillingen bliver bevaret, men det er de seneste data, der bliver vist. Dette sparer tid, hvis grafens kurver regelmæssigt bliver set og analyseret på samme måde.

Sådan indlæses en grafindstilling:

1 Vis siden med den knap, hvormed grafindstillingen kan indlæses.

2 Klik på den knap eller grafik, der viser den ønskede grafindstilling.

Bemærk: Denne funktion er kun tilgængelig, hvis man bruger Microsoft Internet Explorer version 4.02 eller senere eller Netscape version 6.1 eller senere.
