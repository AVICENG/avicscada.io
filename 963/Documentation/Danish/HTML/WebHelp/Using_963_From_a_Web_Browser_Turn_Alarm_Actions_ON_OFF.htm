Tænd og Sluk for Alarmhandlinger

En bruger kan tænde eller slukke for handlinger, der opstår, når en alarm modtages.

Sådan tændes og slukkes der for en alarmhandling:

1 Gå til 963-Serveren.

2 Vis Alarmoversigten.

3 Klik på fanen ‘Indkommende Alarmer’.

4 Enten afkryds () eller tag krydset væk () fra afkrydsningsboksen ‘Autoudfør handlinger’.

Dette er ikke en permanent indstilling.

Bemærk: Denne funktion er kun tilgængelig, hvis man bruger Microsoft Internet Explorer version 4.02 eller senere eller Netscape version 6.1 eller senere.
