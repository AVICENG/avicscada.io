Zoom Ind og Ud på en Graf

Det er muligt at forstørre og formindske en graf for at gøre det nemmere at se data.

Sådan forstørres grafen:

1 Vis grafen.

2 Klik på mus-knappen, og træk den hen over det ønskede område på grafen.

3 Slip mus-knappen.

Sådan vendes der tilbage til original størrelse:

1 Højreklik på grafen.

Bemærk: Denne funktion er kun tilgængelig, hvis man bruger Microsoft Internet Explorer version 4.02 eller senere eller Netscape version 6.1 eller senere.
