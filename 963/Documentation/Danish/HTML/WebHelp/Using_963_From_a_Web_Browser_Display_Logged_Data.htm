Vis Logget Data

Hvis man har adgang til 963 med andre browsere end Microsoft Internet Explorer version 4.02 eller senere eller Netscape version 6.1 eller senere, kan man se oplysningerne gemt i sensorloggen som en punktliste.

Sådan vises en punktliste:

1 Gå til 963-Serveren, og vis siden med den værdi, for hvilken loggen skal vises som en punktliste.

2 Klik på ‘Se logdata for….’ for det ønskede punkt. Dermed fremkommer en side med punkterne.
