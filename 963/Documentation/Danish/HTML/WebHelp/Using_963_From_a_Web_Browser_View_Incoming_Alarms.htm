Se Indkommende Alarmer

Alarmer vises, som de ankommer på fanen ’Indkommende Alarmer’ i Alarmoversigten. Denne liste gemmer de seneste 100 alarmer.

Sådan kan man se indkommende alarmer:

1 Gå til 963-Serveren.

2 Vis 963’s start-side som beskrevet i kapitlet ‘Vis 963’s Start-Side’ i denne vejledning.

3 Klik på fanen ‘Indkommende Alarmer’.

Hvis teksten ikke passer i kolonnen, kan denne tilpasses ved at trække kanten ud til den korrekte størrelse. Alarmerne kan sorteres for enhver af kolonnerne, der vises, ved at klikke på den relevante kolonne. Listen kan opdateres ved at klikke på ‘Bed om Nye Alarmer’.

Bemærk: Denne funktion er kun tilgængelig, hvis man bruger Microsoft Internet Explorer version 4.02 eller senere eller Netscape version 6.1 eller senere.
