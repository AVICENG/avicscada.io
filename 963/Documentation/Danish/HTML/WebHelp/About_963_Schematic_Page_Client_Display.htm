Skematisk Side Klientdisplay

Med det Skematiske Sidedisplay, som vist nedenfor, kan en skematisk side vises. Med dette display kan du se udførlige oplysninger og forklaringer om, hvad der kan gøres, og ved at klikke på forskellige objekter kan du udføre forskellige handlinger. Ved at højreklikke hvor som helst på siden fremkommer en menu, der giver adgang til hjælpsystemet, og med hvilken man kan navigere mellem siderne.
