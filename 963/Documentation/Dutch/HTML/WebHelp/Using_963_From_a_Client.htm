Bediening 963 vanaf een Client

Informatie van 963 kan gemakkelijk worden geopend met behulp van een webbrowser, over een TCP / IP-netwerk (bijvoorbeeld het bedrijf Intranet, of het internet). Het enige dat nodig is, is de URL van de 963 Server en een geldige gebruikersnaam en wachtwoord. Als er eenmaal verbinding met de 963 Server is gemaakt is het mogelijk om tussen pagina's te schakelen, analoge waardes te verstellen, digitale waardes te verstellen, grafieken te tonen, en alarmen bekijken, of configuration mode openen bij IQ1 en IQ2 controllers door te klikken op de geschikte hotspot, afhankelijk van de mate van toegang tot de 963.

Wanneer er toegang wordt verkregen via een webbrowser zal de getoonde informatie afhankelijk zijn van het type van de gebruikte browser.

PCs met 963 Clients mogen elke configuratie hebben mits ze op een TCP/IP netwerk protocol draaien , en een Ethernet kaart, en een web browser geinstalleerd. Voor volledige grafische toepassingen (graphic mode) Internet Explorer v6.0 of hoger, of Firefox 2 (Aanbevolen is Internet Explorer version 6 of hoger) en de SUN JAVA runtime environment v1.5 of hoger is vereist. Andere browsers zullen alleen in tekst mode werken. 963 clients die een PDAs gebruiken hebben Windows Mobile 2003 Second Edition of hoger nodig. . 963 clients die smartphones gebruiken hebben Windows Mobile 5 of hoger nodig. Clients die PDAs, de Nokia 9210i, en smartphones gebruiken kunnen alleen in tekst mode gebruiken.

Opmerking: 963 is niet getest op alle apparatuur en Trend kan niet de compatibiliteit van ieder apparaat met de 963 server garanderen.
