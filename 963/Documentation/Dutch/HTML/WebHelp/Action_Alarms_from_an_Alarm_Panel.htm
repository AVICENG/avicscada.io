Behandeling van Alarmen vanaf een Alarm Panel

Alarmen kunnen worden behandeld vanaf een alarm panel.

Behandeling van Alarmen:

  1. Klik op in het alarm panel. De alarm historie zal getoond worden met de alarmen van dit alarm panel die bevestigd moeten worden.

  2. Klik op de alarm(en) die behandeld moeten worden (Houdt de CTRL toets ingedrukt en klik op de gewenste alarmen om meer dan één alarm te selecteren) Klik op Selecteer Alles, om alle alarmen te selecteren, klik op Deselecteer alles om alle alarmen uit de selectielijst te halen.

  3. Klik op Behandel geselecteerde alarmen. De Alarm Actie Omschrijving dialogue box wordt getoond.

  4. Type in de box in wat voor actie op deze storing is genomen om te helpen bij storing zoeken in de toekomst (b.v. wat voor actie er is genomen voor dit alarm).

  5. Klik op OK.

Opmerking: Deze optie werkt alleen als 963 in grafische mode is geopend.
