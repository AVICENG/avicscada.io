Een uitzondering verwijderen

Een uitzondering verwijderen:

  1. toon de uitzonderingen voor de diary group van welke de uitzonderingen moeten worden verwijderd.

  2. Klik op het label van de uitzondering die moet worden verwijderd.

  3. Klik op Verwijder deze uitzondering. Een dialogue box is wordt getoond welke vraagt om de verwijdering te bevestigen.

  4. Klik op OK.
