Tonen van grafiek data

De data die wordt gebruikt om de grafiek te tekenen kan als een lijst met punten worden getoond.

Tonen van grafiek data:

  1. Toon een Compact Grafiek, of een Precisie Grafiek voor de waarde waarvan de coördinaten moeten worden weergegeven zoals beschreven in het desbetreffende gedeelte van deze handleiding.

  2. Klik op de List tab. De grafiek wordt getoond.

  3. als er meerdere lijnen in de geselecteerde grafiek zijn klik dan op de lijn waarvan data is gewenst, een lijst van grafieklijnen zal bovenin de pagina verschijnen.

  4. Klik op de Grafiek tab om terug te keren naar de weergegeven grafiek.

Opmerking: Deze mogelijkheid is alleen beschikbaar als 963 in de grafische mode wordt geopend.
