Tonen van een precisie grafiek

Normaal gelogde data vanuit een controller zal in een compact formaat worden verzonden om te besparen op communicatie, echter, om dit te bereiken zal de data minder nauwkeurig zijn. Precisie grafieken geven volledige nauwkeurigheid, maar het duurt langer voordat de data is ontvangen. Precisie grafieken van data gelogd in IQ controllers kunnen worden weergegeven. Elke grafiek kan meerdere lijnen van maximaal 1000 waarden bevatten.

Wanneer er een precisie log wordt opgevraagd zal de controller iedere waarde in het logging kanaal als een individueel 6-digit getal versturen. Dit zorgt voor grote nauwkeurigheid, maar een beperkt bereik van de waarden (999 999 to –99 999, or .00001 to -.0001). Nog belangrijker is dat de overdracht snelheid veel trager is. Om deze reden kunnen gebruikers het aantal op te halen punten voor een precisie log beperken, deze methode moet niet worden gebruikt om 1 seconde logs op te halen. Deze methode heeft altijd de voorkeur bij meterstanden, want er is geen verlies van ruwe data.

Tonen van een precisie grafiek van data gelogd in een controller:

  1. Toon de pagina welke de sensor bevat waarvan de gelogde data in een grafiek moet worden gezet.

  2. Rechts klik op de sensor waarvan een grafiek moet worden gemaakt, en klik op Haal Volledige Precisie Log Grafiek(en) op. De grafiek wordt getoond.

U kunt de grafiek in- en uitzoomen om het gemakkelijker te maken om de data te zien. De grafiek data kan worden weergegeven als een lijst met punten, en geregistreerde grafieken kunnen worden getoond

Opmerking: Deze functie is alleen beschikbaar als de 963 server in grafische mode werkt, en wordt niet ondersteund voor waarden uit BACnet apparaten.
