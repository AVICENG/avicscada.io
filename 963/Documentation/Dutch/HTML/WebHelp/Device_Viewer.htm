Device Viewer

De Device Viewer is alleen beschikbaar als er een webbrowser wordt gebruikt welke de grafische mode van 963 ondersteund. Hiermee kunnen imputs, outputs, verstellingen, tijdzones en kritische alarmen van het geselecteerde gedeelte worden getoond, waardes kunnen worden aangepast en grafieken kunnen worden getoond. Als bv het internetwerk is geselecteerd worden alle waarden van het internetwerk getoond. Als er een aparte Lan is geselecteerd worden alleen de waardes van dat Lan getoond.

De Device Viewer is ingedeeld in twee verschillende gebieden:

Data Display

Navigator

Data Display

De Data Display bevat de gewenste modules, het is kleur gecodeerd om aan te geven of een alarm aktueel is. Rood geeft aan dat het een aktueel alarm is. Als de waarden zijn getoond is het mogelijk om waardes te verstellen, grafieken op te vragen of in configuratie mode te gaan bij IQ systeem apparatuur welke dit ondersteund. Het display heeft een aantal kolommen die de actuele waarde of status tonen van inputs, outputs, verstellingen, tijdzones en kritische alarmen van het geselecteerde gedeelte in de Navigator.

Het display heeft tevens een aantal drukknoppen waarmee kan worden geselecteerd wat voor type modules er moeten worden getoond.

Navigator

De navigator toont een directory tree van het systeem waar 963 mee is verbonden, hier kan het niveau dat getoond moet worden in de Data Display worden geselecteerd. Bijvoorbeeld, klikken op een Lan toont alle punten met labels op dat Lan. Toegang tot dit display kan aan bepaalde gebruikers worden geweigerd. Icons geven het type object aan.
