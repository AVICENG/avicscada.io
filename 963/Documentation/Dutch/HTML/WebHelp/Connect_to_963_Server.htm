Verbinding maken met een 963 server

Het is overal vandaan mogelijk om verbinding te maken met de 963 server, op voorwaarde dat een TCP/IP verbinding kan worden gemaakt met de 963 Server.

De 963 kan in twee verschillende modes werken, grafisch, of tekst, afhankelijk van de browser of apparatuur welke wordt gebruikt als client. PCs met 963 Clients mogen elke configuratie hebben mits ze op een TCP/IP netwerk protocol draaien , en een Ethernet kaart, en een web browser geinstalleerd. Voor volledige grafische toepassingen (graphic mode) Internet Explorer v6.0 of hoger, of Firefox 2 (Aanbevolen is Internet Explorer version 6 of hoger) en de SUN JAVA runtime environment v1.5 of hoger is vereist. Andere browsers zullen alleen in tekst mode werken. PDAs op Windows Mobile 2003 Second Edition of hoger, de Nokia 9210i en smartphones op Window Mobile 5 of hoger kunnen alleen toegang tot de server krijgen in tekst mode.

Opmerking: 963 is niet getest op alle apparatuur en Trend kan niet de compatibiliteit van ieder apparaat met de 963 server garanderen.

Er zijn verschillen tussen de twee modes

Verbinding maken met de 963 server:

  1. Start de web browser.

  2. Vul het URL adres van de 963 server in. Wanneer de 963 opgezet is om een andere TCP/IP poort te gebruiken dan poort 80, geef dan het poort nummer op gescheiden door een dubbele punt (:) bv. http:// 963:6000.

Dit zal dan het IP adres of naam van de pc zijn waarop de 963 server draait. De 963 Server’s standaard pagina wordt getoond.

Tip: De engineer heeft misschien een snelkoppeling gemaakt welke stap (1) en (2) uitvoerd. Klik daar dan op.

Opmerking: Er kan een andere pagina worden getoond, dit komt dan doordat de engineer dat zo heeft ge-engineerd.

  1. Wanneer u een geldige gebruikersnaam en paswoord invult wordt er een informatiepagina getoond. Als er een probleem is om met 963 te verbinden verschijnt er een fout melding.

Opmerking: Om veiligheidsredenen is het alleen mogelijk om in grafische mode toegang te krijgen met een 963 server.
