Configuratie mode openen in IQ1 en IQ2 controllers

963 geeft toegang tot configuratie mode in controllers die dat ondersteunen. Eenmaal in configuratie mode kunnen simpele dingen in de strategy worden gewijzigd. In configuration mode worden alle toetsaanslagen rechtstreeks naar de controller verstuurd als de zendknop is aangeklikt. Configuratie mode voor elke IQ op het netwerk die dit ondersteunt kan worden geopend vanaf de Device Viewer. Er kunnen ook drukknoppen op worden gezet om toegang te verschaffen tot configuratie mode voor een bepaalde controller.

Opmerking: dit is niet mogelijk voor BACnet apparatuur.

Configuratie mode openen vanuit de Device Viewer:

  1. Tonen van het IQ systeem

  2. Navigeer naar de gewenste controller.

  3. Rechts klik op de controller, en klik op IQ Configuration. Configuratie mode van die controller wordt nu geopend.

  4. Configuratie commando's kunnen worden ingetypt op het toetsenbord. Al de configuratie informatie zal in de configuration viewer worden getoond.

Configuratie mode openen door gebruik te maken van een drukknop:

  1. Toon de pagina met de drukknop die toegang geeft tot de configuratie mode van de controller.

  2. klik op de drukknop of het plaatje dat de configuratie mode van de betreffende controller opent. Configuratie mode van die controller wordt nu geopend.

Zenden van configuratie commando's naar de controller: :

  1. Eenmaal in de configuratie-mode, toetst u het configuratie commando in het tekstvak aan de onderkant van het scherm in.

  2. Druk op ENTER of klik op Submit.

Het systeem geeft de beschikbare functies aan; door het intypen van de hoofdletter in ieder woord kan de functie gebruikt worden. De meeste functies vereisen ook een toegevoegd nummer. Druk op X en klik op Submit om de pagina af te sluiten en de wijzigingen op te slaan. Druk op Q en klik op Submit om de pagina af te sluiten zonder de wijzigingen op te slaan. Als er bij de beginpagina van configuratie mode een X wordt ingetoets zal configuratie mode afsluiten. Het onderstation zal in configuratie mode zijn real time regel taken blijven uitvoeren, maar zal NIET reageren op andere (niet configuratie) communicatie. Het is daarom belangrijk dat configuratie mode wordt afgesloten VOORDAT wordt teruggegaan naar 963 supervisor mode. Het zenden van meer X+ENTER commandos zal geen schade aanrichten, dus bij twijfel, toets X+klik op zenden voordat configuratie mode wordt verlaten. 963 zal terugkeren naar normale toestand nadat het onderstation terug meldt met ‘Exit from Utility’.

Opmerking: Als een controller in configuratie mode is achtergelaten, zal configuratie mode na 15 minuten worden afgesloten.
