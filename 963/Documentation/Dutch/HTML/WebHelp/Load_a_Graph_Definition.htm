Laden van een grafiek definitie

De specificaties over welke grafieklijnen verschijnen, hoe de grid is opgezet etc kan opgeslagen worden als een definitie op de server. Deze set ups kunnen later worden geladen. De set-up van de grafiek blijft behouden, maar de laatste data zal getoond worden. Dit bespaart tijd als er grafieken zijn die regelmatig op dezelfde manier moeten worden bekeken en geanalyseerd.

Laden van een grafiek definitie:

  1. Toon de pagina welke de drukknop bevat die het mogelijk maakt om de graffiek set up te laden.

  2. Klik op de drukknop of het plaatje dat de gewenste grafiek opzet toont.

Opmerking: Deze mogelijkheid is alleen beschikbaar als 963 in de grafische mode wordt geopend.
