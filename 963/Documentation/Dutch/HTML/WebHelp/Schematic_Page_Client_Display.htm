Schematic Page Client Display

De Schematic Page Client Display maakt het mogelijk om een schematische pagina te tonen. Benaderd via een web browser die ondersteuning biedt voor de 963's grafische mode verschijnen de pagina's vrijwel hetzelfde als op de server-machine. Op het scherm kunt u de informatie zien, door te klikken op de verschillende objecten kunnen verschillende taken worden uitgevoerd. het display moet duidelijk maken wat u kunt doen. Rechts klikken ergens op de pagina achtergrond toont een menu dat toegang biedt tot de Help files, hier kunt u navigeren naar de volgende of vorige pagina. Er is geen Navigator op de Client, navigatie moet mogelijk zijn gemaakt door de ge-engineerde drukknoppen op de pagina's.

De 963 Server zal de informatie in tekst mode tonen Indien benaderd vanaf een browser die niet de 963 grafische mode ondersteund, grafische weergaves worden nu niet getoond. De pagina wordt weergegeven als 3 tabellen met live data, acties, en aanvullende informatie. Er zijn een aantal verschillende tekst mode lay-outs voor de verschillende controller types. De juiste lay-out voor het client apparaat wordt automatisch geselecteerd. Elke lay-out biedt dezelfde functionaliteit, maar de weergegeven gegevens varieren om verschillende schermformaten en beeldverhoudingen aan te kunnen.
