Tonen van gelogde data

Wanneer u de toegang heeft tot de 963 Server in tekst mode kunt u informatie die is opgeslagen in een sensor loggen als een lijst met punten.

Tonen van een lijst met punten:

  1. Start de 963 Server en toon de pagina welke de waardes bevat waarvan de gelogde data als een lijst met punten moet worden getoond.

  2. Klik op voor het gewenste punt. Dit toont een pagina met een puntenlijst.
