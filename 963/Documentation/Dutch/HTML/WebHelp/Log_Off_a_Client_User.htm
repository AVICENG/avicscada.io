Een Client gebruiker uitloggen

Client gebruikers die momenteel zijn ingelogd kunnen worden afgemeld door gebruikers die beschikken over de rechten voor het configureren van werkgroepen en gebruikers, of voor 963 Secure gebruikers die behoren tot de 'System Administrator' werkgroep.

Uitloggen van een Client:

  1. Start de 963 Server.

  2. Log In

  3. Klik op Server Status. De Server Status Pagina wordt getoond.

  4. Klik in het Client gedeelte op Log gebruiker uit voor de gewenste gebruiker.
