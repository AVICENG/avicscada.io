Tonen van een opgeslagen grafiek

Als data van een sensor in een controller is gelogd en is opgeslagen door 963, kan de opgeslagen informatie in grafiek worden gezet:

Een grafiek tonen van opgeslagen data:

  1. Toon een compact grafiek, of een precisie grafiek voor de sensor waarvan een grafiek moet worden gemaakt.

  2. Klik in het Data menu op Laad Opgeslagen Data. De Kies een periodedialogue box wordt getoond.

  3. Klik op de gewenste optie om de periode te specificeren voor de data die moet worden opgehaald. Klik op Custom om een specifieke periode op te geven en voer de eerste en laatste datum in door te klikken op naast de Start en Stop boxes om een dialogue box te tonen waar de gewenste data ingevuld kan worden.

  4. Klik op OK. De grafiek zal getoond worden.

U kunt de grafiek in- en uitzoomen om het gemakkelijker te maken om de data te zien. De grafiek data kan ook worden getoond als een lijst met punten.

Opmerking: Deze mogelijkheid is alleen beschikbaar als 963 in de grafische mode wordt geopend.
