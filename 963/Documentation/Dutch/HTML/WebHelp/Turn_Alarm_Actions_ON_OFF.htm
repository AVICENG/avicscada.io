Alarm acties AAN/UIT schakelen

De acties die plaatsvinden wanneer een alarm is ontvangen kunnen worden AAN / UIT geschakeld door de gebruiker.

Een alarm actie AAN/UIT schakelen

  1. Toon de inkomende Alarmen

  2. Wis de Auto execute acties check box.

Dit is geen permanente instelling.

Opmerking: Deze mogelijkheid is alleen beschikbaar als 963 in de grafische mode wordt geopend.
