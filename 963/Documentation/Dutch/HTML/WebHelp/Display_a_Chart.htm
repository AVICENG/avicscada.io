Tonen van een grafiek

Met 963 kan een overzicht van waarden vanuit een controller worden weergegeven.

Tonen van waarden:

  1. Toon een compact grafiek, of een precisie grafiek voor de sensor waarvan een grafiek moet worden gemaakt.

  2. Klik op Chart points in het Data menu. De geselecteerde waarde(n) zullen nu opgetekend worden met een verversings interval van 30 seconden.

U kunt de grafiek in- en uitzoomen om het gemakkelijker te maken om de data te zien. De grafiek data kan worden weergegeven als een lijst met punten, en geregistreerd grafieken kunnen worden getoond.

Opmerking: Deze functie is alleen beschikbaar als de 963 server in grafische mode werkt, en wordt niet ondersteund voor waarden uit BACnet apparaten.
