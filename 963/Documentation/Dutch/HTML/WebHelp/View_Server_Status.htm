Bekijk server status

Indien gewenst kan informatie over de status van de server worden getoond. Dit is handig voor de engineer als er problemen zijn aangetroffen.

Het tonen van de server status:

  1. Log in op de 963 Server..

  2. Log In

  3. Klik op Server Status. De Server Status Pagina wordt getoond.

Client gebruikers die zijn ingelogd kunnen uit worden gelogd door te klikken op Log gebruiker uit in het Clients gedeelte van de pagina.

De weergegeven informatie is afhankelijk van uw toegangsrechten. Als u de juiste autoriteit hebt zal de server status pagina de Toon afstand site verbindingen drukknop bevatten die het RemoteSiteDiallers Window toont welke een lijst bevat van alle momenteel aangesloten externe sites, hier kan de verbinding worden verbroken door op Verbreek verbinding naast de gewenste site.
