Over 963

Eenmaal ontworpen voorziet de 963 supervisor de gebruiker met een bedien paneel voor het hele systeem met de mogelijkheid om het Building Management System (bms) te monitoren en aan te passen met de garantie dat de HVAC installatie veilig en efficiënt werkt.

Het gebruik van gekleurde grafische weergaves speciaal ontwikkeld voor het systeem laat de informatie op een simpele en effectieve manier zien. Grafische voorstellingen en pagina's met tekst kunnen gebruikt worden om de gemonitoorde gegevens aan te vullen. Een snel en efficiënt communicatie netwerk maakt het mogelijk om deze informatie te verkrijgen van een HVAC systeem, dat misschien wel kilometers verspreid ligt in verschillende gebouwen, op andere locaties, of zelfs in andere landen.

De gebruiker heeft de mogelijkheid om HVAC installaties te monitoren en aanpassingen te maken in de manier en de wijze waarop het gebouw wordt beheerd door het gebruik van gekleurde grafische weergaven. Storing rapportage, analyse, en data opslag mogelijkheden bevorderen een efficiënt en energie zuinig werkend HVAC systeem.

De beschikbare informatie en instel mogelijkheden kunnen precies aan de behoefte van een bepaalde gebruiker worden aangepast. Dit betekent dat een operator nooit meer gegevens of opties ziet dan dat hij of zij nodig heeft, op deze manier wordt verwarring voorkomen. Echter, diegene die vanuit hun functie meer gegevens nodig hebben, kunnen toegang krijgen tot meer gedetailleerde gegevens.

Als 963 wordt benaderd vanaf een web browser wordt deze automatisch omgezet naar HTML (de taal die wordt begrepen door web browsers) en geeft de informatie door naar de client pc om deze in de web browser te tonen indien gewenst. Dit betekend dat er geen extra engineering nodig is om 963 door heel het bedrijf te kunnen gebruiken. Op Client pc's hoeft geen 963 software te worden geinstalleerd, deze moeten alleen een TCP/IP netwerk aansluiting en een web browser hebben.

963 server werkt op twee manieren, grafische mode en tekst mode, dit hangt af van het type web browser. Voor grafische mode is minimaal Microsoft Internet Explorer 6 of hoger nodig, of Firefox 2, en SUN JAVA runtime environment v1.5 of hoger. De browser moet JAVA script ingeschakeld hebben. Met andere browsers is alleen tekst mode mogelijk. Toegang tot de server kan via web browsers op PCs, PDAs (Windows Mobile 2003 Second Edition of hoger), Smartphones ( Window Mobile 5 of hoger), en de Nokia 9210i, hoewel volledige client functionaliteit alleen beschikbaar is op PC's die aan de eisen voor grafische mode voldoen. Andere apparaten kunnen alleen tekst mode gebruiken.

Notities

Schematische pagina's

In grafische mode kunnen alle pagina's worden getoond, er kan echter een klein verschil zijn in de verschijning van de pagina. WMF en EMF formaat graphics worden niet ondersteund. Zowel dynamische als statische en ook de backdrops worden getoond. In tekst mode zijn grafische weergaven niet te zien, de pagina wordt weergegeven als 3 tabellen die live data bevatten (dynamische objecten), acties, en statische objecten. In beide modes worden statische objecten welke niet ondersteunde acties uitvoeren niet weergegeven. Actieve files, zoals Excell worden niet ondersteund op een client.

963 Acties

De volgende acties worden ondersteund CONFIG, DROPALLLINES*, EXECUTESMS*, GOTO, GOTO Diary*, GOTO NEXT*, GOTO PREVIOUS*, LOGINAS, LOGOUT, MESSAGE*, PLAY*, POPUP*, SEND, SENDAUTO*, SETGENERIC*, VIEWGRAPH*, VIEWPOINTS*, VIEWQUERY, WEB.

*Alleen in grafische mode.

De EXECUTESMS actie is alleen beschikbaar als de SMS Direct optie gelicenceerd is.
