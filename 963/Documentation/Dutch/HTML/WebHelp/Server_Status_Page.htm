Server Status Pagina

De Server Status Pagina geeft informatie over de 963 Server status. De informatie is onderverdeeld in verschillende tabellen met verschillende soorten informatie die hieronder worden beschreven.

Tabel

Omschrijving

Server Informatie

Dit levert de volgende informatie over de 963-server: Lan nummer, netwerk adres, versie, aantijd, vrije schijf ruimte, scherm resolutie, en het aantal clients die momenteel zijn ingelogd.

Clients

Deze tabel geeft informatie over de clients die momenteel zijn ingelogd.

Cache

Deze tabel geeft informatie over alle huidige trend communicatie verzoeken

IQ Comms Statistieken

Deze tabel geeft informatie over alle apparaten die een communicatie fout hebben gemeld.

IP Comms Statistieken

Deze tabel geeft ondersteunende informatie voor de huidige IP-verbinding problemen.

De weergegeven informatie is afhankelijk van uw toegangsrechten. Om alle informatie te zien moet u zich aanmelden als een gebruiker met de bevoegdheid voor het configureren van werkgroepen en gebruikers, gebruikers zonder deze toegangsrechten kunnen alleen server informatie zien.

Gebruikers met de autoriteit om werkgroepen te configureren hebben ook toegang tot de Toon afstand site verbindingen drukknop welke een apart window toont met informatie over verbindingen met remote sites gemaakt door de 963 Server, hier kunnen ook, indien nodig, verbindingen worden verbroken.
