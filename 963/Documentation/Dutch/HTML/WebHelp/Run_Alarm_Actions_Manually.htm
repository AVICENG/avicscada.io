Uitvoeren van handmatige alarmacties

Als de automatische werking van alarm acties zijn uitgeschakeld, of als het nodig is om een bepaalde actie te herhalen, kunnen de alarm acties handmatig worden uitgevoerd.

uitvoeren van handmatige alarmacties:

  1. Toon de inkomende Alarmen

  2. Klik op het alarm waarvan de actie moet worden uitgevoerd.

  3. Klik op Emuleren Alarm Actie.

Opmerking: Deze mogelijkheid is alleen beschikbaar als 963 in de grafische mode wordt geopend.
