963 Server Opstart pagina

De 963 Opstart pagina wordt getoond zodra je bent ingelogd. Het geeft toegang tot Schematic Page Client Display, Device Viewer, Diary Display en als je bevoegd bent om alarmen te zien de Alarm Viewer.

Opmerking: Gebruikers die alleen toegang tot schematische pagina's hebben kunnen alleen de Schematics Page Display zien.
