Tonen van IQ3 Web Pagina's

963 kan IQ3 Web Pagina's tonen.

Opmerking: dit is niet mogelijk voor BACnet apparatuur.

Tonen van IQ3 web pagina's:

  1. Maak verbinding met de 963 server.

  2. Log in door gebruikersnaam en paswoord in te geven en klikken op Log in. De 963 Server’s Start up page wordt getoond. Deze pagina biedt toegang tot schematische pagina's, de Device Viewer, en zal de alarm viewer tonen als u daar toegang tot hebt.

  3. Klik op Device Viewer. De Device Viewer wordt in een apart window geopend.

  4. Dubbel klik op de site welke de controller bevat.

  5. Klik op de lan welke de controller bevat.

  6. Rechts klik op de controller, en klik op IQ Configuratie. De 'Welcome' web pagina zal worden getoond in een apart web browser window.
