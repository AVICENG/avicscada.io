Hälytystoimenpiteen käynnistys käsin

Manuaalisen hälytyskäsittelyn avulla käyttäjä voi hälytyksen ilmetessä käynnistää tietyn toimenpiteen. Tämä antaa käyttäjälle mahdollisuuden kontrolloida näyttöä, jotta 963 ei siirry liian nopeasti sivulta toiselle, jolloin käyttäjä ei ehtisi toimia muun järjestelmän kanssa vaadittavalla tavalla.

Hälytystoimenpiteen käynnistäminen käsin:

  1. Napsauta halutussa hälytyspaneelissa sen ollessa näkyvissä.
