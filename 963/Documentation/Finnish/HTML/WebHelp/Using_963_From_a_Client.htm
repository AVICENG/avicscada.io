963:n käyttö työasemakoneelta (Client)

963:n tietoihin päästään helposti web-selaimella kaikkien TCP/IP-verkkojen kautta (esim. yrityksen intranetin tai internetin kautta). Tarvitset vain 963 Serverin URL-osoitteen sekä voimassa olevan käyttäjätunnuksen ja salasanan. Kun yhteys 963 Serveriin on luotu, voit liikkua sivulta toiselle, säätää analogisia arvoja, säätää digitaalisia arvoja, katsoa trendikäyriä ja selata hälytyksiä tai siirtyä pre IQ3 -säätimien (IQ1, IQ2) ohjelmointitilaan napsauttamalla tarkoitukseen varattuja kohtia, riippuen käyttöoikeuksistasi 963:een.

Kirjautuessasi web-selaimen avulla näytettävät tiedot ja käytettävissä olevat toiminnot riippuvat selaintyypistä.

963-työasemien PC-kokoonpanolle ei ole erityisvaatimuksia, kunhan niissä on asennettuna TCP/IP-verkkoprotokolla sekä Ethernet-kortti ja web-selain. Täysiä grafiikkaominaisuuksia (graafinen tila) varten tarvitaan Internet Explorer v6.0 tai uudempi tai Firefox 2 (suositus Internet Explorer versio 6 tai uudempi) sekä SUN JAVA runtime environment v1.5 tai uudempi. Muut selaimet toimivat vain tekstinäytöllä (tekstitilassa). 963:n työasemina käytettävissä PDA-laitteissa on oltava Windows Mobile 2003 Second Edition tai uudempi. 963:n työasemina käytettävissä älypuhelimissa on oltava Windows Mobile 5 tai uudempi. PDA-laitteet, Nokia 9210i ja älypuhelimet tukevat vain tekstitilaa.

Huomaa, että 963:a ei ole testattu kaikilla laitteilla eikä Trend voi taata tietyn laitteen yhteensopivuutta 963 Serverin kanssa.
