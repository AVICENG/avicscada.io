Työasemakäyttäjän (Client) uloskirjaaminen

Käyttäjät, joilla on oikeudet ohjelmoida työryhmiä ja käyttäjiä tai kuuluvat 963 Securen "Järjestelmänvalvojien" työryhmään, voivat kirjata ulos parhaillaan kirjautuneena olevat työasemakäyttäjät (Client) tai kirjata heidät ulos edellisestä istunnosta, jos he yrittävät kirjautua sisään toiselta työasemalta.

Työaseman (Client) uloskirjaaminen:

  1. Muodosta yhteys 963 Serveriin.

  2. Kirjaudu sisään.

  3. Napsauta Palvelimen tila. Status-sivu tulee näkyviin.

  4. Napsauta halutulle käyttäjälle Etäkäyttäjät-alueella Kirjaa käyttäjä ulos.
