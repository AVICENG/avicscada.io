Poikkeusajan muokkaaminen

Poikkeusajan muokkaamiseksi:

  1. Näytä poikkeusajat sille aikatauluryhmälle, jonka poikkeusaikaa haluat muokata.

  2. Napsauta muokattavan poikkeusajan tunnusta

  3. Muokkaa poikkeusaikaa tarpeen mukaan.

  4. Jos muutokset on lähetettävä säätimeen heti, valitse Valitse tämä, jos ajat lähetään alakeskukseen heti, muuten ne lähetetään päävalvomosta määriteltynä aikana -valintaruutu.

  5. Napsauta Siirrä ajat päävalvomoon.

Palataksesi ryhmän poikkeusluetteloon napsauta Paina tästä palataksesi aikatauluryhmän poikkeusaikoihin.
