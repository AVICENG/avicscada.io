IQ3 web-sivujen näyttö

963 voi näyttää IQ3 web-sivut.

Huomaa, että tämä toiminto ei ole käytettävissä BACnet-laitteille.

IQ3 web-sivujen näyttäminen:

  1. Muodosta yhteys 963 Serveriin.

  2. Kirjaudu sisään antamalla käyttäjätunnuksesi ja salasanasi ja napsauttamalla Kirjaudu sisään. 963 Server Aloitussivu tulee näkyviin. Tältä sivulta pääset kaaviosivuille ja Laitenäyttöön sekä, jos olet oikeutettu näkemään hälytykset, myös Hälytysnäyttöön.

  3. Napsauta Laitenäyttö. Laitenäyttö avautuu erilliseen ikkunaan.

  4. Kaksoisnapsauta toimipaikkaa, joka sisältää halutun säätimen.

  5. Napsauta Lania, joka sisältää halutun säätimen.

  6. Napsauta hiiren oikealla painikkeella laitetta ja napsauta sitten IQ ohjelmointi. Valitun säätimen "Tervetuloa" web-sivu avautuu erilliseen selainikkunaan.
