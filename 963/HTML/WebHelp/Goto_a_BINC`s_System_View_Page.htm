Goto a BINC`s System View Page

963 can display a BINC`s System View Page.

To display IQ3 web pages:

  1. Display the IQ System.

  2. Navigate to the required BINC.

  3. Right-click the BINC, and click System view page. The BINC`s System view page will be displayed in a separate web browser window.
