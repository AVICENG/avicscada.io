Add Time Scheme to an existing Diary Group

The Times Schemes tab displays the normal occupation times. Based on your requirement, you can add new time schemes to an existing diary group. For example, you can add winter and summer time schemes.

To add time schemes to an existing Diary Group:

  1. Access the 963 Server.

  2. Click Diary. A separate window is opened containing the diary groups. All the diary groups or folders containing diary groups are listed on the left pane of the page.

  3. Select the required diary group by clicking it. If the required diary group is not visible navigate to it by clicking the required folder.
    Once you have selected the diary group to which you want to add a time scheme, a page is displayed that shows the Group Time Planner, Group setup and status, and Time Schemes.

  1. Click the Time Schemes tab for the selected diary group.
    You can create time schemes for a single day or for a whole week.

To create a time scheme for a whole week

 

  • Select the Display Week Sets option to create a time scheme for an entire week and click New.

  • The Diary Week Set Editor window appears.

 

  • In the Name box enter the name for the time scheme.

  • In the Choose colour box click the colour that is to be used to represent days that use these times.

  • Set up the timings for each day as required in the grid for the time scheme. The time is then reflected in the Start Time and End Time boxes.

  • Click Submit to add the time scheme to the list of Configured Schemes for the selected diary group.

 

To create a time scheme for a single day

 

  • Select the Display Special Days option to create a time scheme for a special day and click New.

  • The Diary Week Set Editor window appears.

 

 

  • In the Name box enter the name for the time scheme.

  • In the Choose colour box click the colour that is to be used to represent this day.

  • Set up the timings as required in the grid for the time scheme. The time is then reflected in the Start Time and End Time boxes.

  • Click Submit to add the time scheme to the list of Configured Schemes for the selected diary group.
