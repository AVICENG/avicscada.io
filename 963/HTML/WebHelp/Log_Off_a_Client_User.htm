Log Off a Client User

Client users that are currently logged in can be logged off by users who have the rights to configure workgroups and users, or for 963 Secure belong to the 'System Administrator' workgroup will be logged out of a previous session if they attempt to log in from another client.

To log a client off:

  1. Access the 963 Server.

  2. Log In.

  3. Click Server Status. The Server Status Page is displayed.

  4. In the Clients area click Log out user for the required user.
