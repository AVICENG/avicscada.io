963 Server Start up Page

The 963 Start up Page is displayed once you have logged in. It provides access to the Schematic Page Client Display, Device Viewer, Diary Display and if you are authorised to view alarms contains the Alarm Viewer.

Note that for users that only have access to schematics the Schematics Page Display will be shown instead.
