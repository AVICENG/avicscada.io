Add a Week Set Template

Week set templates can be added to provide a template of occupation times for a weekly pattern.

To add a week set template:

  1. Access the 963 Server.

  2. Display the page containing the button that provides access to the diary group, and click the button.

Or

Click Diary. A separate window is opened containing the diary groups, or folders containing diary groups. Select the required diary group by clicking it. If the required diary group is not visible navigate to it by clicking the required folder. To move back to the previous folder (parent) click Go up one folder level.

Once you have selected the required diary group, a page is displayed that lists the time zones connected to it, and enables access to the exception templates and exceptions.

  1. Click Click here to go to the time schemes for this group.

  2. Click New week set. A display is opened similar to the one shown below.

  3. In the Label box enter the name for the template.

  4. In the Colour box click the colour that is to be used to represent days that use these times.

  5. Click Update label and colour.

  6. In the boxes in the Start and End columns enter start or stop times for each period.

  7. For IQ3 and IQ4 controllers periods can be added by selecting the check box in the New column, then in the boxes in the Start and End columns entering start or stop times for the new period, and then clicking Send adjustments. Unwanted periods can be removed by selecting the check box next to the and then clicking Send adjustments.

  • For pre IQ3 controllers unused periods should have both times set to 24:00.

  1. Click Send adjustments in the area that specifies the times.

  2. Repeat steps (8) and (9) for each day.

  3. If the changes are to be sent to the controller immediately click the Tick this box to send changes immediately, otherwise changes will be sent at the group download time check box.

  4. Once the operating times are correctly set up click Process time scheme adjustment.
