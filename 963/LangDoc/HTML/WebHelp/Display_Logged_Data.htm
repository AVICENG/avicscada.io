Display Logged Data

When you are accessing the 963 Server in text mode you can display information logged in a controller as a list points.

To display a list of points:

  1. Access the 963 Server and display the page that contains the value for which the log is to be displayed as a list of points.

  2. Click for the required point. This displays a page listing the points.
