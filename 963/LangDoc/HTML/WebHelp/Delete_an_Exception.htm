Delete an Exception

To delete an exception:

  1. View the exceptions for the diary group from which the exception is to be deleted.

  2. Select a date or a date range for an exception that you want to delete.

  3. Click Delete Exception(s). A dialogue box is displayed asking for confirmation of the deletion.

  4. Click Yes to delete an exception.

Alternatively,

  1. Select a diary group and go to the Time Schemes tab.

  2. Select Display week sets to view the weekly time scheme applicability or select Display special days to view the time scheme applicability for a special day.

  3. Select a time scheme from the list of Configure Time Schemes.

  4. Click Where are these times used?. The Where are these times used? dialogue box is displayed.

  5. Select a time scheme by checking the empty check box.

  6. Click Delete Exceptions. A dialogue box is displayed asking for confirmation of the deletion.

  7. Click Yes to delete an exception.
