Diary Display

The Diary Client Display allows the occupation times of the controller to be viewed, and adjusted. Exceptions to the normal working times can be setup, and edited as required.

The Group Time Planner tab displays the occupation times set for an exception. An exception can be any day which usually does not follow the normal occupation times, e.g bank holidays. Areas can be set to be occupied at times different to the normal occupation times (e.g. for bank holidays) by adding an exception to the diary group that is linked to the time zone controlling the occupation times for that area. This feature allows different occupation times to be set up for each day of the week. Each Diary Group can contain its own exception templates, allowing the same name to be used within different groups, but defining different occupation times. Buttons enable exceptions to be added, edited, or deleted, and entire time schemes to be applied within a diary group.

The Group setup and status tab displays a list of the timezones that are linked to the diary group(s) selected in the Navigator. The list indicates the site, Lan, controller name, timezone label, item code, and device type. Buttons enable linked timezones to be displayed, times to be sent to the controllers, actual times to be viewed, and group setting to be edited.

 The Times Schemes tab displays the normal occupation times, and the times schemes that have been set up for the Diary group selected in the left pane. Buttons enable new time schemes to be created, existing ones to be edited, or deleted.
