Display IQ3 Web Pages

963 can display IQ3 Web Pages.

Note this facility is not available for BACnet devices.

To display IQ3 web pages:

  1. Connect to the 963 Server.

  2. Log in by entering your user name and password and clicking Log in. The 963 Server’s Start up page is displayed. This page provides access to schematic pages, the Device Viewer, and will display the alarm viewer if you have access to it.

  3. Click Device Viewer. The Device Viewer is displayed in a separate window.

  4. Double click on the site containing the controller.

  5. Click the, Lan containing the controller.

  6. Right-click the device, and click IQ Configuration. The selected controller's 'Welcome' web page will be displayed in a separate web browser window.
