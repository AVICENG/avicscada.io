Display Graph Data

The data used to draw the graph can be displayed as a list of points. This feature is only available when accessing the 963 Server in graphic mode.

To display the graph data:

  1. Display a graph from a schematic page or from the Device Viewer.

  2. Click the List tab. The graph data is displayed.

The list data can be copied (using the keyboard shortcut, Ctrl+C) on a clipboard and pasted into another application, e.g. Microsoft Excel. However, if the copy action does not work follow the below instructions.

  • Open the C:\Program Files\Java\jre6\lib\security\java.policy file in notepad.

  • Look for the below line:

"standard" properties that can be read by anyone

  • Paste the below line just after the above line:

permission java.awt.AWTPermission "accessClipboard"

  • Restart your computer.

  1. If there is more than on trace on the graph in the Selected trace box click the trace for which data is required a list of the traces will appear at the top of the window.

  2. To return to the graph display click the Graph tab.
