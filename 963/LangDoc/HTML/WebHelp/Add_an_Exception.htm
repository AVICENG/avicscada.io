Add an Exception

Areas can be set to be occupied at times different to the normal occupation times (e.g. for bank holidays) by adding an exception to the diary group that is linked to the time zone controlling the occupation times for that area.

You can add an exception in two ways:

  • Using Time Schemes

  • Using the Exception Wizard

To add an exception using time schemes

 

  • View the exceptions for the diary group to which the exception is to be added as described in the ‘View Exceptions’ section of this manual.

  • Click on a date to select one day or click and drag the mouse to select a date range.

  • Right click and select Apply Time Scheme. The Exceptions screen is displayed.

     

  • Select an exception that you want to apply. The selected exception settings are applied to the selected days.

 

To add an exception using the Exception Wizard

  1. View the exceptions for the diary group to which the exception is to be added as described in the ‘View Exceptions’ section of this manual.

  2. Click on a date to select one day or click and drag the mouse to select a date range.

  3. Click Exception Wizard. The Configure Exception screen is displayed.

     

  4. In the Name box enter a name for the exception.

Note: To repeat the exception annually, check the Repeat this exception yearly check box.

  1. Click Next. The Edit Times screen is displayed.

     

  2. Select Display week sets to view the existing weekly time schemes. Click New to create a new exception. The Diary Week Set Editor is displayed. Create a new weekly time scheme as explained in the ‘Add Time Scheme to an existing Diary Group’ section of this manual.
    or
    Select Display special days to view the time schemes for special days. Click New to create a new exception. The Diary Week Set Editor is displayed. Create a new time scheme for a day as explained in the ‘Add Time Scheme to an existing Diary Group’ section of this manual.

  3. Click Next. The Edit Dates screen is displayed.

     

  4. Click on a date to select a day or click and drag the mouse to select a date range. Click on the date range to clear the selection.
    In case of a date clash while applying an exception, the following error message is displayed. Choose the appropriate option to close the window.

     

  5. Click Next. The End screen is displayed with the summary of the exception that you just created.

     

  6. Click Finish. The Download Options  is displayed.

     

  7. You can choose to download the changes either at the group schedule time or in the next available time slot. Select the appropriate option and click OK.

  8. Click Cancel to undo the whole process.
