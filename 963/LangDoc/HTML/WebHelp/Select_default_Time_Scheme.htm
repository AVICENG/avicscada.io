Select default Time Scheme

A default time scheme can be selected for a diary group at any time. The existing time scheme is overridden. You can also select a future date to apply the selected time scheme. This way the selected time scheme will be applicable only from the date that you select.

To select default time scheme:

  1. Access the 963 Server.

  2. Click Diary. A separate window is opened containing the diary groups. All the diary groups or folders containing diary groups are listed on the left pane of the page.

  3. Select the required diary group by clicking it. If the required diary group is not visible navigate to it by clicking the required folder.
    Once you have selected the diary group to which you want to add a time scheme, a page is displayed that shows the Group Time Planner, Group setup and status, and Time Schemes. Click the Time Schemes tab for the selected diary group.

  4. Select a time scheme from the Default Times selection for group list.

  5. A confirmation dialogue box is displayed asking you to either change the time scheme instantly or set it for a future date. Select the appropriate option.

  6. If you select Yes, a Select Date dialogue box is displayed. Select a date to apply the time scheme and click OK.

  7. If you select No, a confirmation dialogue box is displayed. Select Yes to apply the time scheme instantly.

  8. The colour information for the time scheme is displayed, if there is an overlap with the existing time scheme colour in the diary group.

  9. Click OK. The Download Options dialogue box is displayed.

  10. You can choose to download the changes either at the group schedule time or in the next available time slot. Select the appropriate option and click OK.

  11. The selected time scheme is either applied instantly or set for a future date.
